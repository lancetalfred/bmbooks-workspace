# Go-Live Day

Steps for the actual cutover day. Pre-launch technical work is complete — this is what happens on the day the site goes live.

---

## Before removing the password

- [ ] Confirm domain connection is ready with Abbey (Black Sheep Design)
- [ ] Set featured images on new genre collections in Shopify Admin (Romance, Horror, Manga, Crime & Thriller, Translated Fiction)
- [ ] Confirm BookHub has been notified and "Go to Store" links are updated to the Shopify URL

## Domain cutover (with Abbey)

- [ ] Point bmbooks.co.nz DNS to Shopify
- [ ] Confirm SSL certificate activates (may take a few minutes)
- [ ] Remove store password in Shopify Admin → Online Store → Preferences

## Immediately after going live

- [ ] Submit sitemap to Google Search Console: `https://bmbooks.co.nz/sitemap.xml`
- [ ] Submit sitemap to Bing Webmaster Tools (bmbooksellers@gmail.com)
- [ ] Test any product URL with Rich Results Test (search.google.com/test/rich-results)
- [ ] Place a test order to confirm checkout works end to end
- [ ] Confirm BookKeeper sync is running and a new product appears within 1 hour

Full pre-launch technical checklist lives in GitHub Issues (milestone: Pre-Launch and Go-Live Day).
