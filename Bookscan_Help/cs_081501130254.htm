The Returns Reasons section of Bookscan allows for you to maintain the different Returns Reason you may want to use within the system. (E.g. Short Supply)
To maintain Returns Reasons on the main menu click on Tables,then point to Authority Tables and then click on Returns Reasons.
The return reasons will shown on your Return Authorisation request and Returns reports when printed.

Add
To add a new Returns Reason, click on the Add button.
Enter the following:
Code (3 characters)
Name

Click the OK button.

Edit
To edit an existing Returns Reason, click on the Returns Reason and click the Edit button
You can make changes to:
Code
Name

Click the OK button.

Delete
To delete an existing Returns Reason, click on the Returns Reason and click the Delete button.
Then click the Yes button.

Close
To exit the Returns Reasons section, click this button.
