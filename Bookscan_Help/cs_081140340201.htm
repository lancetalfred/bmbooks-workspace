Backup Data Files
Previous  Top  Next


WARNING: To back up your files you will require exclusive access to Bookscan.
Ensure that all terminals are back to the main menu.

The backup data files functionality allows for your database to be saved as a restore point in the event serious problems.

·From the main menu, click on Utilities/Database Utilities/Backup Data Files.  
·This will open the backup window.  
·The backup will be saved to the data directory. This will overwite the previous backup. To save to another drive select the drive from the combo box.  
·Click on the Backup button.  
·All your data files and your reports will be zipped up and saved as the file ebbackup.zip. This may take some time depending on the size of your database.  
·When finished, a line will be selected in blue 'Zip Archiving Complete'.  
·Click on Exit when done.
