Sales Report:   All Daily Sales


   Purpose:
Detail the current day's sales.  

   Parameters:
Sort-order, Summary option and (suppliers only) option to print only one line per ISBN.  

   Output:
ISBN, Title, Author, Sale Qty, On-hand, Sale Price, Cost Price, Discount levels, Operator and Time details  
Subtotalled either by supplier or by department.  
 
   Report-form Variables reset at runtime:
ReportTitle    -   reflects the selection parameters.  
Summary      -   determines the level of detail reported.  
ByDept      -   determines sort-order.  

See also:   Selection Controls.
