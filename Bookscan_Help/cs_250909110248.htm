Web orders are picked up from your web site by Bookscan's e-Comms program. e-Comms stores the orders in the Bookscan database and Bookscan displays them in the Web Orders window. From the Web Orders window you can manage your web orders, processing them without re-keying, via the Order Entry window. For the distributor/publisher configuration, a picking slip will be created. For the retail configuration, it will be an invoice.

The Web Orders window is opened from the main menu: Sales/Invoices /Web Orders.



·The upper browser displays all the outstanding web order header details – the customer's email address, the web order number and date, the order value and shipping method.  
·The lower browser shows the items ordered.  
·To view the customer details, select a line in the upper browser and click the Show Details (F7) button (or just double click on the line). The customer details will display, hiding the upper browser. Click the Show List (F7) button to go back to the previous view.  



·If the customer already in the customer master the Customer field will display the customer code and name. If it is empty you will need to add the customer. To add the customer to the customer master, just click on the Add button.  
·To invoice the order, click on the Invoice (F8) button. The Order Entry window will open with this order filled out.  



Make any amendments that you wish to the order header information and then click on the Save (F12) button. The browser, with the order lines filled in, will now be displayed.



Make any amendments that you wish to the order lines and then click on the Finalise (F12) button and the Order Entry Footer window will open.


 
·Add any other information such as comments, freight, invoice terms etc.  
·Click on the Payment (F9) button to open the Tendering window.  
·Process the payment as for a standard invoice. If there are back orders, you will have the choice of taking payment for the full sale or just for the items in stock. In the latter instance you will need to process another payment when invoicing the backorder. In the retail configuration, the backorder will take the form of a special order. Any payment for it will be stored as a deposit on the special order.  
·Click on the Post (F12) button to create the invoice (or for the distributor/publisher configuration, a picking slip).
