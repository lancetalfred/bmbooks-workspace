ONIX / BISAC / Bookfind / GBIP Import Window

The import window allows you to import titles into the Bookscan Master database in one of the following 4 formats. CSV, ONIX, BISAC and Bookfind TAGGED format and CSV.

The import window from the main menu is located in Utilites-->Import.

Obtaining Import Files

To import files from one of the supported web sites, right click the mouse and you will be offered a context menu with each of these sites. Select one and Internet explorer will open at the corresponding web site. Follow the web site instructions and download a file in one of the 3 formats. Then follow the previous step to import the file into the import browser. Opening the Import window will create the directory "c:\import" automatically for you. Use this directory for a consistent place to download files from the web sites and import them into Bookscan.
Files can be imported from elsewhere too. (as shown below)



Importing/Loading Files

·To load a file on a disk/local hard drive simply click on the file cabinet in the file detail box and select the drive, directory and filename.  
·Then click on the "import file" button. If the file is in one of the 4 formats Bookscan will automatically detect which one and prompt to import the file into the import browser. At this stage you will then be viewing the contents of the import file (nothing has been saved at this stage). CSV files require special setups to be done, so before using this for the first time, speak to barcode solutions.  

When the file loads and displays into the browser, if the title is already in your master file, it will have a tick in on the left-hand side in the 'I' column.
Note: If a title is already in your database, if you select it and use the 'Import Selected Titles', it will not touch this title.

Adding to Draft PO when Importing

The column "DPO Qty" can be edited to allow the direct importing of titles into Draft Purchase orders for titles being imported for the first time and when updating existing titles.
Double click on the DPO Qty square for the rows and you can enter a quantity that will be added to the DPO when the title is imported/Updated. Clicking on the "DPO Qty" column header caption will also filter titles so you will only see titles that you have entered a DPO Qty into.

Options for Importing
· Price/Status Update - With this ticked, when updating titles already in your master database, it will only change the Retail Price and Product Status. This will be ticked by default and will enable any grooming that has been carried out to remain in place.  
·Get Images - This will allow Bookscan to obtain from the internet any images that have been included in an ONIX import file (generally an internet address of where the image is that our program will download) and store under the Publisher tab in the title master. This will slow the process down a little and requires internet access.  
·Manual Edit - The manual edit checkbox if checked, will also open the normal Bookscan title master window on each title to allow further editing of other master title fields. Once you have edited the title click the "select" button to accept the changes or the "cancel" button to discard the changes and optionally abort the rest of the import.  
Selecting Titles to Save/Update

Once the contents of the file are listed, you can use the "Find ISBN" button to find a particular title by BARCODE / ISBN.
To import these titles into Bookscan highlight the ones you want using standard windows selection / blocking commands.

·To select individual titles hold CTRL and click the left mouse button.  
·To select a block of titles hold SHIFT and left mouse click the first title in the block and then click the last title that you want to select.  
·To select all titles use the "Select All" button to highlight all titles to be imported / updated.  

Importing New Titles

Once you have highlighted the titles for import you must select a supplier that these titles will be imported with from the supplier combo box.
If you also wish to have the Publisher information updated at the same time (Stored in Tables-->Authority Tables--Publisher), select from the drop-down list for Publishers.
Next click the "Import Selected Titles" button. Then click 'Yes' to confirm.
That's all there is to it. Once you have imported titles they will change colour to red to indicate that you have already processed them. It will also tick the 'I' column.

Updating Exisiting Titles

Once you have highlighted the titles for import (For updating, you do not need to Select a Supplier or Publisher)

The fields that will get updated are(Unless 'Price/Status Update' is ticked) : Title, Author, RRP, Edition, Year, Binding, Status, Supplier ( if one is selected in the supplier combo box, otherwise will not change ), publisher ( if one is selected in the publisher combo box, otherwise wont change ) , and all the fields visible on the publisher tab page of the Bookscan master title window.

To Update, click "Update Selected Titles" button. This will update all titles that are selected, that are currently in your database. (If a title is not ticked, it will not add it).





Most of the columns in the import browser can be sorted to make it easier to find the titles you are looking for, especially if there are many titles in the import file. Simply click on the column header caption to re-sort the titles by that column.

Importing Images

Click on the browse icon & select a text file with just a list of ISBN's only. One ISBN per line.

Click on Images. Bookscan will import images for the ISBN's listed in the text file from either Nielsen or Bowker, depending on your settings, in the sizes you have selected in the Title Master - Web Search - Set Defaults window.
