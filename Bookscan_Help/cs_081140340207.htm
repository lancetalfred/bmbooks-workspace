Vouchers

Vouchers are set up in the Title Master with the Type set to Untracked Voucher, Voucher, Tracked, or Docket Voucher.
For Docket vouchers, the starting number is initially set in the System Options - Counters tab. Tracked Vouchers use the number that is on your pre-printed voucher, and this is enterred into Bookscan during the sale process.


Tracked vouchers
A tracked voucher is a gift voucher whose number and outstanding value is recorded within the Bookscan program. You can view the amount outstanding and the history of the vouchers use in the Voucher Enquiry window.

You need to set up voucher tender types in the Transaction types.

In the Tendering window, when you select a tender transaction of type 'tracked voucher', the window replace the Amount Tendered field with two fields: Voucher Amount and Voucher Number.



Enter the voucher number in the second field. The Voucher Amount field will then display the amount outstanding on the voucher. Click the OK button or press the Enter key, and if the voucher is sufficient to cover the sale, the transaction will be finalised. If the voucher still has an outstanding amount after the sale, this amount will be displayed in a pop-up window. Write this new balance on the voucher.
If the voucher is insufficient to cover the sale total, click the OK button will cause the amount to be saved to the Transaction browser, the Owing and Amount Tendered fields reduced and the tender type reset to the default.



Select another tender type to complete the transaction. See 'multiple tender types' below.

Docket Vouchers

These are tendered using the same process as tracked vouchers above, however when only partially redeemed, Bookscan will print a new copy of the voucher with the same number, but an updated remaining value, when the sale is completed.

Rewards traked vouchers

You must have set up a rewards tracked voucher separate to the normal tracked vouchers. When you select this tender type, the drop down list will display ony the reward tracked vouchers for the customer selected in the cash sales screen.



Selling tracked vouchers
Tracked voucher are set up in the title master in the usual way but with the 'product type' set as 'tracked voucher'. You may have your vouchers printed with a barcoded product number on them or you may choose to set up your vouchers with an easy to remember product code such as 'VOU'. See the Title Master section for further details. To sell your vouchers through the POS, enter the product code in the Barcode field. The program will display the Voucher Entry window.



Enter the number of vouchers the customer is buying.
In the next field enter the first voucher in the sequence. The program will then display the final number in the sequence. If any of the voucher numbers in the sequence have already been sold, you will be prompted.
If you have a broken sequence of numbers, break them up into contiguous sequences or enter each voucher individually.
Click the OK (F12) button to save the line to the browser.
Then add any other purchases and finalise the sale as usual.


Gift cards and untracked vouchers
You may find it useful to set gift cards and untracked voucher transactions to be of type "require name". Where this setting is made, you will be required to enter a customer name (or other detail such as a voucher number) in a text field on the Tendering window. (Refer to the Set Up chapter for details in setting up the various transaction types).



So in the Tendering window, select your transaction type. The window will display a text field Surname below the Amount Tendered field. You can overtype the amount tendered if required then press the Enter or the Tab key to move to the Surname field. You can type up to 20 characters. Click the OK button or press the Enter key to finalise the transaction. If the amount tendered is greater than the sale amount, the difference is displayed as change in the Change window. If the amount tendered is insufficient to cover the sale, it becomes a part payment, and you will need to select another tender transaction to complete the sale - see 'multiple tender types' below.

Enquire on Vouchers
From the main menu, click on Sales, then point to Vouchers and then click on Enquire.
A window will open displaying the list of vouchers on the system.
Check the Show outstanding only box to display only those vouchers not finalised.



Columns displayed:
·Voucher number  
·Date issued  
·Customer Key (if any)  
·Customer name (if any)  
·Purchase price  
·Amount outstanding  
·If it is a voucher generated by a rewards program  

Click on the icon at the top of Bookscan to print a listing of the vouchers.

You can also double click in the Outstanding field to adjust the amount to a new, (lower only), value. The amount cannot be adjusted upwards.

Print voucher reports
From the main menu, click on Sales, then point to Vouchers and click on Print.
You have the option to select all vouchers or finalised vouchers only.
Click OK to print.

Purge vouchers
From the main menu, click on Sales, then point to Vouchers and click on Purge.
The system will offer to purge all finalised vouchers older than a year. To change the purge date, select a new date from the drop down box.
You have the option to purge all vouchers or finalised vouchers only.
Click OK to purge.
