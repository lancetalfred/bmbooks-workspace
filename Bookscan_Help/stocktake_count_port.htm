Counting Stock with Portable Scanners
Previous  Top  Next

Note: Documentation will be supplied on disc with the scanners, please refer to that for the most relevent instructions for the scanners supplied. There are different scanners available and they will come with drivers and instructions specific to them.

When using portable scanners to count stock, you should try to do one section or gondola at a time. After counting a section, upload the file from the scanner and load it in to Bookscan. After uploading the scanner is automatically refreshed and is ready for counting the next section. This way, if an error is made or there is equipment failure, it will be easier to correct.


Counting stock using Metrologic scanners  
1. Retrieve a scanner from the cradle. When you pick it up, the screen should turn on. If it doesn't, press the ESC button. The Stocktake menu of the scanner will display.  
2. We need to ensure that the scanner's memory is empty before using it for the first time. To do this, press '.' to enter 'Utilities Menu'. Then press '1' to enter 'Browse Data Menu'. If 'No Data' is displayed, the scanner memory is empty.  
3. Go back on the main menu and press 'ESC' to start the stocktake for this scanner.  
4. Begin scanning products. To scan, squeeze the large buttons on the side of the scanner (the laser beam will come on).  
Note: If there is a quantity to be scanned, pressing '-' to get in 'Manual Mode', then scan the barcode, and then on the scanner keypad key the quantity of the total item include the existing one. For example, your current quantity is 10, if you want to add another 4, you should enter 14. Press Enter key. This will show a quantity on the screen against the products ISBN. The mode will then be changed back to 'Automatic Mode', which is increased by 1 for every scan. You can continue scanning the next item.  
5.Continue scanning all items.  
 
Uploading you counts from Metrologic scanners
1.When yopu have finished scanning, press '.' key on the scanner keypad. This will enter 'Utilities Menu' of the scanner. Pressing 3 to select 'Upload Data', and then press 'ENTER'. You will see a message 'UConnecting.'.  
2.Place the scanner back in the cradle.  
3.Return to the PC that the cradle is plugged into.  
4.Click on the Stocktake icon on your desktop to open the StkUtil program. The following window will now appear:  
 
 
5. Set the 'Load Mode' to 'Upload data'.  
6. Click 'Start' button.  
7. A pop up window will open where you can enter a filename of your own choosing, for example Lookup08060301.CSV into your selected folder (e.g. C:\e-BilityData\Stopcktake).  
8.   The data will start transmitting from the scanner to the cradle. The scanner will beep once when it has finished sending. On the screen of the scanner, it will indicate the number it items uploaded.  
9. At this point you will know that the data has been received correctly. The data is automatically erased after a successful upload and the scanner is now ready for further counting.  
 
Loading your stock counts into Bookscan
 
1.From the main menu, select Modules/Stocktake/Stocktake. This opens the Stocktake Entry window.  
2.Select the Default Department from the drop down box (say STK Stocktake). Products without departments are allocated to this department. After the stocktake you can print a listing of these titles and correct them.  
3.Set File Fields to '2'  
4.Click Import from File button.  
5.In the pop up window that now displays, select the file saved in the folder C:\e-BilityData\Stocktake. The file name should be in the format:  
6.'Stocktake_todaysdate' or 'Stocktake_bayNumber'  
Note: Please ensure you do not import a file for the second time; otherwise it will double up your figures for these titles.  
7.Click the Open button.  
8.A pop up window will display 'Import Complete' and display the total number of titles appended and the number of titles not found in the master file.  
9.A listing of these titles will be displayed when you click OK button. This list can be printed.  
Note: To print the report at a later time, right click in the Stocktake Entry window and select 'Reprint Exception report' from the drop down menu. Then select the DBF file in the window (which will have the same name as the file that was imported with unknown titles).  
10.The titles that were appended should now be added to the active Stocktake window for you to view.  
11.You are now ready to upload the next file.
