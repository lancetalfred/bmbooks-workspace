Purchasing Report:      Returns Authorisation


   Purpose:
Wholesaler's report, reprinting a returns authorisation for a nominated customer.  

   Parameters:
Customer.  

   Output:
ISBN, Title, Author, Inv #, Inv Date, Inv Cost, Return Qty, Extended Inv. Cost.  
    Wholesaler details can be readily added to header (see Modifying System Reports).
 
   Report-form Variables reset at runtime:
    Various licensee details.
    RANo   -   the Returns Authorisation number.

See also:   Selection Controls.
