Downloading Stock Counts from Metrologic Scanners
Previous  Top  Next

Note: Documentation will be supplied on disc with the scanners, please refer to that for the most relevent instructions for the scanners supplied. There are different scanners available and they will come with drivers and instructions specific to them.

1.From the main menu, select Modules/Stocktake/Stocktake. This opens the Stocktake Entry window.  
2.Select the Default Department from the drop down box (say STK Stocktake). Products without departments are allocated to this department. After the stocktake you can print a listing of these titles and correct them.  
3.Set File Fields to '2'  
4.Click Import from File button.  
5.With the window that appears, select the file saved in the folder C:\Stocktake. The file name should be in the format:  
6.'Stocktake_todaysdate' or 'Stocktake_bayNumber'  
Note: Please ensure you do not import a file for the second time; otherwise it will double up your figures for these titles.  
Click Open button.  
7.A pop up will will display 'Import Complete' and display the total number of titles appended and the number of titles not found in the master file.  
8.A listing of these titles will be displayed when you click OK button. This list can be printed.  
Note: To print the report at a later time, right click in the Stocktake Entry window and select 'Reprint Exception report' from the drop down menu. Then select the DBF file in the window (which will have the same name as the file that was imported with unknown titles).  
9.The titles that were appended should now be added to the active Stocktake window for you to view.  
10.You can either download the next file or move on to the next section.
