Categories - Global changes
Previous  Top  Next


Clicking the Edit button in the Managing Categories menu opens the Edit Category Detail window.

Here you can globally:
· Rename a category.  
· Change a category code.  
· Moving one category for another.  
· Cloning a category from another.  
   · Replacing a category with a new category.  
 
 
 
Renaming a category  
· In the Name box, overtype the category name and click OK.  
 
Change the category code  
· In the New Code box enter the new code (max. six digits).  
· Click the Replace button  
· Click OK.  
 
Moving one category to another
· In the Category list select the category you are copying from.
· Click on the Edit button.
· In the Edit Category Detail window, overtype the category code to which you are copying in the New Code box.
· Click on the Move button.
· Click the appropriate radio button to update:  
· Titles only  
· Customers Only  
· Both titles and customers  
· Click OK.
· The titles and/or customers will be appended to the second category and deleted from the first.

Cloning a category
· In the Category list select the category you are copying from.
· Click on the Edit button.
· In the Edit Category Detail window, overtype the new category code in the New Code box.
· In the Name box, overtype the new category's name.
· Click on the Clone button.
· Click the appropriate radio button to update:  
· Titles only  
· Customers Only  
· Both titles and customers  
· Click OK.
· The new category will be created with the titles and/or customers appended. The original category will be unchanged.

Replacing a category with a new one
· In the Category list select the category you are copying from.
· Click on the Edit button.
· In the Edit Category Detail window, overtype the new category code in the New Code box.
· Click on the Clone button.
· Click the appropriate radio button to update:  
· Titles only  
· Customers Only  
· Both titles and customers  
· Click OK.
· The new category will be created with the titles and/or customers appended. The original category will be destroyed.
· The new category will take its name from the original one.
