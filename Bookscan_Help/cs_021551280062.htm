Store Transfers - Transfers out

From the main menu, select Purchasing/Transfers/Transfers Out. The Transfers Out window will open.

Processing transfers out
·Select the branch to which you wish to transfer stock in the Transfer to combo box.  
·Enter a reference number in the PO number field, if you wish, or leave as zero.  
·Select the method by which you wish to send the transfer - either EDI (via e-Comms) or by Disk.  
·Scan the barcode (or type in the ISBN)  
·Enter the Quantity to be transferred.  
·Click Save Line (F12).  
·To edit a line you have entered, double click on the line in the browser to open it in the edit line.  
·When all lines have been entered click Process Transfer (F12).  
·If sending via disk, a dialogue box will open. In the Data Path field select the path of the folder to save the transfer file to - this is a standard Windows selection field. Click on the button at the end of the field and browse to the transfer file folder (ie. on USB thumb drive), to select it.  

Transfer History
To display completed tranfers, click on the Show History (F11) button. The browser will display all completed transfers out.

Filtering the transfers
·Radio button To all locations will display all transfers.  
·Radio button To selected location will allow you display only transfers to the selected branch. This will enble the Select order no. combo box where you can select a single transfer by transfer number.  

Click on the End History (F11) button to end displaying history.
