Backorders
Previous  Top  Next

In the Order Entry window, if there is insufficient stock to fulfill an order line, a backorder is created. As stock subsequently becomes available, you will need to release these backorders, creating picking slips for the orders.
The Backorder Release window is accessed via the main menu - Modules/ Warehousing/ Backorder Release.
Note that it is best to maximise window when you are working on it to display all the columns of the browser.
The window displays a browser listing all backorders in the system



Backorders are released against the oldest order first until all available stock is exhausted. However you can prevent individual backorder lines being released (setting them as Held), release backorders only for a selected customer or product code and restrict the maximum quantity to be released to any one order.

Backorders Browser
The browser displays the customer backorders in the system.
There are three methods of filtering the browser display:
·All backorders  
·By customer: display only backorders for the customer selected in the Customer field.  
·By product: display only backorders for the product selected in the Product field.  

Sorting the browser
Where all backorders are displayed, you can change the sort order by clicking on the appropriate column header.
·Pick number         Sort chronologically  
·Date            Sort chronologically  
·Customer key or customer   Sort in customer key order  
·Product code or Title      Sort by product code  

Releasing backorders
Backorders are released by clicking on the Release (F12) button. Backorders will only be released for those lines displayed in the browser.
So if you have displayed backorders only for a particular customer, then only that customer's backorders will be released.
Similarly if you are showing only backorders for a certain product then clicking on the Release (F12) button will release backorders only for that product.
If All Backorders is selected then a full backorder release will be done.

Holding backorders
To prevent a backorder from releasing, you can set it to held by double clicking its checkbox in the Held column. To remove the flag double click on the check box again.
To hold all displayed lines, right click to display the context menu and select Hold All.
To remove the held flag on all lines in the browser, click on the Remove Held button.
To remove the held flag on all lines, not just those in the browser, check the Remove all Held checkbox and then click on the Remove Held button.
An example: you want to release a single line for a customer.
   Move the cursor to the Customer field and enter the customer key.
   Right click on the browser and select Hold All.
   Double click on the Held checkbox of the line you want to release
   Click on the Release (F12) button

Stopped Accounts
You can prevent stock being allocated to order for accounts which are on stop by checking the No allocation to customers on stop check box.

Linking
If the Consolidate Pick Slips option in System Options has been selected, released backorders will be automatically linked to any unprinted picking slips for that customer.
If the total value of these orders is below the minimum order value, the released order will be flagged as held.
If the released order brings the total value of the customer's current orders to above the minimum, then all the held flags will be automatically removed and the customer orders will be available for despatch.

Backorder reports
There are three backorder reports that can be run from this window and from Bookscan Reports. These are:
·All Backorders (sorted by date, customer or product code).  
·For a single customer.  
·For a single product code.  
To run the reports, select either the customer or the product to display them in the browser and then click on the Print (F11) button.
For all backorders, select the All Backorders option. If required change the sort order by clicking on the appropriate column header (as outlined above). Then click on the Print (F11) button.

Handling backorders where there is insufficient stock
Where there is insufficient stock to cover all backorders for a certain product, you can limit the maximum quantity to be allocated to each order.
Select the product in the product field and then enter the maximum quantity you want allocated any order in the Max/Order field. Then click on the Release (F12) button.

Stock availability
You can set a stock availability message against each status type in the Status Maintenance window (main menu: Tables/Authority tables/ Status).
The message will print as the backorder reason against each backorder line of your invoice. For example you may set 'temporarily out of stock' against the 'active' status.
In the Backorder release window, this message displays in the Out of stock reason column of the browser. Next to it is a column showing the due date from your supplier.
You can edit these fields by double clicking on them. This opens the Availability pop-up window.
