Creating a Schedule of Shows
Previous  Top  Next

Overview
For each movie, show or event (let's call them all 'shows' from now on), you will need to set up a product in the master file. Sales for every session of this show are recorded against this product code. So your ticket sales will be included in your standard Bookscan sales. As well you will be able to print reports showing how well your shows have succeeded.
For each show will you need to set a venue, set up a series of sessions and set the price points. This is done in the Ticket Maintenance windows where there are wizards to speed this up.
Then you are ready to start selling your tickets through the POS.

Departments and suppliers
Before creating tickets for the first time, you may wish to create an Bookscan department for shows. In the examples that follow, we will use a department called Tickets with a code TIX. You should also create a binding type (e.g. binding code 'MO', name 'Movies') for your show.

Bookscan requires that you set a supplier against each product. You will need to set up in the supplier master either a dummy supplier for your shows or, for movies, set up your distributor as a supplier.

Creating a show in the master file
For each show, you will need to set up a product in the master file. Open the Title Master window and click on the New F11 button as you normally would to set up any product.



You will need to set the following fields:
·Product code  
·Title. You may also want to enter the director or principal star as the author  
·Product type as 'Ticket'.  
·Binding  
·Status  
·Department (as 'TIX' in our example).  
·Supplier  

Set these flags to true:
·Firm sale (so the program doesn't generate returns to supplier).  
·No discount  
·No special orders  
·Generic (turns off standard stock controlling – the ticketing module will control the number of tickets you can sell for each session).  

Setting up your show sessions
Setting up your schedule of shows is done in the Ticketed Shows window which is opened from the main menu: Modules/ Tickets/ Ticket Maintenance. The window will show all your current shows in the browser on the left. Current shows are those for which you are now selling tickets. For the show selected in the browser, the schedule, prices and its other settings are displayed.



To add a show to the schedule, click on the Add Show (F12) button. The Title Master and Title Find windows will open. Find the show you want and press the Select button in the Title Master window to add it to the Ticketed Shows browser

For each show, you can add or edit a message to display in the tickets, set an audience rating and set the 'no printing' flag if you don't want tickets to print as they are sold at the POS.

To display both current and non-current shows, untick the 'Show only current' checkbox. The browser will display all shows and will add a third column: 'Cur'. Current shows will show a tick in the column. To toggle the currency of the show, double click the Cur column. Non-current shows will to be available for sale in the POS.

You can change the display order of the shows by using the Up (F3) and Down (F4) buttons. Moving your next-to-go show to the top of the list will cause it to be selected as the default in the POS.

Price Types
As you add each show to the browser, it will be allocated the default price points.

To add a new price point, click the Add Price (F11) button.

To edit a price point, double click on it. The Ticket Price window will open:



Overtype any field you want and click the Save (F12) button.
The Short Text and Text fields are what will print on the stub and long side of the ticket respectively.

You can change the display order of the price points by using the Up (F5) and Down (F6) buttons. Moving your most frequently sold price point to the top will cause it to be selected as the default in the POS.

Creating a Show Schedule
To create individual sessions for the ticket, click on the Build Schedule (F8) button. This will open the Ticketed Shows Schedule Creation window:



In this window you will create a session for performance of your show.
·Set the first and last dates of your schedule.  
·Set the days there will be performances:  
oEvery day: set this check if there are performances every day in you date range.  
oSingle day: set this if there are just performances on one day. (This is provided as a short cut).  
oSet the recurring days: you may have performances say, every Wednesday to Friday over your date range.  
oExtra dates: click the Add Date (F7) button to add odd extra dates not within the date range or not on a selected recurring day.  
oExcluded date: click the Add Date (F8) button to exclude a date in the range. For example, you may have performances every Thursday of the year except Christmas Day.  
·Next add a session or sessions to the Default Sessions browser. Click the Add Session (F7) button to open the Ticket Session window:  
 

oSelect a session from the Session Name combo box and a location from the Location combo.  
oYou can alter the start time and the number of available seats.  
oClick Save (F12) to add the session. In our example above we will have two sessions a day  
·Now click the Build Schedule (F12) button to add each session to the Schedule browser. Repeat these steps for as many sessions and dates as required to build your schedule. If you get it wrong and want to start again, tick the Overwrite check box before clicking the Build Schedule (F12) button.  

Example
An example may be useful here:
Say you want to schedule the play Wind in the Willows through January. There will be matinees on Wednesdays and Fridays in Theatre #1 and evening performances on Thursdays in Theatre #2.
·Select 'Wind in the Willows' in the browser of the Ticketed Shows window  
·Click on the Build Schedule (F8) button to open the Ticketed Shows Schedule Creation window.  
·Set the Date range: the First Day field to '1/01/2009' and the Last Day field '31/1/ 2009'.  
·In the Recurring Days field select Wednesday and Friday.  
·Click on the Add Session (F7) button. Select the session 'Matinee' and the location 'Theatre #1'. Save the session.  

 

·Click the Build Schedule (F12) button. The browser will load with matinee sessions in Theatre #1 for each Wednesday and Friday in January. The Default Sessions browser will clear.  



·Now change the Recurring days to Thursday and set the default session to 'Evening' in Theatre #2.  
·Click the Build Schedule (F12) button. The program will add to the schedule evening sessions in Theatre #2 for each Thursday in January.  
·Close the Schedule Creation window and you are finished.
