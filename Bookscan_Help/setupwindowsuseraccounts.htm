Setup Windows User Accounts
Previous  Top  Next


All register computers should have the same User Account and Password for use on the Points of Sale. This same account must also be created on the server. On the register computers the account may be a limited account, but on the Server it must be a Power User or Administrator.  
To create a new User account, go to [Start Button] -> Control Panel -> Add or remove user accounts  
 





Select Create a new account
 

In this example I will create the User called "POS". Enter the new Username when prompted.
Then click Create Account button.


Now click Create a password

You will now be back at the User Accounts screen. Click on the user POS icon/name to select it and you will see the window above. Select Create a Password option.


Now you need to enter the password you want to use for the account (and enter it a second time to confirm), enter a password hint and click Create Password button.


You will now have a screen showing the password protected account. Click on the "X" in the top corner to close the window. The account has now been created on this computer with the password set. You can repeat these steps on the other register computers.
