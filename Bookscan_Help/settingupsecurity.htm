Setting up the security system.
Previous  Top  Next

You can set up security in four different ways:  
 
Full security  
·The full security module allows you set restrict access for each operator to every part of the program.  
·Operators must login (optionally with a password) to use the system.  
·The system will maintain an audit log of all operations such as record deletions and additions and price changes. This log can be viewed in the Security window (Utilities\Security).  
·Additionally the operators' initials are recorded against each transaction.  
·Contact Barcode Solutions if you wish to purchase this option.  
 
Prompt for operator initials.  
·This option forces the operator to enter his ( two character) initials before using any of the sales screens.  
·In cash sales, the operator will need to enter his initials before each transaction.  
·The operator's initials are recoded against each transaction.  
·To turn on this option, open System Options from the main menu, select the Sales tab and set the Prompt for operator initials flag.  
·This option can be used in conjunction with the full security module.  
 
Use encoded initials.  
·This option is a variation of the Prompt for operator initials option, adding a higher level of security.  
·Instead of entering operators entering their two character initials they instead enter a three character which is set against each operator in the Operator window.  
·This options stops an operator from logging in using another user's initials.  
·To turn on this option, open System Options from the main menu, select the Sales tab and set the Prompt for operator initials flag and then the Use encoded initials flag.  
 
Master Password  
·If you are not using the security module you can still password protect the System Options window. The password can be set on the Licensee tab by clicking on the Set System & Password (Alt F9) button.  

Setting up Operators
Operators are set up in the Operators window. From the main menu select Utilities\Security\Operators.

Viewing the Audit log
When an operator performs a task that creates transaction, the operator code is recorded against the transaction ( e.g. an invoice or a cash sale). However not all tasks result in the creation of a transaction, for example deleting a special order or closing sales for the day. In these cases a record is created in the audit log and the date, time, operator, register and the details of the task are recorded.
You can view the audit log in the Security window. Go to the main menu and select Utilities\Security\Audit window.
In the window you can:
·View all operations performed on Bookscan except transaction creation.  
·Select an operator from the combo box to view just that operator's actions.  
·Print an audit report filtered by date range (and optionally filter by operator).  
·Purge old audit records.  

Stock adjustments
If you are using the full security module, you can restrict which operators can perform stock adjustments. Stock is adjusted up in the Receiving window by "receiving" stock against a supplier called "Stock Adjustment". Similarly stock is adjusted down by creating a "return" against the same supplier. After you have created the stock adjustment supplier (usually supplier code STK, supplier name Stock Adjustment), open the Purchasing tab in System Options and nominate that supplier as the stock adjustment supplier by selecting it in the Stock Adjustment Supplier combo box there. Those operators without the authority to do stock adjustments will not be able to receive from or return to this supplier.
