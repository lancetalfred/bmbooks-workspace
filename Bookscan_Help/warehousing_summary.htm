Warehousing - Topics Summary
Previous  Top  Next


Bookscan can be configured for either a retail environment or for a publisher or distributor. The main feature of the publisher/distributor configuration is the warehousing module:

Customer orders
Customer orders are entered into the Order Entry window to create picking slips. These can be printed in the warehouse via the picking window. When the stock is picked it is scan packed at the packing station using the Packing window. Customer labels are printed and then the invoice is created and despatched with the goods.
You can have the program automatically link multiple picking slips for each customer allowing you to process all the orders for customer and so saving you freight.
The Order Entry window also monitors credit limits, and controls small orders, either adding small order surcharges or holding small orders until further orders are received.
See the Order Entry chapter for details.

Backorders
Where there is insufficient stock to fill a customer order line, the product is backordered (as opposed to creating special orders in the retail system). As the backorder is created, so too is a draft purchase order for the product. As stock is received to cover backorders, backorders can be released in the Backorder release window.
Pricing backorders
You can arrange to have the backorders automatically re-priced to reflect the latest prices. This is a very handy feature when you want to take orders on a new title but don't yet have a price for it. It is also useful where you are bringing in products from overseas and, because of fluctuating exchange rates, you don't want to set a price until the stock arrives. See the Re-pricing backorders section below.

Picking Slip Control The program has a picking slip control window allowing managers to monitor warehouse activity.

Packing
For the packing stations, the program has a dispatch window where you scan in each product as you pack it. This ensures the accuracy of your shipments. It also prints the carton labels, allows recording of the shipping details and charges, creates the invoice and, for EDI orders, electronically transmits the ASN (advanced shipping notes).
The program caters for Coles Myer central warehouse electronic invoicing and labeling.

Setting up carriers
Set up each of your carriers (road freight, air freight, post, etc). This will enable you to record the shipment method and the consignment note against each invoice. You may also wish to set up quasi-carriers such as "Pick up", "Delivered by rep" and so on.
