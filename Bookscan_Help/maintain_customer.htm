Grooming the Customer Master
Previous  Top  Next

Customer masters created in Bookscan or other software may need to be groomed to allow you to use all of Bookscan's features.
Bookscan provides a window to speed up grooming your customer master. It has three separate functions:
·Extract the surname from the (full) Name field. This allows you to search and index on the surname field.  
·Extract the post code from the second and third address lines.  
·Extract the state from the second and third address lines or calculate it from the post code.  
Using the surname field allows you to do surname searches to find a customer.
Correct state and post code fields are necessary to make your mailing files comply with Australia Post's electronic sorting requirements.

Operating Instructions
The grooming window is opened main menu: select Utilities/Database Utilities/Groom Customer Master.

Click on the Load Database button.
This copies the customer master into a temporary file for you to work on. Any changes you make here will not be saved to the master file until you click on the Update Customer Master button. While working in this window, you and other users should refrain from editing the customer postal addresses in the customer master window. Any edits will be lost when you save your temporary file back to your customer master file. You may still add new customers and their addresses.

Surname extraction
If the surname option is not already selected, click on the Surname radio button to select it.
The browser will display only those customer records with blank Surname fields.
Surname extraction consists of three steps, each step initiated by pressing in turn one of the three Go buttons. The order in which you do them depends on the format of your data:
If the majority of your customer records have the surname placed last in the Name field (e.g. 'John Smith' as opposed to 'Smith, John'), press the top Go button.
If the majority of the records are in the format 'Smith, John', you would run the middle option first.

Step 1
·Click on the top Go button.  
The system will copy the last word of the Customer field to the Surname field and check the Use column.  
·Scroll through the browser and uncheck (by double clicking on the checkbox) those records you do not want to update (e.g. company names). Unticking the Use field will clear the Surname field. If you make a mistake you can reverse it my double clicking the checkbox again; the Surname field will be re-populated.  
·You can use the right mouse menu to check all or uncheck all records and also to uncheck all above (or below) the currently selected record. This is useful if you only want to work on a portion of your database at a time.  
·You can now also manually edit the Surname field by double clicking on the entry you want to change and overtyping it.  
·Once you are ready click on the Update Customer Master button. This will save your changes to the customer master. Those records that have been updated will disappear from the browser, leaving only those records still to be done.  

Step 2
If the some of the records are in the format Smith, John, initiate the second step by pressing the middle Go button. It none of your records are in this format you can skip the second step.
·Click on the middle Go button to copy over first word of the Customer field to the Surname field.  
·Proceed as in step 1.  

Step 3
The last step is used for company names. It copies the first 25 characters from the Customer field to the Surname field.
·If the majority of your customers are companies you may wish to run this option first.  
·Click on the bottom Go Button.  
·Proceed as in step 1.  
·Any records not updated will need to be changed manually in the customer master.  

Post code extraction
This operation extracts the first four digit number from first, the third address (shown in the Suburb/Town column) and then the second address field. You may wish to do the steps in the reverse order if most post codes are recorded on the second field. The system will only extract numbers whose preceding and trailing characters are a space, a comma or a full stop.
When the changes are saved, the customer master's post code field is updated and the post code (along with preceding and trailing spaces, commas or full stops) is removed from the address field.
Click on the Post code radio button to select the post code option.
The browser will display only those customer records with blank Post Code fields.
The Use column will move to be beside the Post Code column.
Post code extraction consists of two steps, each step initiated by pressing in turn one of the top two Go buttons.

Step 1
·Click on the top Go button.  
The system will extract the last possible post code of the third Suburb/Town field to the Post Cod field and tick the Use column.  
·Scroll through the browser and untick (by double clicking on the checkbox) those records you do not want to update (e.g. where phone numbers have been stored in this field). Unticking the Use field will clear the Post Code field. If you make a mistake you can reverse it by double clicking the checkbox again; the Post Code field will be re-populated.  
·You can use the right mouse menu to tick all or untick all records and also to untick all above (or below) the currently selected record. This is useful if you only want to work on a portion of your database at a time.  
·Once you are ready click on the Update Customer Master button. This will save your changes to the customer master. Those records that have been updated will disappear from the browser, leaving only those records still to be done.  

Step 2
This step is the same as the step 1 except that the post code is extracted from the second address field.
·Click on the middle Go button to extract the post code from the Address2 field.  
·Proceed as in step 1.  

State extraction
The first two steps extract the state (e.g. NSW) from first, the third address (shown in the Suburb/Town column) and then the second address field. You may wish to do the steps in the reverse order if most states are recorded on the second field.
The third step uses the post code field to calculate the state. As state fields are usually optional you may not wish to use this option at all. Also remember that this option will not extract the state from the address fields, as the first two steps do.
In the first two steps, the system checks for the characters listed in the 'Search For' box at the top of the window. This defaults to the standard abbreviations, Vic, NSW etc. You can add to this list in the 'Add State and Search Criterion' box. In the state field type the state's abbreviation e.g. TAS (use upper case) and in the Search For field type the search string e.g. Tasmania (case unimportant). Press the Enter key to add it to the list.
The system will only extract characters whose preceding and trailing characters are a space, a comma or a full stop.
When the changes are saved, the customer master's state field is updated and the search string code (along with preceding and trailing spaces, commas or full stops) is removed from the address field.

Step by step guide
·Click on the State radio button to select the state option.  
·The browser will display only those customer records with blank State fields.  
·The Use column will move to be beside the State column.  
State extraction consists of three steps, each step initiated by pressing in turn one of the Go buttons.

Step 1
·Click on the top Go button.  
The system will extract the last possible search string of the third Suburb/Town field to the State field and check the Use column.  
·Scroll through the browser and untick (by double clicking on the checkbox) those records you do not want to update. Unticking the Use field will clear the State field. If you make a mistake you can reverse it by double clicking the checkbox again; the State field will be re-populated.  
·You can use the right mouse menu to check all or uncheck all records and also to uncheck all above (or below) the currently selected record. This is useful if you only want to work on a portion of your database at a time.  
·Once you are ready click on the Update Customer Master button. This will save your changes to the customer master. Those records that have been updated will disappear from the browser, leaving only those records still to be done.  

Step 2
This step is the same as the step 1 except that the state is extracted from the second address field.
·Click on the middle Go button to extract the state the Address2 field.  
·Proceed as in step 1.  

Step 3
The last step calculates the state from the post code field.
·Click on the bottom Go Button.  
·Proceed as in step 1.  
·Any records not updated will need to be changed manually in the customer master.
