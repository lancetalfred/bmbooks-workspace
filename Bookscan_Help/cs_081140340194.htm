Posting invoices
If you have selected Auto Post GRNs in System Options, invoices are automatically posted to accounts payable during receiving.
If Auto Post GRNs is not selected all invoices and credit notes have to be entered manually as described below.

Manual Invoices
Note that if Auto post GRNs in system options has been selected, invoices are automatically posted here during receiving.
In that case the manual invoice entry allows you to enter an invoice raised externally.

Step 1:
From the main menu, click on Creditors and then click on Transactions.

Step 2:
In the Creditors Transactions window, select a supplier by either:
·typing the supplier key in the Supplier box.  
·clicking the button and scrolling through drop-down list, or  
·clicking the button and using the Find window.  

Step 3:
Right click anywhere in the window and select Invoice (or Credit) from the drop down menu.

Step 4:
Enter the customer's Reference number , the Transaction amount and a Description of the transaction.
Click OK.


Credit notes and journals.
Manual credit notes and journals are handled in exactly the same way as manual invoices except that, instead of Invoice, you select Credit, Debit Journal or Credit Journal from the drop-down menu.
· Journal Credits can be applied against any outstanding debit.
If no debit is selected, these entries appear on the account as unapplied credits.
· Journal Debits can be applied against Credits, Journal Credits, or any unapplied payments.
