Catalogues
Previous  Top  Next

This module is an aid to users who are putting together catalogues or promotional material. It allows the user to create lists of products and then export the list (and a selection of product fields) as a comma-delimited file (csv file) for importing into other programs such as Excel or Word. The window provides plenty of shortcuts for assembling your lists and you can also save the list as a dbf file fro later use. You can add an unlimited amount of text against each title and automatically import text from either the title abstract field or from a blurb imported from the publisher.

Using the Catalogue window

Open the catalogue window from the main menu - select Modules/Catalogues.

Building a list of products
There is a variety of ways to create a list of products.

Import from a department, category, subject or imprint
Select a department category, subject or imprint in the appropriate combo box on the left side of the window.
Click on the Add to Browser button.
The products will be added to the browser. The program will check for items already in the browser, so you don't have to worry about duplications.
If you change your mind (before you add the products) you can clear the combo box fields by clicking the Clear Combos checkbox.

Adding product one by one
Add products by entering the barcode (or using one the standard shortcuts) in the barcode field.
You can use the F2 button to search for a product and the Recall (Alt F2) button to load the last used product.
Again, the program will ensure you don't duplicate a product in your list.

BestSellers
You can calculate what your best-selling products are and add them to yuor list.
Click on the Best Sellers button. This will open the Create Best Seller List window.
Select the sales date range you require.
Click on one of the radio buttons to select either best sellers by quantity or your most profitable products.
Enter the number of records you want to import.
Click the OK button.
The best sellers will be added to your list.
Again, the program will ensure you don't duplicate a product in your list.

Product data

When you add products to your list the following fields are copied from yuor master file:

Product code (ISBN)      Title         Author
Binding            Selling price      Abstract*
Jacket path         Imprint         Dimension (eg 250 x 150 x 25mm)
No of pages         Release date      Publisher
Subject

If you already have a list, you can update it for any changes in the title master (except for the abstract and product code fields). Just click on the Update from Master button to perform the update.

*In your catalogue file there is a text file where you can store any text about the product that you wish. When adding products to the browser you can choose to automatically fill this text field from either the abstract field on the Catalogue tab on the title master or from the Blurb/Reviews field on the Publisher tab or from neither of these.The Abstract combo box you can set one of the following:
      None (don't load any abstracts)
      Use master abstact
      Use publisher review
      Publisher review if no master abstract
      Master abstract if no publisher review.
The combo box will be set to whatever you used last time (on that computer).

Editing the abstract field
Double click on the Abstract column of the browser.
The Catalogue Abstracts window will open. This will display the title master abstract and the blurb/reviews field from the publisher tab in the top text fields. The lower text field displays the catalogue file abstract.
You can append or overwrite the catalogue file abstract by clicking on the Append or Overwriet buttons.
You can also just type in (or cut and paste) any text you want.
Click on the Save button to save youy cahnges to the Catalogue file. To discard yuor changes click the cancel button.
Note that any changes you type in the upper text fields are not saved back to the title master.

Saving and loading files

Saving a catalogue list
Once you have assembled a list of products you can save it for later use.
Just click on the Save List button and save the file as you would for any Windows file.
The file will be saved with an extension of .dbf.

Clearing the Browser
To clear the browser, click on the Clear Browser button. warning - any unsaved data will be lost.

Loading a List
To load a list click on the Load List button and navigate to the dbf file you wish to open (not the csv file!).
You may need clear the browser first before the Load List button appears.

Export field selection
You can select which of the fields (listed above) that you wish to export to the csv file. The default for new users is all fields; teh program will then remember which fields you chose last time (on that computer).
Click on the Field Selection button. This will open the Field Selection dialogue window.
Use the arrow buttons or double click on a field name in the one of the list boxes to select ot deselect it.
Click Save to save your changes or Exit to discard your changes.

Creating the CSV file
To create a comma-delimited text file, click on the Export button and save the file as you would for any Windows file.
The file will be saved with an extension of .csv.
