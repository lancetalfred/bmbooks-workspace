Web Orders - e-Web

Web orders are picked up from your web site by Bookscan's e-Comms program. e-Comms stores the orders in the Bookscan database and displays them in the Web Orders window. From the Web Orders window you can manage your web orders, processing them without re-keying.

SETTING DEFAULTS
Prior to downloading orders from the web site, you my choose to map the web site transaction types to Bookscan types. This only takes a few minutes.
Open the Web export window, open the context menu, (right click), and select "Set Defaults". Then click on the "Web transactions" [F11] button to open the following window:

Enter each of the transaction types in the order they are displayed on your web site. The numbering and order are important.
Those transactions that are made through a gateway on your web site must have the gateway checkbox ticked.
Where relevant, transactions should be mapped to Bookscan tender types.

WEB ORDER PROCESSING
The Web Orders window is opened from the main menu: Sales/Invoices /Web Orders.


There are three views which can be selected in the Filter radio button group:
·Awating stock - if the order is waiting for stock it will be displayed here.  
·Require payment - if a credit card payment is yet to be processed the order is displayed in this view.  
·Ready to invoice - orders where the stock has been received and the payment processed can be invoiced in this view. Users of the warehouse module would probably want to use the picking and packing window rather than this view.  

Awaiting stock
Orders waiting for stock it will be displayed in the "Awaiting stock (F4)" view. This option is for viewing only and has no processing function. As backorders and special orders are released, orders will move out of this view.

Processing payments
Orders waiting for a manual credit card payment is to be processed are displayed in the "Require payment (F5)" view.
(If payment has been taken on the web site via a credit card gateway or via PayPal, the order will be displayed in the "Ready to invoice" view).

MOTO Payments
If your EFTPOS provider suppprts MOTO payments (where you can type the credit card details into the EFTPOS machine), select the "Tendering window (F8)" option in the Payment Method box. When you click the Take Payment (F12) button the Tendering window will open and you can process the credit card in the usuual way.

Other payment methods
If you are procesing the card payment my other means, select the "EFTPOS payment (F7)" option. The default tender type is be displayed in the combo box just above this radio button. You can change the tender type here if you wish.
Click the Take Payment (F12) button to mark the payment as taken.

To have the invoice be created as you take the payment, tick the Invoice when tendering (F9) checkbox. Otherwise the order will be move to the "Ready to Invoice" view.
For users of the warehousing module, the order, after taking payment, be displayed in the Picking window.

Invoicing
Orders waiting is to be invoiced are displayed in the "Ready to invoice (F6)" view. To invoice orders, simply select them in the left browser and click the Invoice (F12) button.
