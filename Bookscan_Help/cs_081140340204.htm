In cash sales:

The Singles button (F9) option is at the top of the cash sale window.

Clicking this button will mean you do not need to press the Save button after scanning each line. The quantity will default to one.
This can help speed up entering a cash sale when there is only one of each of several items.
To change the quantity or apply a discount, you will need to double click on the line in the browser to re-load it into the edit line.

When this option is on, the following line is displayed above the quantity field.
      
To turn the option off click on the Multiples button.

The default setting is to have this option off.
