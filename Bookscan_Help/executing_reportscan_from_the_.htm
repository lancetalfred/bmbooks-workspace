Executing Report Writer From The Command Line

Certain reports can be obtained from Report Writer programatically (e.g.: from a batch-file). This enables Bookscan users to take "single-click" advantage of Report Writer's superior report-presentation whilst continuing to enjoy the benefits of a POS system running under Windows. The command-line structure uses the following conventions:

< x:PathToProgram >\Report Writer.EXE \<ReportIdentifier> \<Parameter1> \<Parameter2> \<Etc.>

Omit the angled brackets from the actual command line. And only supply the parameters that a particular report (see links below) requires. Values within the angled brackets are place-holders for values which must be specified in order to run any particular report. The reports able to be run by these means include:   Reprint Invoices,   Transfer Reprint,   Special Orders By Customer,   Special Order (Particular), Purchase Order Number.
