Browser Fields
Pos
Position, from the left, in the tendering window where the transaction type button will show.
You can change the position of a transaction by doulble clicking on it in this column. Moving up or down is determined by the setting of the radio buttons at the bottom right of the window.

Code   
Abbreviation for the transaction used by the system. E.g. CHQ for cheque.

Description  
Full Name of the transaction. E.g. Visa.

NCD
No cash drawer. Stops the cash drawer from opening during a counter sale.

EFTPOS
EFTPOS transaction.

CO
Allow cash out in EFTPOS transactions

Type
Options are:
·Standard  
·Require name - a standard transaction but in the Tendering window the operator has to enter a name or code against the transaction.  
·Tracked voucher - tracked vouchers, numbered & stored in the system  
·Untracked Voucher - an untracked gift voucher worth the amount recorded on it  
·Cheque  
·Instant Rew. Vou. - If using the rewards at point of sales, this will allow use of the customers current reward or part thereof. If they only use part, they may fall below the threshold set in the reward program & be unable to redeem the rest until they once again reach the minimum. This option will cause the tender type to appear at the far right of the tendering window regardless of the number of tender types.  


Surch
Used for applying surcharges on credit cards.

RO
Rewards voucher. A voucher issued by generating customer rewards through the rewards program.

Hide
Obsolete transaction type, will not display in the Tendering window, but is available for transaction history reports.

   
 

Default tender types
There is the ability to set which tender types are used by default in areas of Bookscan. You can set these for Cash Sales, Order Processing (Invoiving, Special Orders) and Debtor Payments. Set these by selecting what they are via the drop-down list in System Options - Financial tab.

Click OK button to save the settings.
