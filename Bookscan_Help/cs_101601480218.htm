Academic Module  
 Previous  Top  Next


The Bookscan Academic module is used to assist in calculating order quantities for textbooks used in school, college and university courses.
It allows you to keep track of the following data:
Lecturers and the courses they teach
Textbooks and other materials used on the courses
Student numbers for these courses.

Summary of the Academic module procedures   
Setting up a course
Attaching lecturers to a course
Maintaining student numbers and rolling over figures at year/semester end.
Course texts -adding and editing
Placing orders
Academic reports

Course Details
An existing course can have been selected either from the drop-down list of the Select Course combo-box or by using the Find Course By Lecturer button.
The course details are displayed in the various fields.

Course History
In the Rolls box the history of student numbers for the course is displayed
Next to the faculty Phone number field is a combo-box by which you may choose to view either five or ten slices of history (these slices are nominally referred to as years but the figures can be rolled with whatever frequency is desired).
When the course is being set up, you may enter as much historical information as you prefer. From that point forward, each time the course information is rolled the existing data will move one column to the right.

Lecturers
The list of lecturers attached to this course is displayed and edited by clicking on the Lecturers (F5) button.

Course Texts
The textbooks set for this course are displayed in the browser.
Current set texts are displayed on a white background, recommended titles on yellow and deleted titles on cyan.
To edit any of these lines double click on the line in the browser. The browser will then be hidden and the titles detail fields displayed.
To save your changes and return to the browser view, click on the Save Text (F9) button.
You can also scroll through all the texts using the Previous (F11) and Next (F12) buttons. When you use these buttons any changes you make to a text will be saved.
To discard any changes, click on the Cancel button (or press the Escape key )

Buttons
Add Course (F3)Add a new course  
Delete Course Delete a course  
Edit Course (F4) Edit a course's details  

Lecturers (F5)To display or attach lecturers to the course.  
Edit Rolls (F2)Edit the course's student numbers and history.  
Title Details (F2)To display the master record of the selected title. The Courses tab of the master record can be used to show all courses on which the title appears.  
Marketing (F7)An on-screen report of sales by marketing type for the currently selected title.  

Add Text (F9)To add text(s) to the course.  
Delete TextTo delete a text from the course.  
Order Text (F11)To transfer current order values to the Draft Purchase Orders or to zero the current order values. Items added to the Draft are left on hold and show a source of "Te".  
History (F8)An on-screen report of the currently selected title's sales history.  

Right mouse options
Edit Rolls Edit the course's student numbers and history.  
Add Course Add a new course.  
Change Course Code Change the course code of the currently selected course.  
Delete Course Delete a course.  
Reports Print one of the 5 available Academic reports.  
Period Sales DisplayDisplay a floating window of the currently selected text's sales history.  

End of Year RolloverRoll over the student numbers and history at year end.  

Show all items Have the browser display all texts for a course.  
Hide dropped items Have the browser display only current texts.  
Show only dropped Have the browser display only dropped texts.
