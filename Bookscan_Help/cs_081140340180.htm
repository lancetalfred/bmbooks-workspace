This window allows you to set various system options and allows you to access purchasing budget figures.


Subsidy Module
This module is used for those who have items that can be subsidised, such as government rebate text books, or even used for staff discounts.
This module can only be used if activated by Barcode Solutions.
For information on setting up the Subsidy module and using it, click the link.

Other settings
·Enquiry key length: This field determines how many characters the title master field is indexed on. The usual number is 25.  
 
·Lines per page on pre-printed invoice forms: This field determines how many lines will be printed per page on invoice forms.  
 
·Customer key length: Set the length of the alpha part of the customer key. It is usually set to 5. The maximum is 8.  
 
·No Auto Numbering for customer key: As customer keys are created, the program adds a number (usually three digits) to the end of the alpha section of key –which is usually the customer's surname. So when creating your 53rd customer called Smith, the customer key becomes SMITH053. Setting this flag turns this auto-numbering off.  
 
·Shopper key must be unique: When creating a new customer, the shopper key is checked for uniqueness.  
 
·Bookscan style address: This legacy setting can be ignored by almost all users. (This legacy setting can be ignored by almost all users.)  
 
·Browse with lines separating rows: Display lines between rows of the title, customer and supplier masters.  
 
·Legacy account exports: This legacy setting can be ignored by almost all users.  
 
·Academic with Semesters: Used by universities that use semesters for their courses.
