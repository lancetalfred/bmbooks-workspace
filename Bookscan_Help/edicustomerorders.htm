EDI customer orders (Wholesale)

Customers can place orders with you electronically using the Pacstream service. See the EDI chapter for details about setting up Pacstream. Using EDI orders will save re-keying and reduce the number of order entry errors, saving you time and money.
Customer EDI purchase orders are received from Pacstream using Bookscan's e-Comms program. e-Comms stores the orders in the Bookscan database tables and Bookscan displays them in the Incoming EDI Purchase Orders window. From this window you can manage your orders, processing them without re-keying, via the Order Entry window.

PREPARING EDI ORDERS



·The upper browser displays all the outstanding EDI order header details – the customer code, unique EDI number, and their order number and date. Other columns relate only to Coles Myer orders.  
·The lower browser shows the items ordered.  
·To view the order header details, select a line in the upper browser and click the Show Details (F7) button (or just double click on a line in either browser). The customer details will display, hiding the upper browser. Click the Resume (F7) button to go back to the previous view.  



·By default the selling price to be used in the invoice is that shown in the Order Price column and the New Price showing as zero will be ignored. If you enter a non-zero figure into the New Price field, that price will be used in the invoice.  
·Order lines where the order price is different to the order price are colored red.  
·You can change all the prices in at order using the radio buttons in the Pricing Calculations group. Select the calculation type and click the 'Apply to all items' button. The new price will be displayed in the browser.  
·You can edit an individual order line by double clicking it in the lower browser to load it to the edit line. Enter your changes and click the Save Line (F12) button.  
·To cancel an unprocessed order click on the Cancel PO (F9) button.  

INVOICING EDI ORDERS
For the distributor/publisher configuration, a picking slip will be created. For the retail configuration, it will be an invoice.

To invoice the order, click on the Invoice PO (F8) button. The Order Entry window will open with this order filled out.



Make any amendments that you wish to the order header information and then click on the Save (F12) button. The browser, with the order lines filled in, will now be displayed.



Make any amendments that you wish to the order lines and then click on the Finalise (F12) button and the Order Entry Footer window will open.



·Add any other information such as comments, freight, invoice terms, payments etc.  
·Click on the Post (F12) button to create the invoice (or for the distributor/publisher configuration, a picking slip).
