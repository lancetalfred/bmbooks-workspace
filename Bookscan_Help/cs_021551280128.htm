Enquiries - Quotations and Pro Formas  
 Top 


From the main menu, click on Sales, then point to Invoices and then Quotes/Pro Formas.

Search Methods
Enquire by transaction number
In the Trans No field, either type in the quotation or pro forma number or select one from the drop down list.

Enquire by customer
Select a customer in the Customer box.

Actions

Delete Transaction
Select a transaction line in the browser and then click on the Delete Order (F4) button to delete a transaction.

Delete Record
Select a transaction line in the browser and then click on the Delete Item (F5) button to delete a line from a transaction.

Reprint
Select a transaction line in the browser and then click on the Reprint (F6) button to reprint a transaction.
