The bindings section of Bookscan allows for the storing and maintaining of the bindings you wish to contain within your database. These bindings can be included in the details of a title. To maintain the bindings click on Tables,then point to Authority Tables and then click on Bindings



To be ONIX compliant:
To load and use the ONIX compliant bindings, press the F12 key on your keyboard, then click Yes. This will load all the ONIX bindings automatically. Using the correct ONIX bindings will enable this to be correctly applied to any titles imported/updated from Title Page.
If you do not have the ONIX bindings, when you import titles from Title Page, it will leave the field blank for these titles. Alternatively, you can use your existing bindings and map them to ONIX codes by double clicking on the binding or selecting one & clicking on the Edit (F4) button as per the Edit entry below.

To manage the bindings: (custom bindings/become ONIX compliant if currently not or to not be onix compliant. Use the following)

Add
To add a new binding click on the Add button.
Next fill in:
Code (2 characters)
Name
Group classification (Select from drop down) optional
ONIX code (select from drop down) optional

Click the OK button.

Edit
To make changes to an existing binding, click on the binding and click the Edit button. You can make changes to:
Name
Group classification (Select from drop down) optional
ONIX code (select from drop down) optional

Click the OK button.

Global
To change all items marked as one type to another. E.g. Code AA to Code BB.
Note: Must be existing codes.

Click on the binding you wish to change from.
Click the Global button.
The from Code will be displayed in the Absorb Binding Code field.
Type in the code you wish to change it into in the Into Binding Code field.
Click the OK button.

Delete
To remove an existing binding click on the record.
Then click the Delete button.
Then click Yes.

Close
To close the bindings section click on the Close button.
