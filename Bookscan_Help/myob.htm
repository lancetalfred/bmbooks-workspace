Introduction: exporting Bookscan accounts to MYOB

You can export all transactions created in Bookscan to MYOB standard edition V17 onwards. It only takes about 10 minutes to set up Bookscan for MYOB export. The steps are outlines below. Once set up, you can export daily weekly, monthly or whenever you choose. Exporting should only take a few minutes.

During the export the following types of transactions are totaled and journals are created for import into MYOB:
·POS sales  
·Laybys  
·Layby deposits, deposit refunds and payments  
·Special order deposits and refunds  
·Special order deposit redemptions  
·Debtor payments and refunds  
·Cost of goods sold  
·Invoices and credit notes (if you are not exporting them individually).  
·Purchases and credit claims (if you are not exporting them individually).  

If you are not using the Bookscan creditors option, you can export your supplier invoices and credit claims individually rather than as totaled journals. In this case you will also need to export your supplier cards into MYOB.
Similarly if you wish to handle debtor payments in MYOB rather than in Bookscan, you can export your customer invoices and credits individually rather than as totaled journals. In this case you will need to export your customer cards into MYOB.
You can set one or both of these options on the Financials tab of System Options.

Important note
For the export of purchases you will need to have the correct invoice totals and GST for supplier invoices. These can be entered in several places:
·First page of the Receiving window  
·The final window when posting received items into stock.  
·The Good Inwards History window: this is a new window for version 5.00.00. To open it, select Purchasing/Incoming/Receiving history from the main menu. Double click on a line to edit the invoice details.  
·The Creditors window: Select "change invoice details" from the context menu.  

Export methods
There are two methods of exporting into MYOB:

1. Exporting directly to MYOB
Exporting directly to MYOB is faster and safer than using manual files. The cost of this service is including in the Bookscan accounts export license - there is no extra charge.

2. Exporting via csv files
To set up this option just click on the Create CSV import file radio button and then select the path for the csv files in the file path field.
