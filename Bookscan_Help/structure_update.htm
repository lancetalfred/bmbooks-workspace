Structure Update
Previous  Top  Next


The Structure update is what takes place when changes have been done to the systems database structure, typically when new versions are installed. When new versions are installing, upon opening Bookscan for the first time this will run automatically.
Ensure that all terminals are back to the main menu.
Running this allows for these changes to be made to you existing database to reflect the new structure.
Running this can also be used to repair problems with the database where the structure has been affected.

To run a structure update on the main menu click Utilities/Database Utilities/Structure Update, click OK, Click Yes.

This will then run the update.

Note: A structure update can take some time depending on database size. The time can be reduced by regular purging of un-necessary records and also regular 'Packing' of the data files.
Note: Running a structure update will also run a re-indexing on the database too.
