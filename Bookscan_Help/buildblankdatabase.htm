Build Blank Database
Previous  Top  Next

The Build Blank Database function allows you to create a 'blank' copy of your database to use at another site. This is handy if you are opening a new branch of your business or wish to create a blank copy of your database to send to someone else.

What does a 'Blank' database contain;
·Titles (Including Names, Authors, suppliers, prices, publisher details, categories, department, abstract, comments)  
·Customers (Including Names, Addresses, Phone numbers, email address, financial details)  
·Suppliers( All details, except stock movement/history)  
·Bindings  
·Currencies  
·Imprints  
·Departments  
·Location  
·Publishers  
·Return Codes  
·Sales Reps  
·BIC Subjects  
·Transport  

What does it not contain:
·Titles (Sales/Purchasing/Layby/movements/approval/backorders/consignment/specials history, stock figures[all])  
·Customers (Specials, laybys, backorders, purchases)  
·Suppliers (Stock movements/history)  

Creating a Blank Database
To open the Build Blank Database, got to the main menu and select Utilities/Database Utilities/Build Blank Database.

Select a path to save the copy of the database to.
Click OK button. The time to run will depend on the size of your master files.
When finished a message 'Process Complete' will display. This should say '15 database created'. Click OK.
Click Cancel.



Using the Blank Database
To move the newly created blank database you will need to burn it to a CD/DVD and take/send it to the new site. Copy this folder onto C:\ of the server machine. Bookscan at this new site will need to be installed and point to this folder as the data directory.

If you are giving the blank database to another store and you wish to not pass on your customer details, simply go into the blank databases folder delete the files 'Customer.dbf' and 'Customer.fpt'. The same can be done for your sales Reps also, but following the same process.
