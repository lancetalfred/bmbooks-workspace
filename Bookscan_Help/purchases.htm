If you are not using the Bookscan creditors option, you can export your supplier invoices and credit claims individually rather than as totaled journals. You can set this option on the Financials tab of System Options. In System Options you can also select whether to export your credit claims as 'orders, or 'bills'. Check your MYOB documentation to see which suits your MYOB set up.

Supplier invoices, credit claims & suppliers
If you have selected "Export purchases individually" in System options, an extra tab, Purchases & Suppliers, is displayed in the MYOB export windows.

Setting up for first time use
You will need to export your supplier cards to MYOB first. First, flag any suppliers you do not want to export by clicking the 'Exclude from account export' checkbox on the Detail tab of supplier tab.
Next load all the unflagged suppliers into the browser: right click the browser and select Load all cards into browser. Then click the Export Suppliers button. This will create the export file SuppCardsYYYYMMDD.txt in your MYOB export file path.
Importing in MYOB is almost the same as outlined above in "Importing into MYOB":
·Open MYOB. In the MYOB main menu, select File\Import date\Cards\Supplier cards. This will open the Import File window.  
·In the "Import file format" combo box, select "Comma-separated".  
·In the "First record is" combo box, select "Data record".  
·Click the Continue button.  
·In the next window that opens, navigate to the file path you select earlier and select the SuppCardsYYYYMMDD.txt file. Then click the Open button.  
·In the Import Data window that now appears click on the Match All button. Then click the Import button and you are done. You may now wish to move the text file to a new folder, and re-name it, to prevent it being accidentally imported a second time.  
When new suppliers are added to Bookscan they will appear in the Supplier Export browser. You should export these to MYOB before exporting the purchases and credit claims.


Exporting purchases and credit claims
In the Purchases & Suppliers tab, the top right group box is Purchases export. This displays the date of the oldest transaction ready to be exported ('Start Date') and the date of the latest transaction ready to be exported ('End Date'). You can change the dates of the export to what you require (say, to the last month's transactions).
Note: MYOB will not import data dated before its lock date. You can enter the lock date here to ensure transactions dated prior to that date are re-dated so MYOB will import them.

Press the Load Purchases button. This will load the Purchases/Claims browser. Transactions whose supplier is not marked for '"no account export' will show a tick in the Use column. Only these records will be exported to MYOB. (The other records will be marked as 'not for export' after you click the Send to MYOB button). You can toggle the Use column value by double clicking it.

Importing into MYOB
Using the direct method
Press the Send to MYOB button.

Using the manual csv file method
Press the Send to MYOB button to create the PurchasesYYYYMMDD.txt file.
Importing in MYOB is almost the same as importing journals into MYOB:
·Open MYOB. In the MYOB main menu, select File\Import date\Purchases\Service Purchases. This will open the Import File window.  
·In the Import file format combo box, select Comma-separated.  
·In the First record is combo box, select Data record.  
·Click the Continue button.  
·In the next window that opens, navigate to the file path you select earlier and select the PurchasesYYYYMMDD.txt file. Then click the Open button.  
·In the Import Data window that now appears click on the Match All button. Then click the Import button and you are done. You may now wish to move the text file to a new folder, and re-name it, to prevent it being accidentally imported a second time.
