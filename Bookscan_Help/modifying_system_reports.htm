Modifying System Reports

To change a report, highlight it in the main selection window then click the Modify button. Only one user at a time can modify any given report.

Before you see the normal "Parameters" window (if the report has one) you will be presented with some information about the effect that any changes will have and what variables will be using the report-form's default settings. (NOTE: these defaults can be changed, to vary the preview's performance, without upsetting the runtime which, itself, overrides these particular defaults.)

Report Writer generates data for the report, as usual. This is so that you will be able to make modifications to the report-form without receiving messages about undefined data sources. If it generates an empty file it will give a warning before loading the report form (an empty file will usually emasculate the Print Preview available within the Designer).

You can modify the data displayed in the report, the font(s) employed, column-orders, spacings, titles and almost anything else
"fixed" about the report. Certain variables (other than the database values) can also be obtained by any report. And you can easily add a picture if you need a report to include the corporate logo or somesuch.

If you use Print Preview (on the File menu, whilst modifying the report-form) do not take the output literally. Although correct in most ways, it can be distorted by the report-form's Variables (which are not set to match the report data when in Modify mode). Run the report as usual to get a true picture.

If you have saved changes to the report-form and later wish that you hadn't, look on the Report Writer's File menu for: Restore Original Report Writer Report.
