If you wish to handle debtor payments in MYOB rather than in Bookscan, you can export your customer invoices and credits individually rather than as totaled journals. You can set this option on the Financials tab of System Options.

Customer invoices & customers
If you have selected 'Export invoices individually' in System options, an extra tab, Invoices & Customers, is displayed in the MYOB export windows.

Setting up for first time use
You will need to export your customer cards to MYOB first. First, flag any customers you do not want to export by clicking the "No account export" checkbox on the Detail tab of the customer master.
Next load all the unflagged customers into the browser: right click the browser and select Load all cards into browser. Then click the Export Customers button. This will create the export file CustCardsYYYYMMDD.txt in your MYOB export file path.
Importing in MYOB is almost the same as outlined above in 'Importing into MYOB':
·Open MYOB. In the MYOB main menu, select File\Import date\Cards\Customer cards. This will open the Import File window.  
·In the 'Import file format' combo box, select 'Comma-separated'.  
·In the 'First record is' combo box, select 'Data record'.  
··Click the Continue button.  
·In the next window that opens, navigate to the file path you select earlier and select the CustCardsYYYYMMDD.txt file. Then click the Open button.  
·In the Import Data window that now appears click on the Match All button. Then click the Import button and you are done. You may now wish to move the text file to a new folder, and re-name it, to prevent it being accidentally imported a second time.  
When new customers are added to Bookscan they will appear in the Customer Export browser. You should export these to MYOB before exporting the invoices and credits.



Exporting customer invoices and credits
In the Invoices & Customers tab, the top right group box "Invoices export". This displays the date of the oldest transaction ready to be exported ('Start Date') and the date of the latest transaction ready to be exported ('End Date'). You can change the dates of the export to what you require (say, to the last month's transactions).
If you have a multi store set up, you may wish to click the checkbox 'Add store code to invoice number'.

Press the Load Invoices button. This will load the Customer Invoices browser. Transactions whose customer is not marked for 'no account export' will show a tick in the Use column. Only these records will be exported to MYOB. (The other records will be marked as "not for export" after you click the Send to MYOB button). You can toggle the Use column value by double clicking it.

Importing into MYOB
Using the direct method
Press the Send to MYOB button.

Using the manual csv file method
Press the Send to MYOB button to create two files: the InvoicesYYYYMMDD.txt file and the InvoicesCOGsYYYYMMDD.txt file (cost of goods sold).

Both the text files need to be imported into MYOB. The process is almost the same as importing journals into MYOB:
·Open MYOB. In the MYOB main menu, select File\Import date\Sales\Service Sales. This will open the Import File window.  
·In the Import file format combo box, select 'Comma-separated'".  
·In the First record is combo box, select 'Data record'.  
·Click the Continue button.  
·In the next window that opens, navigate to the file path you select earlier and select the InvoicesYYYYMMDD.txt file. Then click the Open button.  
·In the Import Data window that now appears click on the Match All button. Then click the Import button. You may now wish to move the text file to a new folder, and re-name it, to prevent it being accidentally imported a second time.  
·For the InvoicesCOGsYYYYMMDD.txt file follow the same procedure for journal imports outlined in Importing Journals into MYOB above, except that you select the InvoicesCOGsYYYYMMDD.txt file.
