Draft Purchase Orders - Sales Based Replenishment
Previous  Top  Next


Using the sales based replenishment method, draft orders are generated in three ways:
·As special orders and backorders are generated, a draft order for the item is immediately created.  
·Draft purchase orders can be created manually in the title master, draft purchase order window and when creating a new title.  
·In the Draft Purchase Orders Generate window, you can batch create draft orders based on sales over a specified period or on sales since you last generated drafts. These draft orders have a zero re-order quantity. You will need to allocate a quantity against each line while processing it.  
 
After generating draft purchase orders in the DPO Generate window, you have a choice of processing them in the Draft Purchase Orders window or in the Generated Draft window. See below for details.

Draft Purchase Orders Generate window
In this window you can generate a list of products that have had sales in a nominated period. Open the window from the main menu: Purchasing/Draft Order/Regenerate.



There are two date range options:

Sales by date range
You would only use this option occasionally. It creates draft orders for each product sold between the dates selected. You would use this option for say, looking at what you sold leading up to last Christmas or last Father's Day.

Sales since last review
This is the option you would use regularly for your re-ordering. It will generate a list of products sold since the last review date. The default date and time is set to the last time the Regeneration was run. You can change this setting if you wish.

With both options, the system will generate sales and stock movement data for the last 13 months for each item with sales in the nominated date range.

WARNING - When you regenerate draft orders using the data range you will overwrite the draft orders with origins of Sa and Av.

Draft Purchase Order window
You can now use the draft purchase orders window in the same way as for the minimum order method, although the data displayed in the edit window is slightly different.

Note: the order quantity is set at zero for sales-generated draft orders. You will need to enter an order quantity for each line you wish to order.
.
For products where sales and stock movement data have been generated via the DPO Generate window, the edit window will display a browser showing a summary of the sales and stock movements over the last 12 months.



Clicking on the Show by Month button pressing the F7 key will toggle through the four different displays:
Stock movement summary
Sales by month
Sales for the last 14 days
Sales history
Clicking on the first column header in the browser will return to the original view.

Generated draft window
This window is an alternate way for processing your draft orders. While it gives much less data to work with, it is faster and simpler.
The window displays all draft orders generated using the DPO Generation window. Special order lines will show in this window also. They will appear as a white line (with a quantity already entered) when 'Show only zero order quantity (F6)' is not checked.

After running the regeneration, open the Generated Draft window from the main menu: Purchasing/Draft/Generate Draft.



The lines showing in Yellow are the lines that have not been reviewed (and still have a value of 0 in the Qty Ord field).

Note: Lines entered manually in the DPO window will not show here but will be included when you create the purchase order.

Reviewing the List
To review the list, start at the top.
·Click in the Qty Ord field, so it highlights the value.  
·Key the value you wish to order.  
·Press the Enter key on the keyboard, which then moves to the next line.  
·If you do not wish to order a line, when you come to it, you can click the Delete Line (F5) button, or use the F5 key on your keyboard, which will then move on to the next line.  

Note: The lines shown in this window are also available in the regular Draft Order window (Purchasing -> Draft -> Add/Change), with a Origin code of Sa. What this window allows is a fast way to review the list of regenerated titles only. Your manually added lines and Special order lines will still need to be processed as normal.

Show only Zero Order Quantity (F6)
If you wish the lines they have been reviewed (shown in white in the image above) to not show, simply check this option.

Finalising a draft purchase order
You can Finalise Orders in this window by using the Finalise Orders (F12) button. Alternatively you can do it from the Draft PO window. It both case the Finalise PO window will display and you can finalise your orders as outlined in the minimum order section.
