RETURNS TO SUPPLIERS

There are two situations where returns are done:

No fault returns
This is where stock has been supplied as "sale or return" and it is now time to return it. You can have the system generate a draft returns list of all such returnable stock. The system will automatically allocate the original invoice numbers and cost prices to each item on the Draft Returns List.

Other returns   
These are where stock has been either:
·wrongly supplied,  
·supplied damaged,  
·supplied with faulty printing or binding,  
·superseded by a new edition or  
·recalled by the supplier.  
These returns will need to be added manually to the draft returns list. You will need to allocate original invoice number to each item as you add it to the draft.

Returns to supplier - procedures summary

Generate the draft list
Create a list of draft returns in the Returns Generation window.

Groom the draft
Manually groom this draft returns list in the Draft returns window.

Pick the stock
Print the draft returns list for each supplier and use this to pick the stock.
Then edit the draft for items not found or in unreturnable condition.

Add other returns
Add wrongly supplied, damaged or faulty stock to the draft.

Returns authorisation
Print a Returns Authorisation Request for each supplier.

Return stock and post returns
When authority to return the stock is received, re-edit the draft, if necessary.
Post the return. This removes the items from stock and a credit claim is generated.
Return the stock with the credit claim to the supplier.
