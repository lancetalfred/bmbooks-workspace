Setting Up Pre-pack
Previous  Top  Next



Select System Options from the Utilities menu. (The option is grayed out if any other Bookscan windows are opened.)

Click the tab with the caption Modules and mark the Pre-pack check-box. This will enable the following controls:

Generate Item IDs automatically: When a Title is included in a book-list for the first time, it can be given an unique ID Number (some sellers call it a Stock Number) to provide a means of identifying it (more rapidly than having to data-enter the ISBN). Once this has happened, any ISBN-input will find that title if the ID-Number entered is prefixed by "<" (no quotes). Bookscan will generate sequential numbers if this option is checked, otherwise you will be prompted to enter your own each time one is needed.

Treat Students as Debtors: If you process thousands of students and don't want them to clutter your debtor reports, leave this unchecked! In the current version this setting only affects student identification in the customer table.

Reward Pre-pack Sales: By default, the customer-loyalty processes ignore sales made through pre-pack.

Discount for 2nd-hand in good condition: Defaults to 33.33%.

Discount for 2nd-hand in poor condition: Defaults to 66.66%.
