System Options - Counters
Top 


In this window, you can set the numbering sequences for your documents:
·Picking slips  
·Special orders  
·Laybys  
·Invoices and credit notes  
·Returns  
·Carton numbers  
·Sales transactions  
·Consignment advice notes  
·Approvals  
·Transfers  
·Receipts  
·Returns authorisations  
·Tickets  
·Quotations  
·Rewards vouchers: ensure that this sequence does not conflict with you tracked voucher sequences.  
·Journals  

The numbers displayed are the last numbers used.
To change the sequence, just overtype the number. Using the same numbers twice for the same counter can cause issues, so avoid duplicating numbers.
