Power Failure recovery

This is used when there has been a communication error between the PC & the EFTPOS pinpad. It will resend the data for the transaction to the pinpad to complete the transaction. If you have already manually run the transaction through the pinpad we recommend that you contact Barcode Solutions, and we will assist with clearing the stored data. (This is done by opening the registry editor & clearing the data held in the Barcode Solutions \ LastEFTTrans entry.)
