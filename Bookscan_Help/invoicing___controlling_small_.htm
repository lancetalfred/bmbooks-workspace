Invoicing - controlling small orders
Top 

Handling small orders
The cost of freight and invoice handling can make small orders uneconomic. To overcome this, Bookscan offers the following features to allow users to trap small orders and hold them until further orders have been received. As further orders are received from a customer, or as their backorders are released, the system checks the total value of the customer's order and when the values moves above the minimum, removes them from being on hold, allowing them to be processed.
Orders held this way can be monitored and controlled in the Picking window and can be manually taken off hold and if required, either a surcharge or a freight charge added.

System Options
On the Sales tab there is a Surcharge As combo box with three choices:
1.None  
Set this option if you wish not to use the minimum order features.  
2.Small order surcharge  
Select this option to hold orders that are below the minimum value or to apply a small order surcharge if they are to be released. If using this option, enter the Small Order Surcharge amount and Minimum Order Value in the fields below the combo box. For example you may set a standard surcharge of $7.00 on all orders below $60.00.  
3.Hold order below minimum  
Select this option to hold orders below the minimum value but not use the small order surcharge features. If using this option, enter Minimum Order Value in the field below the combo box.  
Also on this tab the Consolidate Pick Slips checkbox should be checked to allow the automatic linking of customers' picking slips..

Invoice Entry
The following features will only apply if you have selected either option 2 or 3 above.

Current order summary
After you have saved the header information and ISBN/Catalogue field becomes visible, a summary of the customers current orders is shown in the In Picking box. The information shown is for all this customer's unprinted orders for that are waiting to be processed. This items shown are:
   In picking   The value of all unprinted picking slips for this customer.
   Freight total   The total value of the freight charged on these pick slips.
   Surcharges   The total value of surcharges on these pick slips.
   Backorders   The total value of backorders for this customer.
This allows the operator to make decisions on charging freight or adding a surcharge.

Surcharges
Option 2
If you have selected option 2 for small order surcharges, you can add the surcharge by clicking on the Surcharge button. This is a toggle button. Clicking the button the:
   1st time   Adds the small order surcharge to Surcharge field
   2nd time   Sets the Surcharge field to zero and marks the order as Waive surcharge.
   3rd time   Removes the Waive surcharge Flag.
Orders flagged as waive surcharge will not be held if they are below the minimum.

Option 3
If you have chosen option 3 (hold orders below minimum), you can use this button to mark/unmark the order as Not to be held. Again orders that as so marked are not be held if they are below the minimum order value.

Posting orders
When posting orders the system takes into account the customer's current orders that are waiting to be processed when checking for orders below the minimum order value. If the value of the current order plus the customer's orders already in the system is below the minimum, a warning will be given to the operator that the order will be held, allowing the operator the option to return to the order entry screen to edit the order or to continue with posting the order.
If the current order brings the total value of orders for this customer above the minimum then the held flag will be automatically removed from all their current orders allowing the picking slips to be printed and the orders despatched. This is the principal advantage of this system - that releasing the orders is fully automated.
If the current order brings the total value of orders for this customer above the minimum and a surcharge has already been applied to any of the orders, the operator will be given the option to have the surcharges removed automatically (option 2 only.)

If the Consolidate Pick Slips option has been selected, then when posting, the current order will be automatically linked with the customer's orders already in the system.

Picking Window
The following features will only apply if you have selected either option 2 or 3 above.
There is now a Held column in the Picking window. This is checked for orders which are flagged as held because they are below the minimum order level. Picking slips flagged as held cannot be printed.

Taking orders off hold
Held orders are automatically taken off hold when other picking slips for customer are created, or backorders are released, to bring the total value of the orders above the minimum order value. To take an order off hold manually, double click on the checkbox in the Hold column. If you have selected option 2 (for small order surcharges) you will be given the option of adding the small order surcharge. If you have selected option 2 and no freight has been charged, you will be given the option of adding a freight charge.

Held Lines
There is now a button to show only held orders. This is a toggle button; clicking it the:
   1st time      Shows only held orders.
   2nd time      Shows all lines except held lines.
   3rd time      Shows both held and unheld lines.

Display mailorder customers
You can now display only mailorder customers. Right click in the browser to display the context menu and select one of the three options:
   Mailorder only   Shows only mailorder customers.
   Exclude mailorder   Shows only debtor customers   
   Show all      Shows both mailorder and debtor customers
Mailorder customers are now shown with a yellow background in the browser.

Improved linking
When authorising a payment in the picking window or applying a payment for a mailorder customer, the order will now automatically be linked the customer's other orders. At the same time a check is done to see whether any Held flags can be removed.


Backorder Release
New window
There is a new window for backorder releases with the following features:
It has a browser for displaying backorders. There are three methods of filtering the browser display:
·All backorders  
· By customer – display only backorders for the customer selected in the Customer field.  
·By product – display only backorders for the product selected in the Product field.  
 
Sorting the browser
Where all backorders are displayed, you can change the sort order by clicking on the appropriate column header.
   Pick # or date column      Sort chronologically
   Cust key or customer      Sort in customer key order
   Product code or Title      Sort by product code

Releasing backorders
Backorders are released by clicking on the Release (F12) button. Backorders will only be released for those lines displayed in the browser.
·So if you have displayed backorders only for a particular customer, then only that customer's backorders will be released.  
·Similarly if you are showing only backorders for a certain product then clicking on the Release button will release backorders only for that product.  
· If All Backorders is selected then a full backorder release will be done.  

Holding backorders
To prevent a backorder from releasing, you can set it to held by double clicking its checkbox in the Held column. To remove the flag double click on the check box again.
To hold all displayed lines, right click to display the context menu and select Hold All.
To remove the Held flag on all lines in the browser, click on the Remove Held button.
To remove the Held flag on all lines, not just those in the browser, check the Remove all Held checkbox and then click on the Remove Held button.
An example: you want to release a single line for a customer.
   Move the cursor to the Customer field and enter the customer key.
   Right click on the browser and select Hold All
   Double click on the Held checkbox of the line you want to release
   Click on the Release (F12) button

Linking
If the Consolidate Pick Slips option in System Options has been selected, released backorders will be automatically linked to any unprinted picking slips for that customer.
If the total value of these orders is below the minimum order value, the released order will be flagged as "Held."
If the released order brings the total value of the customer's current orders to above the minimum, then all the held flags will be automatically removed and the customers orders will be available for despatch..

Backorder reports
There are now three backorder reports that can be run from this window and from Bookscan Reports. These are:
   All Backorders ( sorted by either date, customer or product code).
   For a single customer.
   For a single product code.
To run the reports, select either the customer or the product to display them in the browser and then click on the Print (F11) button.
For all backorders, select the All Backorders option. If required change the sort order by clicking on the appropriate column header ( as outlined above). Then click on the Print (F11) button.

Handling backorders where there is insufficient stock
Where there is insufficient stock to cover all backorders for a certain product, you can limit the maximum quantity to be allocated to each order.
Select the product in the product field and then enter the maximum quantity you want allocated any order. Then click on the Release (F12) button.
