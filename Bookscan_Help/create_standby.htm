The Standby functionality of the Bookscan allows for terminals that have their databases remotely, (on a different machine on the network), to operate when there is temporary loss of connection to that database.

The standby functionality will activate when Bookscan is started and there is no connection to the database. It will prompt the user to initiate standby when this is the case.
When connection to the database is reinstated and Bookscan is restarted, it will also prompt the user to ask if they wish to transfer all transactions that took place while in standby back to the main database. If you choose not to, they will be stored and you will be asked again the each time Bookscan starts until they have been uploaded.

You can also choose to enter/exit standby by using the Utilities - Set/Unset Standby option. Again, when you exit standby, if any sales have been made, you will be prompted to upload them.

Preparing for standby
Running in standby mode can only work if preparations are made at regular intervals (Suggest weekly).
This preparing will create a copy of the titles, customers and suppliers etc currently in the database onto the local machine in C:\standby directory.

·To run the preparations on the main menu click Utilities, then click Create Standby.  
·Read the information.  
·Then click Start button.  
·This will then create a backup of the information required to run in standby mode, then run a re-index on the backup database.  
·When this finishes click OK button.
