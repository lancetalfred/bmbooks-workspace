Selection Controls

In choosing the parameters for a report you will be using fairly standard Windows controls - checkboxes, radio-buttons, combo-lists and edit-lines. A couple of spare observations may be of benefit...

Where lists are presented in an open (rather than a drop-down / combo) fashion you can usually make multiple selections, simply by mouse-clicking on multiple items. Click a second time to deselect an item. A button captioned "Select All" accompanies each multiple selection list and performs as you'd expect. If you use it, then the functional caption changes to "Deselect All", minimising your need to issue instructions.

Where date-input is availed, the edit control is post fixed by a button which opens a calendar control (wherefrom the full selection can be made by double-clicking on a date). Various means of navigation are provided within the calendar control. In the edit control, one component of the date is highlighted at a time. The plus and minus keys increment/decrement the selected component. The arrow keys select the next component (day, month or year). Experiment with all of the selection controls. They're the bulk of the interface!

Some of the edit-controls accept a partial value (e.g.: a partial title for the Titles On Hold report) and Report Writer will retrieve the remainder of the information as part of validating the parameters (in this case you'll need to click the OK button a second time in order to launch the report). Report Writer generally performs validation as soon as you click the OK button (to run the report). Read warning messages fully and you won't ever get stuck for long!
