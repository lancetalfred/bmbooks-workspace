Marketing Module  
 Previous  Top  Next

The marketing module is licensed functionality. Contact Barcode Solutions to purchase a license.

The marketing option allows you to:
·record the location your customers are from (usually by postcode, state or other grouping), and  
·record your sales against your promotional materials (the 'source').  
These are the standard customer breakdowns that people use but you can set any parameters you want.
At point of sale and in the order entry window, as an operator is finalising a sale, the Marketing window is displayed. Operators enter the Location or Source for the sale.
You can then print sales reports to monitor the effectiveness of your promotional campaigns and to see who you are selling to.



Setting up marketing

System options
In the Modules window of System Options you can set your marketing defaults:
You can choose to record sales by location or source or both. You can disable one or the other by using the respective Disable checkbox.
Once you have set up your locations and sources you can, you can set defaults in the Defaults combo boxes.
You can also choose where to force operators to make a selection and you can allow multiple selections per sale.

Setting up the sources
The sources are set up in the Marketing Source Codes window. This window is opened from the main menu: Tables/ Authority Tables/ Marketing/ Sources.



Add a source
·Click on the Add button.  
·Type in the Code (maximum 6 characters)  
·Type in the Name (maximum 35 characters)  
·Click the OK button.  
The source will be saved and displayed in the list.

Global change
You can absorb one source into another, deleting the original code.
·Click on a source in the list.  
·Click the Global button.  
·Type the new source into the 'Into Source Code' field.  
·Click OK button.  
·The old source code will be deleted.  

Setting up the locations
The sources are set up in the Marketing Source Codes window. This window is opened from the main menu: Tables/ Authority Tables/ Marketing/ Locations.



To set up the sources on the main menu click Tables, then move the mouse on Authority Tables, then Marketing, then click on Locations.

Add a location
·Click on the Add button.  
·Type in the Code (maximum 6 characters)  
·Type in the Name (maximum 35 characters)  
·Click the OK button.  
The location will be saved and displayed in the list.

Global change
You can absorb one location into another, deleting the original code.
·Click on a location in the list.  
·Click the Global button.  
·Type the new location into the 'Into Llocation Code' field.  
·Click OK button.  
·The old location code will be deleted.  

Using the Marketing module
Now in cash sales, laybys and invoicing, the operator will be able to select a Location and Source which will be recorded against the sale.
As the operator is finalising the sale, the Marketing pop-up window will be displayed:



What needs to be entered into the window will depend on you System Options settings. Assuming both locations and sources are enabled and there are no defaults:
·Select a Location by either typing in some of the Code to find the one you wish and double click on it, type in the entire code.  
·Select a Source by either typing in some of the Code to find the one you wish and double click on it, type in the entire code.  
·Click Select (F12) button. The Marketing window will be closed and the sale proceed as usual.  

Notes
·If you have disabled using either Source or Location in the System options, you will not be able to enter that field in the above window.  
·If you have set a default for one or both options, you can simply click Select (F12) button to proceed. If you wish the defaults can be overtyping or overwritten by double clicking on a different option in the browser. Setting a default will mean fewer key strokes.  
·If you have set the 'multiple types per sale' flag in System Options, the marketing window will appear as each line of the sale is saved. This option is for specialized sites – it would not suit a standard retail store.  

Reports
You can create reports to view performance by each of your marketing groups. Open the Marketing Report Parameters window in either Bookscan Reports or at Sales/Reports/Marketing.:



Parameters:
All items/ summary: display all sales or just total sales per marketing group
Date range: select the start and end date of your sales period.
Customer sales: setting this flag will report sales from the saleline.dbf file, otherwise the report is based on the sales history file.
Type: choose whether to report on your sales or your locations.
