The Transport section of Bookscan allows for you to maintain the different Transporters you can use within the system. (E.g. Australia Post)
To maintain Transport on the main menu click on Tables,then point to Authority Tables and then click on Transport.

Add
To add a new Transport method, click on the Add button.
Enter the following:
Transport Code (4 characters)
Transport Name
Default Carrier (Check box to select)
Cube Weight (Check box to select)
Weight (Check box to select)
No Consignment Notes (Check box to select)
Con Note Per Carton (Check box to select)

Click the OK button.

Edit
To edit an existing Transport method, click on the Transport and click the Edit button
You can make changes to:
Transport Name
Default Carrier (Check box to select)
Cube Weight (Check box to select)
Weight (Check box to select)
No Consignment Notes (Check box to select)
Con Note Per Carton (Check box to select)

Click the OK button.

Delete
To delete an existing Transport method, click on the Transport and click the Delete button.
Next click the OK button, and then click the Yes button.

Close
To exit the Transport section, click this button.
