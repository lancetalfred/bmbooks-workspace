Customer Master - Summary
Previous  Top  Next

Customer data is stored in the customer.dbf table. Customer details can be viewed in the Customer Master window which can be opened in many places throughout the program:
·From the main menu: select Tables/ Customer Master.  
·By using the 'person' icon on the toolbar (second from the right):  

 

·By using the F3 button in many windows in the program.  
 

·In many windows, clicking the Alt-F3 button, will load the last customer you used.  

Customer Master window
The Customer Master window has 10 tabs displaying different information about your customers:



Account details tabs
·Details - customer's key and name fields, and account flags.  
·Address – customer's addresses, phone numbers and email address.  
·Finance – for debtor customer's, the account details are displayed here.  
·Categories - shows all categories which contain this customer.  
·Abstract – a free text form where you can record your notes about the customer.  
·Contacts - shows all contacts listed for this customer.  
·List – contains a browser displaying all your customers.  

Sales tabs
·Specials - lists all current special orders for the customer.  
·Laybys - lists all current laybys for the customer.  
·Purchases - itemises all the customer's purchases.  
·Backorders - displays a list of titles the customer has on backorder (distributor/ publisher configuration only).  

Displaying tabs
To open a tab (or close an open tab), use the right mouse to open the context menu and then select the required tab. Alternatively, use the shortcut keys listed at the bottom of the window. E.g. Alt F5 (i.e. hold the Alt button down and press the F5 function key) will open (or close) the Specials tab.
On each computer, you can save which tabs you want to open by default. With the window displaying only the tabs you want, and with the tab you want displayed first showing uppermost, use the right mouse to open the context menu and then select 'Save as default view'.
Note: to speed up the opening of the customer master, it is best to only have the tabs you regularly use, open by default. Note that not all these tabs will be relevant to all users.

Tabs – detailed notes

Details tab
Key
The customer key is the field used to uniquely identify a customer. Usually the key comprises the first 5 letters of the surname (or company name) and a number generated by the program e.g. KELLY006. In System Options you can vary how the key is set up.

Change key
You can change the customer key here. Just click on the Change Key button: A pop-up window will open where you can type in the new key. The program will then update the more than 40 tables contains the customer key.

Frequent shopper key
The frequent shopper key is an alternate way for the users to identify a customer. The field is 16 characters and can be used to record a barcode if you are issuing customer cards to your customers. In the Find Customer window you can select the frequent shopper search and scan the customer barcode into the search field.

Names
Individuals
With customers who are individuals as opposed to companies, you should break down the customer name into parts: surname, first name etc. The full customer name is also stored in the Name field. (The Build Name button will build customer's name from the other name fields).
While it is not necessary to break down the name in to parts, it is very advantageous to do so. It allows for searches by surname and provides greater flexibility for customer merge and export files.
If you have imported a customer table from elsewhere without this name break down, there is a grooming tool in Bookscan to help you: see 'Customer Grooming' below.

Companies
For companies, you should enter the company name in the Surname field and the Name field. (The Build Name button will copy the surname into the Name field). Other name fields should be left blank.

Contacts
For companies, you can record your various contacts in the contacts table. The primary contact is displayed next to the Contacts F7 button. To view, add or edit contacts, click on the button. The will open the Contacts window:



Notes
·Use the arrow buttons on the left to navigate through the various contacts.  
·Use the arrow buttons on the right to navigate through the various addresses for this customer.  
·The main contact is set using the Main Contact (F8) check box.  
·To edit a contact, just start typing. The Add button caption will change to 'Save (F3)' and the Exit button to 'Cancel (Esc)'. Use the cancel button to undo any changes.  
·To add a contact, click the Add (F3) button. The fields will clear and you can type in the contact details.  

Holds
You can place a product on hold for a customer. To do this, click on the Holds (F7) button. This will open the Holds pop-up window which will display all products on hold for this customer.



Holding a product for the customer:
·If you want to print a Holds docket, ensure the Print checkbox is ticked.  
·Set a 'hold till' date.  
·Click on the Add Hold Item button.  
·In the pop-up window that opens, scan the barcode and press the Enter key.  
·In the next pop-up window that opens, enter the quantity and press the Enter key.  

Releasing a held product:
·Select the item in the browser.  
·Click on the Release Held Item button.  

Comments
You can enter a short comment about the customer that will display below the customer name in the various sales windows.
For very important comments, tick the 'Pop up comments' check box. In the POs and the Order Entry windows, a pop-up window will display, showing the comments, when the customer is selected. This will force the operator's attention.

Flags
·Debtor – set the customer as debtor customer. After setting this flag you should enter the account details on the Finance tab.  
·Student – this is for the pre-pack schools module only.  
·Mailorder – allows the customer to be invoiced through the Order Entry window but unlike a debtor, they will need to make a payment with the order. Use this flag to set up your web customers.  
·No statement – for debtors set them to not receive a statement.  
·Special order letters – set the program to print a letter when their special order comes into stock.  
·No backorders – in the order entry window, backorders will not be created where there is insufficient stock to fill the order (distributor/ publisher configuration only).  
·On shipment labels – a special setting for Coles Myer.  
·No account export – prevents the customer, and their transactions, from exporting to MYOB.  

Optional groupings
·Area – used to group debtor customers in the "all transactions" report.  
·Customer type – when using the pricing matrix, the settings allocated the customer to a discount group for each product. So product 9785464644644 may have a 47.5% discount for customer of type 'B' (distributor/ publisher configuration only).  
·Sales reps – the sales rep 2 field is used if you have a mixed book and music company where you have separate sales reps for books and music.  
·Commission rate – you can set your commissions for your sales reps by customer. Enter the percentage amount in the Commission Rate field.  

Address tab
The customer master allows for a single postal address and multiple delivery addresses. To add extra delivery addresses click on the Alternate Addresses (F7) button.



You can print a customer label by clicking one on the Print Label buttons.

Finance tab
The Finance tab displays account details for customer who are debtors:



·Bill to – if the customer is a branch or division of a company, you can have their invoices billed to a central customer key. Enter that key in the Bill to field.  
·Invoice sort order – some customers want to specify the sort order of their invoices. The choices are ISBN, title, author and natural (or 'as entered').  
·EDI - if the customer is using Pacstream, you can send electronic invoices to them. Tick the EDI checkbox and enter their Pacstream number in the text field.  
·Supplier number – if the customer has allocated you a supplier number you can enter it here. It will be quoted on their invoices.  
·Terms – set your terms of trade for this customer here.  
·Credit limit – for retail users the program will warn operators when the credit limit is being exceeded. In the distributor/ publisher configuration, customer over the credit limit will have their orders backordered.  
·Stop – setting a customer on stop will prevent their orders being processed in the Order Entry window.  
·No reward – customer is not eligible for any rewards schemes.  
·No auto allocation of credits – when crediting customers by appending either accredit note or a returns authorisation in to the Order Entry window, the credit will automatically allocate against the original invoice. To turn off this feature, tick the No Allocation checkbox.  
·Open item – when this flagged is ticked, the customer is set as an open-item debtor. When unticked, they are 'balance brought forward' debtors. The open-item setting is recommended. Here payments and credits are allocated are invoices making it easier to track accounts and settle account disputes.  
·Standard discount – the two Standard Discount fields are default settings for the pricing matrix.  

Categories tab
Customers can be allocated to categories for variety of purposes. If, in System Options, you set the program to track categories of purchases, then as customer purchase products they are allocated to the categories that product is in. For example, if the title 'Julius Caesar' is in categories 'biography' and 'history', a customer buying that title will also be allocated to those two categories. You can then use these customer category lists to create accurately targeted marketing campaigns. To continue the example, if you had an electronic brochure on biographies, you could load all customers from the biography category into the Mail Out window and have the program email the brochure to them.
You could also create a mailing list manually. You could create a category called say, Newsletter and add you newsletter customers to the category. Each month you could use the Mail Out to create mailing labels for these customers.
You can manually add or remove customers from a category in the Categories tab.
