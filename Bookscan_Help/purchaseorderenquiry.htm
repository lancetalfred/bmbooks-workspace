Purchase Order Enquiry
Previous  Top  Next


Purchase orders can be viewed in the Purchase Order Enquiry window. Open the window from the main menu: Purchasing/Final/Enquire.
Purchase orders can be viewed by either supplier or by PO number. From the window you can print various reports and amend or delete purchase orders



Looking up purchase orders by supplier
Select a supplier in the supplier box. The browser will display all the outstanding orders on that supplier.
The Supplier POs combo box will fill with just that supplier's purchase order numbers. Select a PO in the combo box and the browser will display the order.

Looking up purchase orders by number
Enter the required PO number into the All POs combo box lists to display it in the browser.

Consignment stock
Consignment stock lines on order are shown in the browser in yellow.

Summary Details:
·Value at cost/sell - shows the total value of the outstanding titles at cost/sell.  
·Items on order - total number of items not yet supplied.  

Editing purchase orders
Click on the edit button to display the various editing buttons. Alternatively, you can call these functions using the context menu. Most of the buttons are self explanatory but the function of the Edit Item and Edit All buttons is outlined below:



Edit Item
Highlight a line you wish to edit and click the Edit Item button. A pop up window will open:



Here you can edit the master comments and status, the quantity on order, the shipping date and the purchase order comments.

Edit All
To edit all lines in the browser, click the Edit All button. A pop up window will open:



Here you can edit the master comments and status, the shipping date and the purchase order comments.

Cancellation report
The cancellation report function will allow you to create a letter to the supplier canceling an order, either print or email that letter, delete the purchase order from the file and re-direct the order to the draft (if required).
Click on the Cancellation Rpt (F6) button, and the window will go into Cancellation mode, with 'Cancellations' displayed in red at the top of the window. Two columns, 'Cancel' and 'Select' will be added to the browser.



·To select a line to be cancelled double click on the Select column.  
·To change the cancellation quantity, double click on the Cancel column. A pop up window (see diagram above) will open where you can type in the new figure and click OK.  
Click the Print Report (F12) button. The report will print (and be stored for emailing by e-Comms) and another pop up will display



Make sure the report has printed correctly before proceeding. Clicking 'yes' will delete the lines from the purchase order. If you wish you can re-route the lines to draft purchase orders to re-order from a different supplier. Clicking 'No' leaves the order lines unaffected.

Enquiry Report
The enquiry report function will allow you to create a letter to the supplier enquiring on order. If in the supplier master, the supplier has been set up for emailing, the letter will be emailed by e-Comms.
Click on the Enquiry Report (F8) button, and the window will go into Enquiry Report mode, with 'Enquiry Report' displayed in red at the top of the window. A new column 'Select' will be added to the browser.
·To select a line to be enquired on, double click on the Select column.  
·Click the Print Report (F12) button. The report will print (and be stored for emailing by e-Comms).  

Special Orders
The Special Orders function will allow you to create a letter to the customer for whom a purchase order has been placed. Click on the Special Orders (F8) button, and the window will go into Special Orders mode. Only items which have special orders on them will be displayed in the browser. Two new columns will be added to the browser – 'customer' and 'select'. The customer column will display the name of the customer the item has been ordered for.

Alternate PO
If an alternate PO number has been added to an order it will be displayed in the Alternate PO field. The edit this number or add an alternate number, click on the Edit Alternate PO button. Alternate PO numbers relate to Leading Edge orders; see the Purchase Order import section below.

Reports
To view the available purchase order report, click on the printer icon on the main toolbar.
This will display the reports:
·Reprint - reprint a purchase order.  
·All - print a summary of all outstanding purchase orders.  
·Outstanding – print all POs placed with the currently selected supplier.  
·Back orders – print all POs on backorder with the supplier.  
·Back orders with (supplier) - print all backorders with the currently selected supplier.
