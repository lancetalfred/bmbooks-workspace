Step 1: Opening creditors
From the main menu, click on Creditors and then click on Transactions.



Step 2: Selecting a supplier
In the Creditors Transactions window, select a supplier by either:
·typing the supplier key in the Supplier box.  
·clicking the button and scrolling through drop down list, or  
·clicking the Seek (F3) button and using the Find window.  

On the right-hand side will be displayed the suppliers current, 30, 60, 90 and total purchases YTD.

Step 3: Transaction history
Click on Show History (F9) button to show completed transactions. This window is violet.
To return from history, click Show Current (F9). (The Current window is pink)

Step 4: Enquiry on invoice
To enquire on an invoice, double-click on line. This will display the Enquire On Creditor Invoice window (turtle green).
This window will display each line for the invoice, with the entire invoices details.
Close this window to return to Creditors Transactions.
Then either view a different invoice or return to step 2 and select a different supplier.

Context Menu

If you right click to bring up the context menu, there are useful functions shown.



1.Invoice               Create an invoice record if one is missing.  
2.Credit               Create a credit record if one is missing.  
3.Payment               Make a Creditor payment record.  
4.Debit Journal            Create a journal record to balance a excess credit.  
5.Credit Journal            Create a journal record to balance a excess debit or forgive a debt.  
6.Credit allocation            This opens the credit allocation window to assign unallocated credits or payments to invoices.  
Change invoice details         Allows you to adjust some of the details enterred when receiving the invoice, if required.
Supplier account utilities         Open the Account Utilities window.
Replace all due date         Replaces the Due Date of all invoices with the date you specify.
