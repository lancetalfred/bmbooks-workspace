Exporting to MYOB
Previous  Top  Next


You can export your Bookscan data to MYOB daily weekly, monthly or whenever you choose. Exporting should only take a few minutes.

When exporting from Bookscan to MYOB, the program will total all your various transactions created since the last export and create journals for them in MYOB. Fir invoices and purchases, you can opt to export the transactions individually if you wish.

Exporting accounts
·Exporting takes place in the Journals tab of the MYOB Export window.  
·Open the tab and you will see the top right group box 'Load from sales'. This displays the date of the oldest transaction ready to be exported ("Start Date") and the date of the latest transaction ready to be exported ("End Date"). You can change the dates of the export to what you require (say, to the last month's transactions).  
·Click on the Load button to load the transactions in to the browser. All transactions between the dates specified will be totaled and the journals to be created will be displayed in the browser.  
 
·Select the date you want for the journals (say, the last day of last month).  
·Press the Export Journals button and the export is complete.  

Effects of the export:
·Journals will be created in MYOB for each line in the Journals browser.  
·The MYOB chart of accounts will be updated.  
·The transactions in Bookscan will be flagged as exported.  
 
 
Using the manual csv file method
·The process is the same as for the direct export except that in the last step, pressing the Export Journals button will cause the program to create a single csv text file called JournalsYYYYMMDD.txt in the path you selected in the Set up tab. The file will comprise all the journals to be loaded into MYOB  
·Open MYOB. In the MYOB main menu, select File\Import date\General journal entries. This will open the Import File window.  
·In the "Import file format" combo box, select "Comma-separated".  
·In the "First record is" combo box, select "Data record".  
·Click the Continue button.  
·In the next window that opens, navigate to the file path you select earlier and select the JournalsYYYYMMDD.txt file. Then click the Open button.  
·In the Import Data window that now appears click on the Match All button. Then click the Import button and you are done. You may now wish to move the text file to a new folder, and re-name it, to prevent it being accidentally imported a second time.
