Pack Tables
Previous  Top  Next


Packing the tables is run to ensure that any files within the database that records that have been marked for deletion are deleted. This will help free up an data that is not required and help speed up the system and increase the free space on your computer.
This needs to be run on the server machine and at a time when Bookscan is not being used on any of the machines.

Ensure that all terminals are back to the main menu.

·On the main menu click Utilities/Database Utilities/Pack Tables.  
·Click OK to acknowledge that you have closed all other windows of Bookscan on all machines down.  
·Click Select All button (to run this procedure for all tables).  
·Click Pack button.  

When complete a message will display indicating this, click OK button.


You can resume using Bookscan on all machines.
