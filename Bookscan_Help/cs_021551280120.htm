Credit Notes
Top 

 
Creating a credit note is very similar to creating an invoice.  

Step 1: Open the invoice window
From the main menu, click on Sales, then point to Invoices and then click on Invoice, Credit, Approval Entry.

ENTERING THE HEADER DETAILS

Step 2: Select the customer   
Select a customer in the Customer field.
Note that only account customer can be invoiced. They are highlighted in blue in the Customer drop down box.
Customers flagged as Mail order will require a payment with the order (see Step 11 below)
For help on selecting customers click one of the following links:
·Selecting customers.  
·Using the Find window to select customers.  
·Adding a new customer.  
·The customer's name and default details will be displayed.  
·Details on their account balance are displayed - current, 30, 60 and 90 days.  
·For tax exempt customers, Tax Exempt will be displayed in a red field.  

Step 3: Transaction header details
Now enter the header details for the transaction:
·Enter the customer order number (optional - where appropriate, the order number can also be entered line by line).  
·You can change the:  
· customer Contact - the combo box lists all of that customer's contacts.  
· Sales rep - the second sales rep field is for use where you have separate reps for different product types (e.g. books and music).  
· sales Terms.  
· Discount (off the transaction total). You can optionally enter a discount off the total value of the transaction. This can also be entered (or changed) in the footer window. If a discount is entered here then the running total displayed as you are entering the lines will reflect the discount. If the discount is dependent on the value of the invoice, you would enter it in the footer window.  
·Delivery address: You can use the buttons to select alternate delivery addresses or you can add a new address.  
 
Step 4: Transaction type  
In the Transaction type radio buttons group select Credit note.

Step 5: Transaction mode  
In the Transaction mode radio buttons group select the required option:
·Return to stock: the transaction reduce stock and create a standard invoice.  
·No stock move(ment): the transaction will not reduce your stock levels. This option can be used to correct overcharges on a invoice or for crediting goods lost in transit.  

Step 6: Saving/displaying the header
When you have finished with the header, click on the Save button (F12).
At any time you can return to the header by clicking on the Show Header button (F11).

ENTERING THE ORDER

Step 7: The input line
In the ISBN field:
·Scan the barcode or type in the ISBN.  
·The Order No field: for the first line this will display the order number entered in the header. If you enter a new order number, subsequent lines will default to this new number.  
·In the Order qty box, enter the quantity to be credited.  
·You can apply a discount against a single line here. (To apply the same discount for the whole sale, do it in step 11).  
·You can also add a Comment against the title here.  
·The running total of the credit will display in the Order value field.  
Click Save (F12) to save the line to the browser. Alternatively click Clear Line (Esc) to delete it.

Step 8: Displaying the footer window
Repeat step 7 for each line of the invoice. Click Post (F12) to open the footer window.

Options

Editing
To edit any line you have saved, double click on the line in the browser. The line will be copied into the input line in the header.
Overtype any changes you want to make and click on the Save button.
To delete a saved line, right click on it in the browser and select Delete from the drop down menu.

Free text
To add a message line to an order, type an asterisk ( * ) into the barcode field. The free text line will appear. Type in your message and then click on the Save button (F12).

Appending from invoices  
·When entering a credit note, you can append an invoice to reverse it.  
·Click on the Append button and select the transaction from the combo box that is displayed.  

Check box options
·Quick input :  
Choose this option when you are processing single quantities of goods with no discounts or line comments and with the same order number. Simply scan the barcode of each product.  

ENTERING THE FOOTER DETAILS

Step 9: Footer details
·Apply a discount off the sale total.  
·Add a freight charge.  
·Add a surcharge.  
·You can add up to three lines of header Comments.  
 
Step 10: Posting
·Click the Post button (F12) to post the transaction.  
·If the customer is not a debtor and full payment has not been entered, the Tendering window open allowing you to record the payment (See Step 11 above.)  
When the invoice has posted a window will display with the invoice number.

Step 11: Credit Allocation
If you are using the debtors module, a window will now appear
allowing you to allocate the credit against existing invoices etc.



The window will display the oldest transactions against which you may allocate the credit. Use the Not this One button to trail through the available transactions and click on Credit this transaction to allocate the credit.
You may allocate the credit against several transactions; the Unallocated Credit displayed will reduce as you go.
Click on the Cancel button to post the credit as unallocated.

Check box options
·Print Preview :  
Choose this option when you are processing single quantities of goods with no discounts or line comments and with the same order number. Simply scan the barcode of each product.  

·Batch print:  
If this is unchecked the invoices will print out as you post them.  
When checked, the invoice will be printed when you close the window at the end of the session. When the box is unchecked invoices are printed as they are posted.
