End of Month
Previous  Top  Next


To open the Debtors' End of Month window, go to the main menu and click on Debtors->End of Month.

This window will guide you through the end of month process, remembering where you are up to in the process and ensuring that you complete all the various steps.

As you complete each step, the system will display a tick in the checkbox shown against each process.



Step 1: Reset Window   (Compulsory step)
Click on the Reset Flags button to set the window from last month .

Step 2: Print Reports    (Optional step)
Click on each of the four report buttons on turn to produce the:
   Trial Balance
   Journals report
   Payments report
   Sales report

Options
The Trial Balance has a Summary format option and allows you to option all include debtors with a zero balance.
The other three reports have an option for using only the Current period.
The option settings you choose will be saved for next time you use this window.

 
Step 3: Backup Data (Compulsory step)  
·Ensure that all other terminals have no Bookscan windows open.  
·Ensure that all other Bookscan windows on your own terminal are closed.  
·Click on the Backup Data button. This will open th backup window.  
·Select the drive you wish to backup to. and click the backup button.  
· All databases related to debtor's end of month will be backed up to a file called: EOMBackup.zip
·Click on the Exit button when done.  

Step 4: Calculate Interest (Optional step)
If you are charging interest on overdue accounts:
·Enter the annual interest rate in the Annual Interest Rate field.  
·Click on the Interest button.  
 
If you are not charging interest on overdue accounts:
·Click on the Skip checkbox.  
   
Step 5: Run Statements (Optional step for now)
This step can be run now, or you can run them later from the snapshot of the accounts that is automatically done as part of the aging process.
To defer the process, click on the Print statements using the snapshot radio button and go on to the next step.
You can also choose to send the statements via emil directly for those customers with email addresses. Detailed instructions here for setting up customers & email.

Before starting the statement printing, select
   Statement Date (defaults to today's date)
   Due Date (defaults to 30 days from today's date.)

Options
To add a message to the statements, click the Include the following statement message check box and type in the message ( three lines of 42 characters each.)
You can also select weather to print statements for debtors with current transactions but zero balances.
Another option to print to file. Click on the Print to file checkbox and then enter the path in the field below.

Reprinting
To reprint a single statement click on the Print statement only for the selected debtor radio button and then select the customer in field above this button.
To reprint all statements from a selected debtor , click on the second radio button in this group and select the customer in the field above these buttons.


Step 6: Aging(Compulsory step)  
Click on the Age Accounts button.
The window will display the customer names as it processes them, so that you can see how it is progressing.
If you have not printed statements, you can print them now from the snapshot.
