Metrologic Scanner Setup

Metrologic scanners can be hired from Barcode Solutions. Contact the help desk to book them.

Scanner Pre-setup Checks
Before using Metrologic scanners, you will need to ensure that you have a computer that uses Bookscan that has a USB port. This is the port/cable type that is required when using this scanner type. Without this the scanners cradle/docking bay will not be able to talk to your system.  
Ideally this should be a PC that will not be switched off during the stocktake; the server is usually the best option.  
 
Hardware Checklist
When you receive the scanner firstly you will need to ensure that you have the following;  
·Scanner Cradle/Docking Bay  
·Data Cable (that connects to a COM/Serial port on the pc)  
·Power Cable(will have a box connected on part of the cable)  
·Scanner(s) (this will be at least one, but could be any number of scanners depending on what was hired)  
·Installation CD-ROM Disc  

Hardware Setup
1.Only one PC is required to install the scanner cradle and software for stocktaking.  
2.Turn off the PC that the cradle is going to be connected to.  
3.Connect the USB cable into the back of the cradle (the part that connects is a long rectangular shape, roughly 15mm x 3mm).  
4.Then plug the other end into the USB port of the computer.  
5.Connect the power cable into the back of the cradle. (Small, round plug, slightly thinner than a pen with a silver tip/end).  
6.Plug the other end into the power point.  
7.Turn on the PC (allow it to start and log in to Windows as normal). Insert the CD for Optimus SP5500.  
8.Place a scanner into the cradle (buttons facing forwards)  
9.Cradles are used for communication (sending files or receiving files between PC and Metrologic) and charging you Metrologic batteries.  
10.Install cradle device driver follow the steps:  
·Connect Metrologic OptimusS Cradle (Model: MI5500-614) with USB cable and power cable.  
·Make sure the Power light is on (Red color).  
·Plug in USB cable into PC and you will get the screen as displayed below:  
 

·Click radio button as 'Yes, this time only'. Click 'Next'.  
·Click button 'Install from a list or specific location (Advanced)'. Click 'Next'  
·Check the box 'Search removable media (floppy, CD-ROM...)'. Click 'Next' button.The system will then search for the CIPHERLAB 308 USB-to-RS232 Interface converter.  
·After Interface Converter is found, the screen will be shown as below:  

 
·Just click 'Continue Anyway'.  
·After finish searching USB device driver, a complete install screen will be shown.  
·Right click mouse on Computer icon on Desktop. Select 'Properties'->'Hardware' tab->'Device Manager'->Ports(COM & LPT). Find out the com port for Optimus USB to UART Bridge controller (COM9). In this example, the com port is 9. It can be other than 9.  

11. Test each of the Scanners to ensure they are working. Do this as follows;:  
·Turn on the power of the PDT scanner.  
·Hold orange button on the middle of the scanner (this will activate the scanner laser). Do not scan anything; just ensure that the light comes on.  
·Press '.' to select the utilities option.  
·Key '1' for Browse Data, press Enter.  
·'No Data' message is displayed for a while.  
·Press 'ESC' to enter 'Stock Take Menu'.  
·Turn off the power of the PDT scanner.  
·Place the scanner back in the cradle and try the next.  

Software Setup
1.Once you have finished the previous section, and the cradle has been connected and the scanners appear to be working, we can now set up the software.  
2.Create a new folder in the Bookscan data directory on your local PC called 'StockTake'.E.g. C:\e-BilityData\Stocktake.  
3.Insert the CD-ROM Disc that was enclosed with the Scanner.  
4.View the contents of the CD through My Computer.  
5.There should be three things on the CD:  
·Help documents,  
·StkUtil.exe,  
·Setup.exe and installation files.  
6.Copy StkUtil.exe to C:\StockTake.  
(Do this by clicking mouse to highlight this file, then right clicking on one of the file and select 'Copy' on the CD. Then in the target location, using the right mouse, select 'Paste').  
7.Use the mouse to highlight C:\e-BilityData\StockTake\StkUtil.exe and right click the mouse. Click [Send To] an then click [Desktop (create shortcut)]. An icon shortcut called StkUtil.exe - Shortcut will be created. Rename it to StockTake.  
8.You can run the program by double clicking on Stocktake icon. When this is done a window as shown below is opned. This window is used to upload your scanner stock counts to a csv file in your Stocktake folder.
