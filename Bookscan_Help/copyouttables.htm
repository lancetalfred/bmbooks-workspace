Copy Out Tables
Previous  Top  Next



The Copy Out Tables is used to resolve intermittent issues with comment fields in database files. A re-index will follow the Copy Out.
Ensure that all terminals are back to the main menu.
#Note: Running this on the server machine will allow for this to run as fast as possible.
#Note: Some of the windows will say 'Structure Update' on them, but it is doing a Copy Out.

·On the main menu click Utilities/Database Utilities/Copy Out Tables.  
·A message will display requiring you to confirm you have exclusive access. In accordance with the above note, click Yes.  
·Click Select All (you can also do individual database files if required)  
·Click Copy Out. This will run the Copy Out procedure, then run a re-index. This may take some time depending on the size of your database. Purging of old files and 'Packing' regularly will help improve the speed of Bookscan.  
·When the process is finished a message 'Copy Out Completed' will show. Click Ok, then Close.
