Your system will already have been configured for you by Barcode Solutions during system installation.
The following information is for those making subsequent changes to their system.

Selecting the account type default
On the Modules tab in System Options (from the main menu - select Utilities/ System Options.)
Below the creditors check box is the Balance BF Credit check box.
Here you can select the default account type that will be displayed when adding a customer to in the customer master.

Select from the two types of accounts supported by Bookscan.
They are:
· Open item accounting (Check the box to select)  
· Balance brought forward  
 
Open item accounting retains all transactions on the account until they are paid. At the next ageing, they are then moved to the history file. Payments are applied against specific Invoices. Unpaid or part paid items remain on the account until cleared.

Balance brought forward accounts show only the account balance for anything older than the current month's transactions. The complete history can be obtained only from previous statements.

Barcode Solutions strongly recommend the use of Open Item accounting as this retains the details of each transaction until cleared.
Should you be asked some months later to explain how an outstanding balance is made up, this is very simple with Open Item Accounting. With BBF Accounting this information is not readily available.

Auto posting GRNs
If you check this box, invoices and credit notes are automatically posted to the supplier account during receiving. (Of course you will still be able to add invoices and credit notes manually as well). This is the usual way of setting up creditors.
If you leave this box unchecked you will have to add all invoices and credit notes manually.

Setting up creditors for multiple stores
This will have been configured by Barcode Solutions when they installed the system.
If all the ordering and creditors are to be handled at a head office, check the following boxes on the Stores window of System Options:
· Centralised orders  
· Installation has a head office  
If this store is also the head office, check the box:
· Installation is a head office  
For branch stores leave this box unchecked.
Click on the link to go to System Options for details.
