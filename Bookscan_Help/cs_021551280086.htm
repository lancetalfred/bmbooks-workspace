Managing approvals and approval enquiries

Previous  Top  Next


You can mange and enquire on approvals in the Approval Enquiry window. Open this window from the main menu: Sales/Approval/Enquiry, returns, sales.

Displaying approvals
You can lookup Approvals in three ways:

Enquiry by Approval number
In the Approval No field, type in the approval number and press the Enter key or click on the down arrow and select from the drop down list. All the lines on the approval will be displayed in the browser.
   
Enquiry by customer
Select a customer in the Customer field in the usual way - i.e. enter the customer code, use the F3 button to open the customer search window or the Alt F3 button to recall the last customer. All approval lines for the customer will be displayed in the browser.

Enquiry by ISBN
Type the ISBN into ISBN field. Alternatively use one the title shortcuts, click the F2 button to open the product search window or use the Alt F3 button to recall the last ISBN you used in the program. All the approvals for that ISBN will be displayed in the browser.



The browser will display three quantity fields:
Qty      The quantity ordered.
Ret'd      The number of this item returned by the customer.
Inv'd      The quantity of this approval line that has been invoiced.

Actions
Deleting an approval
In the browser, highlight a line of the order you wish to delete and click on the Delete Order (F4) button.

Deleting a line from an approval
Highlight a line in the browser, click on the Delete Line (F5) button.

Approval returns
Click on the Returns (F6) button. The window will change to an orange colour and the browser will display only items which can be returned. See approval returns below for details.

Invoice an approval
Where stock is still outstanding against an approval you can invoice it by clicking on the Invoice Appro (F8) button. The browser will display in invoicing mode and the window will turn green. See invoicing approvals below for details.

Loading a loan file from an external scanner
This is a specialist function and can be ignored by most users
This option is for users using the approval module for handling items on loan and using hand held scanners to process the loans and returns. A brief summary follows but you should contact Barcode Solutions for further details on setting up and using this option.
Creating export files for the scanners
Open the context menu and select in turn, 'Create title export file' and then 'Create customer export file'. This will create csv files of your customers and products to load into your scanners.
Importing loan files from your scanners
Export your csv loan file from your scanner. Click on the Load File button in the Approval Enquiry window. A pop up window will display where you can select your csv file. Click the OK button to load the file into the approvals table.

Printing
To view the approval reports printing options, click on the Printer Icon on the Bookscan toolbar. A pop up box will be displayed showing the available approval reports. These are:
All approvals
Prints a report of all outstanding approvals.
Option: Include approvals that have been filled.

Approvals summary
Prints a summary of outstanding approvals.
Options: Sort by customer or by date.

Approvals over 14 days old
Prints a summary of approvals over 14 days old.
Options: Change aging date.
Include approvals that have been filled  

Approval by customer
Prints a summary report of approvals for selected customers.
Options: Print in title order
Include approvals that have been filled.  

Approval reprint
Reprints a single approval.
You will need to select the approval from the drop down list.

Approval returns

Approval returns are done in the Approvals Enquiry/Returns window. A step by step guide follows:

Step 1:   Enter "returns mode"
·To process returns, click on the Returns (F6) button ( or press the F6 key).  
·The window will change to an orange colour to indicate that it is in "returns mode".  
·If you have already selected an approval number or a customer, then only items eligible for return will be displayed in the browser.  

Step 2:   Select the customer or approval number
By Approval Number
Select the Approval No. from the drop down box. All items on that approval that are eligible to be returned will be displayed in the browser.

By Customer
Select the customer by entering their key in the Customer field or by using the F3 button. All approval items for that customer that are eligible to be returned will be displayed in the browser. This option is particularly useful if the customer has taken many items at different times and returns them all in one go.



Browser Column heading definitions
Qty      Quantity originally despatched
Outstand   Number eligible to be returned (i.e. not invoiced or already returned)
Ret Qty   Quantity of returns of that you have entered in this session.


Step 3:   Enter the items to be returned
There are two methods for processing the returns
Scanning
If you have the returned items in front of you, you can scan them in.
·In the Barcode field, scan or type in the barcode.  
·A dialogue box will open asking for the Returns Quantity (defaulting to the quantity that is eligible to be returned).  
·Change the quantity if you wish and click on the OK button (or press the Enter key).  
·Repeat this step for each line to be returned.  
Note: Items entered this way are processed against the oldest approval number first.

Double clicking
If multiple items have been sent to a customer on different approval numbers, you may wish to use the double clicking method to ensure that returns are allocated against the correct approval number.
·Double click on a line in the browser.  
·A dialogue box will open asking for the Returns Quantity (defaulting to the quantity that is eligible to be returned).  
·Change the quantity if you wish and click on the OK button (or press the Enter key).  
·Repeat this step for each line to be returned.  

Step 4:   Options   
·To print a receipt for these returns, check the 'Print returns list' box.  
·To check for special orders, check the Check special orders box. This will cause a Special Orders Slip to print if anyone is waiting for this item.  
·To print a returns docket n the docket printer, tick the Print Docket checkbox.  

Step 5: Process returns
·Once all the returns have been entered for the selected customer or approval number, you can finalise the returns by clicking on the Process Returns (F6) button.  
·If you change your mind, click on the Cancel Returns button (or press the Escape key) to cancel the returns process.  

Step 6:   End returns mode
·To go back to enquiries, on the Cancel Returns button (or press the Escape key).  


Invoicing approvals

You can invoice your customers for products sent to them on approval in two different areas of Bookscan:
Order Entry window
In the Order entry window, select the 'Standard Invoice' transaction type. Then after saving the header information, click on the append button to load the approval (or part of it) into the browser. Finalise the transaction. An invoice will be created and the approval table amended to show the approval as invoiced

Approval Enquiry window
You can invoice approvals in the Approval Enquiry window. Open this window from the main menu: Sales/Approval/Enquiry, returns, sales.

Step 1: Set to invoice mode
After selecting an approval or customer, click on the Invoice Appro (F8) button.
·The browser will display in approval invoicing mode and the window will turn green. Note that only approval lines that have stock still outstanding will be displayed.  
·If you see a blank browser then either the approval has been invoiced or returned.  



Step 2: Load the edit line
Double click on a line in the browser that you want to invoice.
·The edit line will appear showing the ISBN, quantity to be invoiced and the pricing.  
·The quantity to be invoiced will default to the quantity outstanding except when you are editing a line, when it will show the quantity you entered previously.  



Step 3: Editing
·Amend the quantity, pricing and discount fields as required.  
·Click on the Save Line (F12) button to save the line.  
·Alternatively click the Clear Edit Line button (or press the Escape key) to close the edit line without saving.  
·In the browser the quantity to be invoiced will display in the Sales column.  
·Repeat steps 2 and 3 for each line you wish to invoice.  

Handy hint  
Auto Scroll (F11)  
Tick this checkbox to have the edit line display the next line when you click the Save Line (F12) button. Using this option can speed up data entry.  

Step 4: Create invoice
To create the invoice, click on the Post Invoice (F8) button. Alternatively click on the Cancel Invoicing button (or press the Escape key) to cancel the process and return to enquiry mode.
The effects of posting are:
·An invoice will be created.  
·Both the stock on hand and approval quantities in the title master will be reduced for each line.  
·The quantity invoiced in the approvals database will be increased for each line.
