Updating Bookscan
Previous  Top  Next

The follow steps are applicable for those who are upgrading to a new version of Bookscan.



Files used for Update

In your L:\e-Bilitydownloads\ folder you will need to place the following files;
·Bookscan6.nn.nn.exe – Bookscan installation file  
·Reports.n.nn.zip – Bookscan report forms (in a zip file if updating the reports as well.)  
n = number (these numbers will change)
These files may be emailed or a link given for you to download. To get these contact support (support@bookscan.com.au 1300 766 905 or 02 8999 1195). Click on these links to go to the help pages for Downloading and Saving an attachment from an email.

Updatling Bookscan
 
The installation of Bookscan will be carried out on each machine; the first machine to do with an upgrade is on the server machine. Users need to ensure Bookscan and e-Comms are closed on all machines, including the server before doing the install.
Open Computer -> L:\ -> e-Bilitydownloads (Where L:\ is the mapped network drive.)
Run the Bookscan.nn.nn.exe (The newest version, higher numbers are newer) by double clicking on the file.


Click Yes button

Click Next button

Select 'I accept the agreement', then click Next button.

Leave it as the default location (So when installed it will be located at C:\Program Files\Bookscan\ on all computers)
Click the Next button

Click the Next button

Click the Next button (leave the defaults, so it will create a desktop icon)


To continue with the installation click the Install button.


Do not click the Cancel button, allow it to continue.


Click Finish button when done.
 
Note: When the first copy of the new version of Bookscan is started, it will trigger a structure update to run. You must allow this to complete before starting Bookscan on another computer as per Post Installation. Once this has completed, you can update & start Bookscan on all other PCs.  
 
 
Post Installation - Structure Update / Re-index

As part of a new version, the software will now set up the databases. What this will do is, if the files required to store the information are not there, it will create them, if it is and new fields have been added, it will do so at this time. Without doing this, the program may not work correctly.
This process will only take place on the first machine to run a new version. It is important that the version not be run on any other machine until the process is complete (as the other computers will not know this is running, and run it themselves, which we don't want.)

If you get an update error message, please contact the Help Desk immediately before continuing.
If you are prompted with an error message with a 'Retry' option, try clicking it and seeing if it continues. If you are not, but are prompted with an 'Ignore', try that, note down beforehand what was shown in the little window displayed above, and the error message before doing this. (You will still need to contact help desk)
Once the database files are set up, Bookscan is installed.
The system will then automatically re-index all databases. The re-index window will look like this;


When done, it will display a message indicating that if there were any errors/issues to contact support, click the messages OK button.

If no problems move onto installing Bookscan on the next computer, Bookscan is ready to use on the server.

New Stores – Additional steps
New users once this is done for the first time will be prompted to fill in their stores details. Fill in as much as you can, then click the OK button to save. (The details can be amended later, refer to the help files [F1 key in Bookscan])
