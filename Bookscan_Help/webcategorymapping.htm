Web Category Mapping
Previous  Top  Next

You can map some or all of your imprints, Bookscan categories, departments and BIC subjects to your web categories. You can then load all your products into your web categories using this mapping. As products are added to the title master over time, the program will use the mapping to also add the products to your web export list. This will allow you to keep your web site up to date.

The Web Category Mapping window is opened from the main menu: Modules/ Web Export/ Web Category Mapping.



Before doing the mapping you will need to have set up your web categories in the Web Export window. See above for instructions on ding this.

Mapping departments
Select the Departments radio button. The Bowser will fill with all your departments.
As you highlight a department in the browser, it will display in the Link Department combo box. If you select a department in the combo box it will be shown as selected in the browser.
To link a department:
·Select it in the browser or combo box.  
·Select the main category in the Main Category combo box. This will load that main category's sub-categories in the Sub-category combo box.  
·Select the sub-category.  
·Click the Link button.  

In the example above HB NONFICTION has been linked to General Reference and MAPS has been linked to Atlases.

Other mapping
You can map your imprints, Bookscan categories and BIC subjects in the same way. You don't have to link them all; just what seems relevant.

Loading you products
After you have completed your mapping, you will need to load all your products to the web categories.
Open the Web Export window.
Open the context menu.
Select 'Load all titles from mapped databases'.
The browser will load with all the products mapped to the appropriate web categories.
Click the Update (F9) button to update the web site.

New products
As you add products to the title master, they will be automatically added to the web lists. Periodically you will need to open the Web Export window and export them to the web site.
