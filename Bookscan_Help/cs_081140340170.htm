Using the Security system has three major benefits. It  
·assists in maintaining the accuracy of your data by recording the operator initials against each transaction they create.  
·improves the security of your system; you can restrict user access to only those parts of the system that they need to use.  
·maintains an audit log of additions, deletions, globals and changes to your database.  
 
Setting up the security system.  
You can set up security in four different ways as outlined in Setting up security:  
 
Operator access  
From main menu, click on Utilities\Security\Operators.  
In the System Log in Box that opens, type in your initials and password. The Maintain Operator Data window will now open.  
 
 
 
Adding a new operator
·Click the Add Record (F3) button and enter a unique Operator ID and the operator's Name and (optionally) a Password.  
·If you are using the Use encoded initials option, enter a three character code in the Sign In field (not displayed if this option hasn't been set.  
·Then click Save Record (F3).  
 
Operator system access  
If you are running the full security module you can restrict an operator's access to only those parts of Bookscan that they need.  
System access is set using the three list boxes in the lower half of the Operators window:  
 
Operational groups
This list box lists the four main groupings of system access:
·sales   cash sales, invoicing, approvals etc.  
·purchasing   all the stock control functions - receiving, returns, stock adjustments etc.  
·modules   stocktake, warehousing, prepack and other modules.  
·utilities   system options, database utilities, security etc     
Click on any of these groups to display the current users access in that area.
         
Accessible areas & operations
This list box shows the current operator's system access for the area selected in the Operational Groups list box.
Click on an area in this list box to see its definition in the field below the Operational Groups list box.

All areas & operations
This list box shows all the available areas and operations for the operational group selected in the Operational Groups list box.
Click on an area in this list box to see its definition in the field below the Operational Groups list box.

Setting up an operator's system access  
·Select the operator in the Operator browser  
·Click on operational group you wish to amend in the Operational groups list box.  
·All the areas in this grouping will be displayed in the All areas & operations list box and the operator's current access in the Accessible areas & operations list box.  
·To give access to an area, select it in the All areas & operations list box and click on the <--- button. Use the Shift and Control keys for multiple selections.  
·To remove access to an area select it in the Accessible areas & operations list box and click on the --- > button. Use the Shift and Control keys for multiple selections.  
·To save your changes click on the Save (F8) button below the Operational groups list box.  
·To cancel your change click on the Reload (F9) button.  

Shortcuts to setting up operator access
The Operator's window provides a few shortcuts to speed up setting user access to the system:

Cloning an operator
The most useful of these shortcuts is cloning an operator's access.
Select the operator whose access you wish to set in the Operator browser.
Click on the Clone (F12) button.
A dialogue window will open with a combo box listing all operator's. Select the operator whose access you wish to copy and click on the Clone Profile (F12) button.
The first operator's accessible areas will be overwritten with the second user's access.
Note that all areas for all operational groups will be overwritten not just the visible one.

Pre-set profiles
Operator's can quickly be given one of three pre-set profiles:
·   Manager   Allows access to all areas of the program.
·   Warehouse   For wholesale setups, sets up a storeman's restricted access.
·   Sales basic   Sets limited access to basic sales functions.
When using pre-set profiles, the system access in the Accessible areas & operations list box will be automatically set. You can then make any changes to the access that you wish before saving the profile.

Step by step instructions to set these accesses up:
·Click on either the Manager, Warehouse or Basic sales radio button.  
·Click on the Load Profile (F11) button.        
·Note that all areas for all operational groups will be overwritten not just the visible one.  
·Manually make any changes you may wish to make to the operator's access.  
·To save your changes click on the Save (F8) button.  

Pre-set area profiles
Operator's can quickly be given access using pre-set area profiles using the check boxes in the Profiles box.

In Sales and Purchasing you can set up three basic profiles:
Enquiry Operator can perform on enquiry functions in either sales or purchasing and cannot enter transactions or make changes.  
ProcessingOperator can create transactions, add and delete records and access the relevant tables but has no access to global functions.  
HousekeepingOperator has full access to either all sales or all purchasing functions.  

In the Other functions you can quickly set up access to:
ModulesAll the optional modules you are running.  
Utilities System options, database utilities, pricing and security.  
TablesDatabase tables.     

Step by step instructions to set these accesses up
·Click on the General radio button.  
·Check the area check boxes you require e.g. Sales Processing, Purchasing Enquiry and Modules.  
·Click on the Load Profile (F11) button.        
·Note that all areas for all operational groups will be overwritten not just the visible one.  
·Manually make any changes you may wish to make to the operator's access.  
·To save your changes click on the Save (F8) button.  

Editing operator access
Click on the user that you want to edit in the Operator's browser .
·To amend the operator's name, just type your changes in the Name field and then click Save Record (F3).  
·To delete an operator click Delete (F4) button.  
·To change a password click Change Password (F7) button. .
