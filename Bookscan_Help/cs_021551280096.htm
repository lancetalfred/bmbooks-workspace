Creating special orders

Step 1:Open the Special Order Create window from the main menu: Sales/Specials/Create.  

Step 2: Select a customer in the Customer field in the usual way - i.e. enter the customer code, use the F3 button to open the customer search window or the Alt F3 button to recall the last customer.  

Step 3: Enter the customer order number in the Order No. field.(if relevant)



Step 4:   
·Enter the barcode in the ISBN field.  
·Alternatively you can search for a product by clicking on the Title Master F2 button to search and select or you can add a new title while on this window and once added select this.  
·Enter the quantity (defaults 1)  
·If a deposit is being taken, type the Deposit amount.  
·Select a Supplier if the field is blank (ie no supplier in the title you selected) or you can change the supplier when in this field.  
·A Comment can also be entered against each line.  
·A follow up date can be added.  
·Click the Save Line button (F12).  

Step 5:
·Repeat step 4 for each special order line.  
·Click the Save Order button (F12) to complete the order.  
·If a deposit has been entered, the Tendering window will open. Enter the transaction details in the same way as for a cash sale.  

 

Options
Unknown ISBNs (More details here.)
·If you don't know the ISBN, you can still put the order through.  
·Click on the upper Unknown button (F8) and then enter the product title and, if known, the supplier and author.  
·You can enter the actual ISBN and correct the other fields later. Click the link for details.  
·Clicking on the lower Unknown button (F9) will display Misc(ellaneous) as the supplier.  

Note: If you use the Unknown ISBN option – the special order is not activated until you link it to an active title in the database. This is done in Sales/Special/Replace. You should discuss the 'Best practice' with management as customer orders can easily be misplaced if this is used without understanding the necessary follow-ups required.  

Print
You can chose whether to print the special order by checking the Print check box (F4) .

EDI
You can choose whether to use email to send a special order advice of the order being placed. This defaults on, for any client who is setup for EDI (Customer/Finance tab). If you do not want to send a placed order confirmation via email, (untick) F6 to turn the option off.

Standing Orders   
Check this box for standing orders.(For example for a magazine).
         
Acquisition No    
Customer acquisition number: check the Standing Orders check box to enable this field.

Selling a special order
Special orders sales can be processed individually through the POS and Order Entry windows, or can be batch processed through the Order Entry window.

Selling a special order through the POS
·Open the Cash Sale window from the main menu: Sales /Cash sales.  
·Click on the Special (F8) button. A window captioned 'Select Special Order' will open.  



·Enter the special order number in the Special Order Number field. (This field is a combo box which you can also click on to select from a drop down list of available special orders).  
·If you have not yet entered a customer code, the program will enter this data into the POS window's customer fields. The special order number will be displayed towards to top of the POS window. You can select further special orders by clicking on the Special (F8) button again.  
·Now scan the barcode of the ordered item. Any special orders deposits will be displayed and taken off the total value of the order.  
·You can also scan other items not on the special order.  
·You may also turn the sale into a layby by pressing the Layby (F5) button.  
·When all items are scanned in, finalise the order as for a standard cash sale.  

Note: it is important to process the special orders using the Special (F8) button rather than just processing them as a standard sale. If treated as a standard sale, the special order is left as outstanding on the system, and will leave a hold on the title causing problems later. The Special order will then have to be Finalised from the Sales/Special/Enquire window.


Selling a special order through the Order Entry window

The client must be a Debtor to charge a special order to invoice.
Access Sales/Invoices/Invoice, Credits, Approval entry
·Select client  
·System should default F4 Standard Invoice as the default transaction type.  
·F12 to save, moves you to the processing screen  
·You can append specific numbers or if there is more than one type of transaction you get an All option – select the appropriate action  
·There is a button on this screen (top center labeled "Append F8") This allows you to append special orders, approvals, quotes. Proformas & consignment stock (if enabled) into an invoice. As the window appends multiple transaction types, you must select the Special you wish to append from the dropdown menu  



The software will display a window of items on that special order.



If you wish to not include a line or reduce the quantity you wish to append you can double click to untick the Use column to not append or in the qty field to append and quantity to process. Otherwise Ok will append the items to the invoice. The system will present this window for each order # if you used All option
Note: There is no facility to delete a special order line after appending it into an invoice so this is where you exclude it from the invoice.

There is a Right mouse Special order append in the order processing screen

Batch processing special order sales the Order Entry window
This feature of Invoice Entry enables you to quickly invoice all special orders for all customers where stock has been received. The process loads in turn, into the header, each customer who has special orders where the stock has been received.
The special order lines for the first customer are automatically copied into the browser. You can then finalise the order in the usual way by clicking on the Finalise button. The invoice will then be created and the next customer and their special orders are loaded. Use the Skip button to skip processing any customer.



Processing Details
Header window
·In the Invoice Entry window ensure that you have not selected a customer and that the Transaction Type is set to Standard Invoice.  
·Click on the Start Batch Alt F8 button to begin processing.  
·The number of customers to be processed and the total number of special order lines will be displayed.  
·The first customer with special orders will be loaded.  
·Make any changes you require in the header (e.g. re-set the terms) and click on the Save F12 button.  

Browser Window
·The browser showing that customer's special orders will now be displayed.  
·Amend or delete any lines you need to and add further lines to the invoice if required.  
·Click on the Finalise F12 button.  

Footer window
·Make any changes or additions you require to the footer window (e.g. add a freight charge) and click on the Post F12 button to create the invoice.  
·The next customer will now be loaded and you can process their orders in the same way.  
·To skip a customer, click on the Skip Customer Alt F9 button; the next customer will be loaded in its place.  
·Add any time you can use the End Batch F8 button to stop processing.  
·When the last customer with available special orders is finished, batch mode will end automatically.
