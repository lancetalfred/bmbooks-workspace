System Options - Sales
Top 

This window has various system options which you can set.

   
 
First column
·Hold special orders: If you tick this checkbox, all new special orders are automatically put On Hold. So if you have 4 copies of an item and 3 are for special orders, the on-hand quantity will be 4 and the quantity available will be 1.This will affect when products appear on the purchase order draft. If your re-ordering is dependent on quantity available (set on the Purchasing tab), this box should be checked. If it depends on the on-hand quantity, leave it unchecked.  
 
·Always pop up Holds: Checking this box will cause the Holds window to always pop up whenever a copy of a title that has holds on it, is scanned into a sale. (Normally it will pop up when there is insufficient stock to cover the sale and the stock on hold).  
 
·Credit note to backorder: When you check this box credit notes are added to the incoming list. This allows special orders to be allocated against the returned stock.  
 
(If using this option you will need to set up a supplier with supplier code "!C/N").  
 
·Redirect customer billing: This flag allows customers to be set up with sub-accounts.  
 
·Allow cash out at point of sale: If you allow EFTPOS cash out at your registers, tick this box.  
 
·Split register takings: If you check this box the X Report run at end of day will subtotal for each register. This allows for separate balancing of cash at each terminal.  
 
·Sales against kit components: When selling kits, the sale can be recorded either against the kit or against the kit's component products.  
·Prompt for operator initials: When logging in, prompt the operator for their initials and password.  
 
·Net Price Override Flag: When the Allow Invoice Net Price Override box is ticked, users in invoice entry can change the price of or add a line discount to net priced items. The items will still be unaffected by header discounts. The option is useful for wholesale/retail operations where you want to prevent discounts on retail sales via cash sales but invoice at a trade price as a wholesaler.  
 
·Instant Rewards: Tick the box to use rewards at the point of sales. Select from the list of rewards programs for the program you wish to use. In the example above, the "Valued Customer" program has been selected.  
 
·Always pop up Ins.Rew.: Will cause a pop up window to appear in the cash sales window notifying of the current reward "points" or the dollar value the customer can use if they have passed the threshold set in the reward program.  

Second column
·Don't track categories of purchases: Turns off the tracking of customer purchases by category.  
 
·Retain invoice comments as default: When you check this box if you enter a comment when creating an invoice, that comment will appear as the default on subsequent invoices created in that session.  
 
·Default to singles in POS: When you tick this box, the default entry in the POS window will be for sales of a single quantity per line.  
 
·No discount if below margin: This flag will stop discounting in the order entry window and in the POS where the margin on a sale line is below the minimum margin set in the next field.  
 
·Minimum invoice sales margin: Set a minimum invoice margin. In invoice entry, where a title's margin is below this minimum, the user will be prompted before saving the line. This is used to prevent incorrectly priced items being invoiced.  
 
·Surcharge as: Select the small order option you wish to enable- none, hold order below a minimum value or small order surcharge.  
 
·Minimum purchase value: Set a minimum value for invoices to avoid being classed as a small order.  
 
·Small order surcharge: Set the default small order surcharge amount for invoice orders under the minimum purchase value.  
 
·Payments discretionary adjustment: This field is useful for invoicing of mail orders, where customers send in payments with their orders. If the payment amount is slightly below the actual invoice total, you may wish to accept the payment amount as full payment. Here you can set a default amount for an acceptable payment difference (e.g. 50 cents) at which the system will process a short payment as full payment.  

Third column
·Consolidate daily sales: If you are using department groups, checking this box will give group subtotals on the Daily Sales Report.  
Departments in a group all have same initial letter in their department code.  
E.g. you might have eight book departments starting with B (BCH, BHE etc) and three stationery departments that start with S (SGE etc). With this box checked, The Daily Sales Report will show subtotals on Books and Stationery.  
 
·Consolidate picking slips: To enable the consolidating of multiple picking slips onto the one Invoice. This is for Warehousing users.  
 
·Invoice on docket: Causes invoices created in the POS window to be printed on the docket printer rather than the standard printer.  
 
·Split store taking: The cash book report will group sales by store areas. The store area is defined by the first letter of each register's name. For example if you have five registers in two areas you could set the registers as Kid1, Kid2, Kid3, Adult1, and Adult2. The cash book would split taking in two groups – 'K" and "A".  
 
·Enable handling charges: This setting can be used for library suppliers who want to charge customers handling on each order line. Setting this flag will enable the Handling filed in the Order Entry window.  
 
·Round down cents: Normally over the counter sales totals are rounded to the nearest five or ten cents. Check this box to always round totals down. This field also affects the calculator. With this box checked, it will paste rounded down figures into a field.  
 
·Round to: Set your country's rounding to 5 or 10 cents.  
 
·Hold order with backorders: Setting this flag will cause orders in the Order Entry window which are only partially filled to be held until the order is complete.  
 
·Tender amount exclude backorders: When processing payments in the Order Entry window on order that are only partially filled, you have the choice of taking payment for the whole order including backorders or just that part of the order which can be filled now. The flag sets which of these options will be used as the default in the Tendering window.
