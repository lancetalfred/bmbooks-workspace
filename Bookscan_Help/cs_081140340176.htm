System Options - Financial
Top 


In this window you can set a variety of financial defaults.

·Financial year starts: Select the month that starts your financial year.  
 
·Name of sales tax: Select either GST or VAT.  
 
·Tax rate: Enter the GST or VAT rate (E.g. Enter 10 for a 10% tax).  
 
·Layby deposit: Sets the default minimum layby deposit.  
 
·Period length: Set the number of days over which you wish to report sales and purchases summaries. This is usually 7 days.  
 
·Default transaction types: Set the default transaction type for the Cash Sales, Order Entry and Debtors Payments.  
 
·Default terms: Set the default terms for customer accounts e.g. 30 days.  
 
·Currency: Set this field to your local currency. The currency's symbol (e.g. $) will be displayed.  
 
·Local currency invoicing: Set this to invoice overseas clients in their local currency.  
 
·Local currency in creditors: Set this to use overseas suppliers local currency.  
 
·Account Exports settings: These settings are explained in the chapter on exporting accounts to MYOB.
