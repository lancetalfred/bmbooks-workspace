Downloading Files

Typically when there is a new version, or any file for that matter, (these steps are not file specific unless otherwise instructed by support), we will either email you a link to the new version or you will view it on our website (http://support.barcode.com.au Log in with your email address & password, then go to the Software Downloads page to download), to then be installed.
On the website, click the link of the file you wish to download.
   OR
If emailed as shown below, click on the link(s) also.




It will then display the above (through our website, or a link emailed), click the Save button.


Browse for where we wish to put it; what want to save it in the e-Bilitydownloads folder that was setup in the pre-install instructions. (You could chose to save it somewhere else, such as a USB thumbdrive.) Select L:\e-Bilitydownloads\ as shown above.


Click the Save button.


It will then show this window, which will start downloading the file to the specified location. When done, the window will close automatically (to stop it automatically closing, uncheck 'Close this dialog box when download completes'. Doing it like this will let you know that it downloaded completely).

You can then go into Computer then navigate to where you saved the files to access them.
In this case, we saved it to L:\e-Bilitydownloads\
