Purchase Order Entry
Previous  Top  Next


The Purchase Order entry window allows you to create purchase orders without going through the draft purchase order system.
The window can also be used as a quick way of adding lines to the draft.
When finalising you will be given the option of saving to draft or creating the purchase order.

Step 1: Open the window
From the main menu select Purchasing/ Draft Order/ Purchase order entry.

Step 2: Select a supplier:  
To select a supplier, click the arrow in the supplier box and select the new supplier.

Step 3: Header instructions

PO number sequence            
If you use more than one purchase order number sequence, click on the down arrow of the PO # Sequence box and select the sequence you require.  
 
Budget month  
If you are using the budgeting module, you can change the effective month of the order in the Budget Month box.  
 
(Special) instructions  
In the Instructions box you can enter a comment (such as Backorder if out of stock) that you want to appear on the order.  
Click on the down arrow in the box and select the comment you require.  
 
Print Instructions  
If you are printing the order you can select the number of copies and choose to by-pass the print preview.  
 
Electronic ordering     
Alternatively if you are using electronic ordering you can click on the EDI check box  
You can also select the order instructions (such as Backorder if out of stock or NYP) that you wish to appear on the order.  
 
Quick order  
Check this box if you just want to enter ISBNs and the quantities without changing the pricing etc.  
 


Step 4: Input line
Enter the details for each line of the order and then click Save Line ( or press F12 key)

Consignment
If the stock for this line is to be on consignment check this box (or press F7 key).

Price
This shows the current cost price for the title that is stored in the title master.

Royalties (Wholesale version only)           
If the title attracts royalties, check this box and enter the royalties agreement number in the next field.

Step 5: Ordering from a different supplier
If you enter an ISBN in the input line that does not normally come from that supplier you will get a warning message.
Click on the appropriate button in the message window:
Change supplier
Changes the primary supplier in the title
master and adds the line to the order.

Place order  
Adds the line to the order but doesn't
change the supplier in the title master.

Cancel  
Do not add the line to the order.

Step 6: Editing
To make corrections to saved lines, double click on the line in the browser to copy it into the input line. Then type in your changes and click Save Line.
To delete a line, right click on it in the browser and select Delete from the drop down menu.

Step 7: Posting or saving to draft
To post the order, click the Finalise button.
You will getting a dialogue box asking whether you want to finalise the order or save it to draft.
Select the required option ( or Escape to continue adding lines).

Finalise
If finalising, the system will post the order and either display a window showing the purchase order number or (it print preview has been selected) show the purchase order.

Save to draft
If saving to draft the lines will be copied to draft. In this case the header information is not saved ( you will re-set it when finalising in draft).
The lines will be saved with an origin code of PO.
