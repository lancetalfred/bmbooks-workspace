Imprint Matrix
Previous  Top  Next


Using the imprint matrix will allow you to set percentage discounts against imprints for groups of customers.
To use the imprint matrix, set the flag on the Titles tab in the System Options window.
The discount and customer type are entered in the Imprint Maintenance window.
The customer type is set on the details tab of the customer master.
Once the matrix is set the system will automatically select this price for these customers in cash sales, laybys and invoicing unless there is a lower price, say from a promotion; the system will always default to the lowest available price.

Note that using imprint matrix pricing precludes you from using the standard matrix.

Setting up the matrix
Open the Imprint Maintenance window (from the main menu, select Tables, then Imprint.).
If you have set the imprint matrix flag in system options, a browser will be displayed, showing two columns: Customer type and Discount.
The browser will show the discounts against each customer type for the imprint highlighted in the browser on the left.
To set discounts against an imprint:
·Select the imprint by clicking on it. in the browser.  
·Double click on the required customer type in the right hand browser. This will open a dialogue window.  
·Enter the discount in the New Discount field and then click on the OK button.
