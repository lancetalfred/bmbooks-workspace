Once you have set up Bookscan be very careful of what features you change in Systems Options. Some of the setup features are purely technical and should not be altered except in consultation with Barcode Solutions. Others control the way the system (and your business) operates and you may need to change them as your business practices change.
The following is a guide to those features:

To open the System Options set of windows, click on Utilities in the main menu. Then click on System Options.

System Options windows
Below is a summary of the system option windows. Click on the
window name for details.

Licensee This is where the basic details of the shop are stored.              
 
StoresIf you have multiple stores, you can set up how they will interact here.  
 
DocketsThese fields control how your computer system is set up.  
 
CopiesThis window allows you to set the number of copies you will print of each document and set some other system defaults.  
 
Modules & OptionsIn this window you can select which Bookscan modules you will be using.  
 
FinancialIn this window you can set a variety of financial defaults.  
 
CountersIn this window, you can set the numbering sequences for your documents.  
 
TitlesIn this window you can set up the defaults for your title master.  
 
Purchasing Here you can set the defaults for the purchasing screens.        
 
SalesThis window has various system options which you can set, particularly relating to sales.  
 
SundryThis window allows you to set various system options and allows you to access purchasing budget figures.
