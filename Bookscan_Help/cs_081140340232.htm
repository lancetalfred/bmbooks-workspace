Prerequisites
·Internet access at each location. Either by dial-up or direct connection via ADSL, Cable, Wide-Area Network, etc.  
·A dedicated email address for each site location. These email addresses will be used purely for the transfer of multi-store data and must be separate from the email addresses used for email correspondence.  
·Made up codes (typically non-book product) have to standardized across all locations.  
·2 character store (or location) codes allocated to each store and defined at all locations. This is important for the Bookscan configuration steps 2 and 5.  
Central Accounts and Central Rewards. All locations, Head Office and Branches, will require a common Customer file to run Central Accounts. For stores starting from scratch, this is implemented seamlessly. For stores already running separate Customer databases, steps will have to be taken to unify a common Customer file across all locations. Once implemented, this will update as new customers are added.


Configuration
From the main menu of Bookscan click on e_Comms.

(If you get the error please edit the transfer setup information or data path is invalid, just click on OK.)
The following will be displayed.



Setup

When in e-Comms to run setup on the main menu click File then click Setup;
This screen is split into 5 tabs as shown in the images below.
   

General tab

The Bookscan path must be set to the location of your data files.
The Transfer Interval is displayed in the form hh:mm:ss and will determine how long e-Comms waits after the last completed transfer before running again. Set it to 00:00:00 if you want to run on demand.
Disabling Transfers Incoming will allow the e-Comms transfer to send data only if it will not try to pick up any detail from the email account.
Disabling Transfers Outgoing will stop any email being sent and will allow Bookscan to pick up details only.
The Activity Log, if checked, will record the activity log to a text file. The text file, called actlog.txt, is located in the Logs folder in the database shown in Bookscan Path.
To view the log file, click the View Log File button. (This may take a long time to open if the log file is very large.)
Pressing Start in Task Bar will automatically minimise e-Comms to the taskbar when it is started.




Connection tab

The Dial Up Networking Entry (obsolete & ghosted)
The Dial Up user name (obsolete & ghosted)
The Dial Up password (obsolete & ghosted)
The SMTP Server is the SMTP server name of your ISP (Defaults to mail.bigpond.com)
The POP3 Server is POP3 server name of your ISP (Defaults to mail.bigpond.com)
The Direct Connection (obsolete & ghosted)



Web Orders tab
This tab is only to be used for stores wishing to transfer between sites using the email method (old). The new transmission method FTP and Local network is contained on the EDI tab. Please refer to that for it setup. If using FTP/Local network options, ensure this tab's fields (Multi Store) stays blank.

Account: Email address used for web site registration & admin login.
Password: Web site admin password
Web URL: web site sub-domain. (The first part of the whole address. Leave out the e-web.com.au)
e-Web Site ID: This can be copied from the website admin via Site Settings / API integration
Jacket FTP User ID: Obsolete, leave empty.
Jacket FTP password: Obsolete, leave empty.
Check for web orders: Optional, used to have e-Comms automatically check for & download web orders.




Sales Export tab
Used if you are sending data to Nielsen Book Scan.

Nielsen Bookscan: Export Settings
FTP Server is the FTP internet address where you will be connecting to send the Bookscan data.
Username is the account ID that has been supplied from Nielsen Bookscan.
The Password is for the Username, also supplied from Nielsen Bookscan.
Enable Nielsen Bookscan is to be ticked if you wish to enable this to be used.

Master onhand export: settings
FTP / None: Select FTP if you wish to export your onhand figures to an FTP server.
FTP Server: FTP server address
Username: FTP server username
Password: FTP server password


E.D.I. tab
Interstore Communication via:
This is for businesses with multiple sites wishing to communicate with each other (sending stock transfers, product information etc). There are the 3 methods that can be selected:
·Local network : Type in Folder Path or browse (yellow icon) to select the shared folder that all sites can see. This folder location is where both sites will be placing and retrieving their files from.  
·FTP : When selected, then fill in the FTP server address, Username and Password for access to that server. The FTP server must be the same for all sites.  
·None: No interstore communication.  


Note: When using FTP and local network method you need to make sure you have full read/write access to these locations.
Note: When FTP and local network methods run the first time, they create folders in these locations for each of the stores, using their short store code as the folders name.



Pacstream FTP Settings:
FTP settings are used for sending Pacstream data
FTP Server is the address of the Pacstream FTP server
Username is the username supplier by Pacstream
Password is the password supplied by Pacstream.
Store EDI Email Address is the email address that all email will display in the From field, also see section on configuring Customers and Suppliers for e-mail communications.
It is also the email that will be replied to by Pacstream.




eWeb tab
This information is for usage of those who have Barcode Solutions: php selected in System Options / Modules tab.
(Obsolete export sysem, no longer supported.)

FTP Server is the address of the FTP server where your website is being hosted.
Username is the username for connecting to your FTP server.
Password is the password for your FTP account.
Export Directory is the location on the FTP server that the files need to be saved to. This is where the website will load files from.
Image Directory is the location on the FTP server that the images need to be saved to. This is where the website will load images from.
Web Encryption Key is for if your website has uses encryption and requires a key.





When all the tabs have been completed click OK button.
