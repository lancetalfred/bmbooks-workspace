Pricing calculation options
The default pricing calculations method can be set on Details tab of the Supplier Master window for each supplier. You can also set the standard discount or margin for each supplier in the Standard Discount field. However, you can set, change or remove the pricing calculator, and change the discount/margin, as you process each line in the Receiving window. The default pricing method is "not set".
The pricing calculator is used when you need to calculate the either the sell or cost price. For some settings it will change the order in which the price fields are displayed.

No Auto Calculations
There is a checkbox called 'No Auto Calculations' on both the Details tab of the supplier master and in the Receiving window. With this option ticked, the edit line of the receiving window will display according to the pricing method set, but it will not automatically calculate the Cost or Sell fields; you will need to overtype them when required.

Not Set
This option will suit most users for most suppliers.

 

·The order of the pricing fields is: Cost, Margin, Sell, Retail.  
·When you first select a line of a receipt, the Cost, Sell and Retail price fields will load the values stored in the title master against the product.  
·You will need to manually key in Cost, Sell and Retail Price where necessary.  
·As the cost and sell price are changed, the Margin field is re-calculated.  
·The 'No Auto Calculations' setting has no effect on this value.  

Discount off retail
The cost price will be calculated at retail less the supplier's standard discount.

 
 
·The order of the pricing fields is: Retail, Discount, Cost, Sell.  
With 'auto calculations'  
·When you first select a line of a receipt, the Retail and Sell price fields will load the values stored in the title master against the product. The Discount field will load with the standard discount. The Cost price will be calculated using the retail less the discount.  
·If you overtype the Retail field, the cost price is re-calculated and the Sell price is set to the retail price.  
·If you overtype the Discount field, the cost price is re-calculated.  
·If you overtype the Cost field, the Discount field is re-calculated.  
'No auto calculations'  
·When you first select a line of a receipt, the Retail, Cost and Sell price fields will load the values stored in the title master against the product. The Discount field will be calculated using the retail and cost prices.  
·Where necessary, overtype the Retail, Cost and Sell price fields. The Discount field will be calculated as you change either the retail or cost prices.  
·If you overtype the Discount field, the cost price is re-calculated.  

Discount off sell
The cost price is calculated by discounting off the sell price for that supplier. It is very rarely used. It is identical to Discount off Retail above except that the Retail and Sell fields are interchanged.

Markup on Cost
The sell price will be calculated by applying the markup percentage to the cost price. The markup used is the setting in the 'Discount' field.

 
 
·The order of the pricing fields is: Cost, Markup, Sell, Retail.  
·When you first select a line of a receipt, the Cost, Sell and Retail price fields will load the values stored in the title master against the product. The Markup field will be calculated using the cost and sell prices.  
With 'auto calculations'  
·If you overtype the Cost field, the Markup will display the standard markup. The Sell price is re-calculated using the Cost and Markup fields.  
·If you overtype the Markup field, the sell price is re-calculated.  
·If you overtype the Sell field, the Markup field is re-calculated.  
·If you need to change the Retail field, overtype it.  
'No auto calculations'  
·The Markup field will be set to 'read only'.  
·You will need to type in any changes to Cost, Sell or Retail fields. Changes the Cost or Sell field will cause the Markup field to be re-calculated.  

Margin
The selling price will calculated by applying the set margin to the cost price. The margin used is the setting in the 'Discount' field.

 

·The order of the pricing fields is: Cost, Margin, Sell, Retail.  
·When you first select a line of a receipt, the Cost, Sell and Retail price fields will load the values stored in the title master against the product. The Margin field will be calculated using the cost and sell prices.  
With 'auto calculations'  
·If you overtype the Cost field, the Margin will display the standard margin. The Sell price is re-calculated using the Cost and Margin fields.  
·If you overtype the Margin field, the sell price is re-calculated.  
·If you overtype the Sell field, the Margin field is re-calculated.  
·If you need to change the Retail field, overtype it.  
'No auto calculations'  
·The Margin field will be set to 'read only'.  
·You will need to type in any changes to Cost, Sell or Retail fields. Changes the Cost or Sell field will cause the Margin field to be re-calculated.  

Receiving in foreign currency
Where a supplier's invoices are in a foreign currency, you should set them up as a foreign currency supplier. This is done on the Details tab of the Supplier Master window. Set the currency the supplier uses in the Currency dropdown box. This will cause the red 'Foreign Currency' field to display. The available pricing calculators will be:
·not set,  
·markup on cost,  
·margin  
By setting the supplier as foreign currency, the money amounts displayed in the Creditors windows and on Credit Claims will be the supplier's currency.
Note: you will need regularly to set the exchange rates in the Currency window as the Receiving window will use these to calculate your cost and sell prices. The Currency window is opened from the main menu: Tables/ Authority Tables/ Currency.

In the edit line an extra field is displayed. The program always calculates the cost price from the foreign currency cost price.

 

·The order of the pricing fields is: O/S Cost, Cost, Margin, Sell, Retail.  
·When you first select a line of a receipt, the O/S Cost, Sell and Retail price fields will load the values stored in the title master against the product.  
·The cost price will be calculated from the O/S Cost and the exchange rate..  
·The Margin field will be calculated using the cost and sell prices.  
With 'auto calculations'  
·If you overtype the O/S Cost field, the cost price is re-calculated. The Margin will display the standard margin. The Sell price is re-calculated using the Cost and Margin fields.  
·If you overtype the Cost field, the Margin will display the standard margin. The Sell price is re-calculated using the Cost and Margin fields.  
·If you overtype the Margin field, the sell price is re-calculated.  
·If you overtype the Sell field, the Margin field is re-calculated.  
·If you need to change the Retail field, overtype it.  
'No auto calculations'  
·The Margin field will be set to 'read only'.  
·If you overtype the O/S Cost field, the cost price and margin are re-calculated.  
·You will need to type in any changes to Sell or Retail fields. Changes the Cost or Sell field will cause the Margin field to be re-calculated.  

If the 'mark up' pricing method is set, the program behaves the same as for 'margin' except that a percentage markup is used in the sell price calculations. The 'not set pricing method behaves the same as the 'margin' setting with 'no auto calculations' set.
