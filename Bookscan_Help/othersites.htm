EXPORTING: OTHER SYSTEMS

Export your categories
You are now ready to export your categories to the web site.
Note: If you have the Not Exported Only check box ticked, the system will offer to update the website by adding the new titles. (The export button will display Update Web (F9)). If the box is unchecked, the web site will be over written. (The export button will display Overwrite Web (F9)).
·You can choose to export just the currently selected subcategory or the currently selected main category or all categories. Select the appropriate radio button above the export button.  
·Click on the Overwrite Web (F9) button (or, if you are updating, Update Web (F9) button).  
·The web export files will be created and the products marked as exported.  
·For Barcode Solutions provided web sites, Bookscan e-Comms will load your web export files to your web ftp site.  

Upload to the web site
These instructions are only for uploading into a Barcode Solutions provided web site.
·Open the back office of your web site.  
·If you are loading for the first time, or have changed your main categories or sub categories click on the link: Import Bookscan categories.  
·To upload your products click on the link: Import Bookscan titles  
·If you are loading for the first time, or have changed your main categories or sub categories click on the link: Import Bookscan main category links.  

Export file options
You can set various options for your web export files. In the Web Export window, open the context menu and select 'Set defaults'. The will open the Web Page Defaults pop-up window.





The optional exports are some the title master fields you may or may not want to export.
The stock availability options allow you to export either the stock on hand figure, no stock figures or a stock level message.
Export file can be in four different formats. For Barcode Solutions provided web sites, use the csv option.
