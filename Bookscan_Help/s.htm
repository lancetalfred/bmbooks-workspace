System Options - Copies
Top 


This window allows you to set the number of copies you will print of each document and set some other system defaults, as listed below.


Special orders
Set the number of copies that will print for each of the following reports:
·Deletion advice: The docket printed when a special order is cancelled.  
·Advice notes: The slips with customer special order details printed during receiving.  
·Customer letters: If the customer master has the Special Order Letters box checked, letters to the customer (instead of Advice Notes) will be produced during the receiving of special orders.  
·Dockets: The number of dockets to print out when the special order is taken.  

Other settings are:
·Group by customer: When ticked, the setting causes advice notes and customer letters to print in customer. This is useful if you are posting them as the multiple slips for a single customer can be easily collated to go in the same envelope. When unticked, the slips will be grouped by item. This makes it easier to match the slips with titles.  
·Special labels: Special order letters and slips print when the good received note is printed during the receiving process. Selecting this option will also cause the program also to print a (barcode-type) label with the customers name and phone number to stick on arriving special order stock.  
·Min stock to zero: This will set the minimum stock level to zero after a special order has been received. Use this if you want to ensure that no special ordered items go into draft purchase orders.  

Invoicing
Her you can set the number of copies of invoices and credit notes to print from the Order Entry window.

Other settings are:
·Default sort order: Determines the order which titles are display on the invoices and credit notes.  
·Auto backorder: When checked, the system automatically generates a special order for a customer when there is insufficient stock to fill a line on an invoice.  

Laybys
Set the number of copies that will print for layby dockets, layby deletion advice dockets and layby payment receipts.

Other settings are:
Days to complete: Set the number of days you allow for a layby to be completed. If you have layby condition printing on your docket, the time allowed will be included.

Other forms
Set the number of copies that will print for:
·Returns Authorisations.  
·Debtor payments     
·Purchase orders  
·Credit Claims  
·EFTPOS dockets  
·Items on hold: Set the number of dockets to print for items on hold.
