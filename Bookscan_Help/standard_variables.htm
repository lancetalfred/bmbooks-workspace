Standard Variables

Report Writer often sets a value (that is stored within the report form) at runtime. The name of the variable can have been anything, and "ReportTitle" is one that we have often used. By using it, we enabled the report form to produce a variable "title", depending on settings selected for the report.

The "standard variables" are sent to all reports, even though some forms don't use them. But you can incorporate them into any report by creating a variable of the designated name within the form (by modifying the report


The standard variables which you can employ in this manner are:

NAME         PURPOSE

"Licensee"       -   to include your company's registered name.
"TaxName"      -   the name of the sales tax you endure (e.g.: GST).
"GSTRate"      -   the tax rate set for your installation.
"CurrencySign"   -   your system's currency symbol (e.g.: $).
"ISBN_DESC"   -   what your system uses the ISBN field for (typically: ISBN).
"AUTH_DESC"   -   what "author" stands for on your system (e.g.: is "Artist" on DiscScan systems).
"IMPR_DESC"   -   how your system uses the Imprint field (e.g.: "Label" on DiscScan systems).

Note: These values are not set when you are modifying a report. Default values are used in that case.
