Archiving sales records

The Archive Maintenance window is located from the main menu of Bookscan, Utilities -> Archives or through Utilities -> Database Utilities -> Archive Maintenance.

In this window you will be able to Archive/Purge/Retrieve most of the following, but it is important that you read carefully how these work and the best way to do it.

·Invoice Header Records - Invoices headers for invoices older than they need to be readily accessible  
·Invoice Line Records - Run following archiving old invoice headers to remove the corresponding lines of the invoice  
·Sales Lines Records - History of the product sold and all details of when the item was sold (including sell price, date etc)  
·Sales History Records - Histories of sales of stock.  
·Stock History Records - Histories of stock inwards, returns and transfers (in/out)  
·Titles - Archives titles older than 1 year that are currently have zeros (for onhand, on order, layby, Special Order, Approval, Consignment) and have not been sold/received in 1 year or more. Important Note: Currently there is no way to get these titles back out of this archive, so be careful when using this.  



Archiving

To archive old lines within a backup storage file, that have past a useful time frame is a good way to keep the system running at it's best. It also shows on the more current information that you need.

Select the Archive file type. Select from the Archive Records the date you wish to archive on or before.
Click Archive Records (F12). Confirm by clicking Yes button.

Note: If archiving a file type for the first time and wishing to archive many years of data, it is advisable that you do so in 1 year lots (working backwards from the present).

This will run for as long as it takes depending on the number of records that need to be moved. When it is done, it will fill the window with records listen, these are the records that have been moved into the archive. If when you first load the window and select a file type, if records are already listed this is because it has been run before and the records shown are being loaded from the archive (This helps if you wish to retrieve records from the archive).

Note: After running the archiving, you will need to run a pack (Utilities -> Database Utilities -> Pack Tables -> Select All -> Pack. )

This works the same for all the options within the Archive File menu.

Retrieving sales records

This window will also allow you to retrieve back into the main database files records that have been archived previously.

Select a Archive File type. This will then load records shown in the archive.

Select either a date range (to pull back records between two dates) or in the list of records below, hold Ctrl and click on individual records you wish.

Click Restore Records (F11). This will then move the old records back. (This may take some time depending on the number of records).

Purging sales records

You can also purge records that have been archived (so that over the time the archive files themselves do not have data that's too old).

Select a Archive File type. This will then load records shown in the archive.

Select either a date (of which to delete where older than) or in the list of records below, hold Ctrl and click on individual records you wish.

Click Purge Records (F9). This will then delete the records permanently. (This may take some time depending on the number of records).

Title Archive

Archiving titles removes them from the title master and stores them in the archive file. Earlier versions of Bookscan only saved selected fields from the title master to the archive. In the present version of the program all fields are retained.

All sales history is retained.

Archived title can be easily restored to the title master. Go to Sales / Enquiry / Archive Enquiry and search by Author, Title or ISBN. You will be shown a list of matches from which you can select

·Select the date the titles were last sold.  
·Select the date the titles were last purchased  
·Select the date the titles were created.  
·Only titles with no stock, no special orders and none on order will be archived.  

Supplier Purge

This functionality will remove suppliers from the Supplier master that are not being used. It determines this by using a supplier and if no products are linked to this, it will delete them (the supplier).

Right click in the archive window, then select "Purge un-used suppliers". This may take some time to run depending on the size of your title master. It is a good idea if you do this following running the Title archive.
