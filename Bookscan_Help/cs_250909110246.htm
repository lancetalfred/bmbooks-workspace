Exporting titles - ONIX / BISAC
Previous  Top  Next


The export functionality allows for titles stored on the database be saved into a standardised format, sent to another location and imported.
This can be handy between stores where one location does not have online access and another one does.
The store who would be receiving it would then use the import functionality , click link for details on this.

The format of exporting can be one of two options:
·ONIX  
·BISAC  

Note: After picking the method the rest of the process is the same.
To export in one of the formats on the main menu click Utilities, move the mouse on Export, then click on either ONIX or BISAC.

Note: If using the ONIX export, titles must have the following fields populated, otherwise they will be excluded:
   (Details Tab) Title, Author, Retail Price, Status, Supplier, Binding, Imprint.
   (Publisher Tab) Publisher, Pub Date, BIC Subject, Blurb/Review (optional).

Note: If a titles status has in the status master been set to 'No ONIX', those titles will not be included.



As shown in the diagram there are a number of options on the left-hand side that you can select to pick the titles to export.

Step 1: Select Retrieval method
Select on the option you wish to use to select titles to export by clicking an option on the left-hand side.
For full details see Retrieval options section below.

Step 2: Enter a file name
In the field Export to (file-spec) field either type in the full path of the file including the file name.
Alternatively click on the file icon button on the right side of this field. Select the save location, and type in the file name.

Step 3: Zipping
To Zip (Compress) the file, check the Package into Zip file by clicking on its box.

Step 4: Exporting
Click on the OK/Export button.
The file will be saved in the location you selected ready for external use.


Retrieval options
Exclusion Options
·On-hand items only  
Will include only titles that are currently on-hand in stock if checked.
This option can be used in conjunction with any of the Selection Options

·Status exclusion  
If in Tables-->Authority Tables-->Status, the 'No ONIX' field has been ticked for a status, titles with that status will not be included in the export.

Selection Options
·All in database  
Includes all titles if checked

·By records-number  
Will display two fields:
·First record to retrieve  
·Last records to retrieve  
These are the order in which they were added to the database, NOT the order they appear in the Title Master List.
The default setting is all titles 1 - title count.
Key in any changes if required.
e.g. 553 records, wish to export last 100 added.
   First record to retrieve: 453
   Last record to retrieve: 553

·By record entry date  
will display two date fields:
·Start of record entry  
·End of record entry  
This will included any titles added between and including the dates entered.
Select using the date icon.


·By year  
This is to export any titles that fall within a year.
Type in the year in the Year Code field.
e.g. 2004

·By imprint  
This will export any titles that belong to a specific imprint.
Select the imprint from the imprint drop down list. Using a drop down list, click link.
You can only select one imprint.

· By supplier  
This will export any titles that belong to a specific supplier.
Select the supplier from the supplier drop down list. Using a drop down list, click link.
You can only select one supplier.

· By department  
This will export any titles that belong to a specific department.
Select the department from the department drop down list. Using a drop down list, click link.
You can only select one department.

· By customer  
This will export any titles that have been purchased by a specific customer.
Select the customer from the customer drop down list. Using a drop down list, click link.
You can only select one customer.

· By category  
This will export any titles that belong to a specific category.
Select the category from the category drop down list. Using a drop down list, click link.
You can only select one category.

·By individual selection  
When this option is checked you will be able to individual select the titles to include to export.
Multiple selection is allowed.

Upon checking this option the Find Title window will display, behind that will be the list of all titles.
Click on the desired titles. You can select multiple by holding down the Ctrl key while clicking.
If the find window is closed you can use it again by clicking Find Title button.



Exception List
Titles that are excluded from the export due to missing fields will display a window following the export, listing the product code(s) and an abbreviation of what is missing;
·Titl: Title (name)  
·AUTH: Author  
·Impr: Imprint  
·BIND: Binding  
·Price: Retail Price  
·PubDate: Publication Date  
·BIC: BIC Main Subject  
·Stat: Status  
·Pub: Publisher  
·Supp: Supplier  




This list can be printed out by clicking the 'Print' button, so these can be corrected for next time, or corrected, then re-exported.
