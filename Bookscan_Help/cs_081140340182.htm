System Options - Purchasing
Top 


Here you can set the defaults for the purchasing screens.


·Purchase order number sequences: Displays the last-used purchase order number for each of the PO sequences. You can add a sequence or edit the sequence names. You can have up to 5 order number sequences.  
WARNING: Please ensure that the sequences do not overlap.  
 
·Never print barcodes: Turn off barcode printing.     
 
·Always print barcodes: When posting your received stock, always print a barcode label.  
 
·Use catalogue number for ordering: With this flag set, the catalogue number, where available, will be used in place of ISBNs on purchase orders and in the purchasing windows.  
 
·Don't use minimum stock for reordering: This flag causes the program to use the sales quantity method of re-ordering instead on the minimum stock method. See the Draft PO chapter for details.  
 
·Stock adjustment supplier: To enable you to view a history of stock adjustments, stock adjustments are posted against a dummy supplier. Create the stock adjustment supplier (usually supplier code STK, supplier name Stock Adjustment) in the Supplier Master. Then select this supplier in the combo box here.  
 
·Order quantity depends on: Select whether the program uses the on hand or the available stock level when decided when to add a product to draft purchase.  
 
·Sort draft PO by: Here you can set the default sort products in the draft purchase orders browser by either author or title.  
 
·Copies to print: You can set the number of copies to be printed for finalised purchase orders and credit claims.  
 
·Show special comments in editing draft PO: Display the special order comments in the draft purchase order screen.  
 
·Preview report of finalised purchase orders: Sets by-passing the print preview as the default when finalising purchase orders.  
 
·Auto-hold all draft orders: Put new draft orders on hold
