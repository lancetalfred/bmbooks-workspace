Draft Purchase Orders
Previous  Top  Next


Bookscan provides three methods of handling your ordering:

Minimum stock method
With this method you set a minimum stock level for each product in your database. Draft purchase orders are created at end of day when you Close & Post the days sales and:
·stock level for a product have fallen below the minimum stock level, or  
·when a special order or backorder is created.  
You can manually add a draft order:
·when creating a new title,  
·in the title master, using a context menu selection,  
·in the Draft Purchase Orders window.  
The system will recommend a re-order quantity for each title and you can amend these quantities (and change the supplier) before having the system create your purchase orders.

Sales-based replenishment method
This method uses period sales to trigger re-ordering. Before starting an ordering session, you need to generate draft purchase orders in the Draft Generate window.
Draft purchase orders will be generated for products which have had sales in the nominated period or since the last regeneration depending on your selection. It will also list any special orders or backorders.
You can also manually add titles to the draft.
The system does not recommend a re-order quantity.
You can process your orders in either the Draft Purchase Orders window or the Generated Draft window.

Purchase Order Entry option
The Purchase Order Entry window allows you to create purchase orders without going through the draft purchase order system.

Importing from a csv file
If you have created a list of draft purchase order lines in some other software such as Excel, you can import them into Bookscan. The file should be in csv (comma-separated) format and must comprise only two columns, ISBN and quantity. Both columns should be text format and if there is a header row, you should remove it. Open the Draft Purchase Orders window and use the right mouse button to open the context menu. Select "Load from csv file", select the file to be imported and the file will load into draft purchase orders.
Some notes:
·The program will look up the master file for each product and set the order agianst that product's primary supplier.  
·If the master record does not have the primary supplier set, the default dummy supplier code ' ~~XX ' will be used. You can then change the order's in the Draft PO window.  
·If the product code is not found in the master, the draft order line is not loaded. A log file (DPOImportLog.log) will be created in the same folder as the csv file. This will list the products (and quantites) that could not be loaded.
