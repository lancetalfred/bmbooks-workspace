System Options - Stores
Top 


IIf you have multiple stores, you can set up how they will interact here. Before setting up a multi-store network you should consult Barcode Solutions.
In a multi-store system, Bookscan's e-Comms program can be used to transfer stock, customer and title information between stores.


Multi-store setups
Synchronisation options
Share on-hand figures
Tick this box when using e-Comms to transfer stock figures between stores. The stock levels at other stores can be viewed on the Stocks tab of the Title Master.

Share title changes
If you wish to have the different branches share the changing of titles, check this box. As titles are added to the master or edited, e-Comms will update the title masters at the other stores.

Do not share new titles
If you are sharing title changes between branches but do not want new titles added, tick this box.

Transfer vouchers
Ticking this checkbox will allow you to have tracked gift vouchers used at all your stores. When new vouchers are sold or when they are redeemed (or partially redeemed), e-Comms will pass the data to your other stores.
Note that you will require unique voucher number sequences at each store.
It is strongly advised that you consult Barcode Solutions before setting up a multi-store voucher system.

Title synchronisation options
·These checkboxes are used to prevent certain title master fields being updated when synchronising product information. If you select "No abstracts" or "No blurbs/reviews", the data from those fields will not be dispatched to other stores. If the data has been sent by other stores, it will be ignored.  
·Ticking the other checkboxes ("No prices" etc) will only cause e-Comms to ignore the relevant data sent from other stores. It will still send that data. So you will need to set these options at each store.  

Head office set ups
These options are only to be used if you are using central debtors and/or central rewards. In any other multi-store set up they should be left unticked.
It is strongly advised that you consult Barcode Solutions before setting up a multi-store head office system.

Centralised debtors
The setting allows for a head office to control all the debtors for the group. e-Comms is then used to transfer sales history from branch stores to the head office.

Centralised rewards
The setting allows for a head office to control all the customer rewards for the group. e-Comms is then used to transfer sales history from branch stores to the head office.

Installation is head office
Tick this box if this branch is the head office.

Installation has a head office
If another branch acts as a head office, check this box. Then select the head office store code from the drop-down box.

Customer synchronisation
Select the appropriate level of customer synchronisation you require. If you select customer synchronisation, you will first need to append the two character store code to the end of each customer code. There is an option to do this in e-Comms. It is strongly advised that you consult Barcode Solutions before setting Customer synchronisation.

Nielson Bookscan
If you wish to be involved with anonymously sending title sales to Nielson Bookscan for statistical purposes, tick this.
(For book trade only)
Check the options to disable, uncheck to enable.
