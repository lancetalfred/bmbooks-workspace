Customers with Multiple Stores or DCs
Top 


Note: the steps below detail the procedures for packing orders for multiple stores, shipped to distribution centres (DCs), such as Coles Myer. The procedures for packing standard orders are slightly different. Click on the link for details.

Orders for DCs are packed in separate cartons for each store ( and separately for each order number) but they are shipped as one shipment to the DC. The carton labels are have a "ship to" address ( the DC) and a "for" address ( the store the order is for). At the end of the packing procedure an ASN (advanced shipping note, equivalent to an invoice) is created and automatically sent to the customer.

Setting up customers with multiple stores.
Open the Customer master by selecting Tables/Customer master for the main menu.
Set up a customer in the usual way except:
·Check the Use store numbers check box.  
·The postal and delivery addresses will show Store No fields. These should be completed with (maximum 4 digit ) store number.  
·It is recommended that you use leading zeros when entering the store number (e.g. enter store 19 as 0019 )  
·Set the delivery address to be that of the DC. This will ensure that it is displayed as the default delivery address in invoice creation.  
 
( If the customer is already set up, go to the Address tab and set the Store No check box to ticked. The postal and delivery addresses will show Store No fields.)

Other stores can be set up as alternate delivery addresses. Go to the Address tab and click on the Alternate Address button and add the other store addresses
Important: Now go to the Detail tab and set the Onshipment labels check box to ticked. This flag must only be set for customers with DCs.

Invoicing multiple store orders
Open the invoicing window (Sales/Invoice/New Invoice).
Ensure the (default) Standard Invoice radio button is selected or select Forward Order )
Orders are entered in the usual way except for the following areas:
·When a multiple-store customer is selected, the Onshipment labels check box is displayed in the header. You can uncheck this flag to turn off the multiple-store features. Warning - if you do this standard carton labels are printed instead of onshipment labels.  
·When adding a line to the order select the store number from the Store No drop down box  
·Coles Myer orders  
The Advertised and New Line check boxes and their corresponding date fields are for Coles Myer orders only.  
Where a Coles Myer order specifies an Advertised date or a New Line release date, check the appropriate check box and select the date specified on the order.  
For Coles Myer orders the Invoice comments field should be only used to specify the zone or department if these are specified on the order. Otherwise leave the field blank.  

Packing multiple-store orders
Step 1
Pick the orders and then sort the stock into stores on the packing bench.

Step 2
From the main menu select Modules/Warehousing/Packing. This will open the Packing window.
In the Scan picking slip drop down box, scan the picking slip barcode.
·To consolidate a customer's orders into one shipment, just scan any subsequent picking slips for this customer.  
·The scanned slips numbers will be displayed below the drop down box.  
·The order lines for the picking slips will be displayed in the browser.  

Step 3
Select the first store in the Store No drop down box.

Step 4
Scan the barcode of each product as you pack it into the carton.
The Quantity is automatically set to 1.
For multiple quantities you can overtype the actual quantity.
Press F12 to save the line (or click the Save Line button).

Step 5
After you fill a carton press the F8 key (or click the Carton Full button).
·The Shipping Details window will open.  
·For the first carton, select the Carrier and enter the Consignment Note. These will be displayed when this window is subsequently opened.  
·If a Freight charge is to be levied on the order, enter it here.  
·You may also record the weight and size of the carton if required for this carrier.  
·Click Save when done,  
A carton label to be printed and the carton number incremented.

Step 6
When all items for the customer have been packed press the Post button.
If the order has been set for Invoice with goods, the invoice will now print.
Otherwise the ASN will be created and electronically despatched to the customer.

Features

Unpacked items
If you try to post the order without it all being packed, the system will display a message Warning Not all lines have been packed. Backorder unpacked lines?
Yes
If have been unable to locate the stock and wish to send the rest of the order click on the Yes button.
The invoice will be created only for the lines packed.
All items not despatched will be place on backorder and the master file flagged as having a stock shortage.
No
If you click on the No button, the browser will display all the lines not yet packed.
To resume packing press the F5 key (or click the All Lines button).

Unpacking from or adding to a carton
To edit what you have packed in a carton, press the F6 key (or click on the Edit Carton button ).
      
The contents of the current carton will be displayed in the browser.
To select a different carton use the arrow keys beside the carton number.
To edit an item double click on the line in the browser to copy it into the edit line.
Type in the corrected quantity
Press F12 to save the line (or click the Save Line button).
To resume packing press the F5 key (or click the Resume button).

Singles
If you just want to scan each item as you pack it without being able to type in multiple quantities, click on the Singles check box (or press the F9 key). This can speed up entering the data as there is then no need to press the F12 key after scanning each item.

Pallets
To palletise an order click on the Palletise button.
The pallet number will be set to 1 and four pallet labels will be printed, to be placed on each face of the pallet after it is shrink-wrapped..
For subsequent pallets click on the Next Pallet button.
