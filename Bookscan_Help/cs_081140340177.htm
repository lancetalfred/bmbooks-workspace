System Options - Titles
Top 


In this window you can set up the defaults for your Title Master.

·Compulsory title master fields: Choose fields in the Title Master that are to be compulsory during data entry – imprints, binding, status or category.  
·Minimum stock: Sets the default which will appear during data entry. This is usually set to 1. It is advisable not to set it to 0 as that setting prevents the title appearing in the purchase order draft.  
·Review locked records after: Determines how long (in seconds) a title record can be open in edit mode before you are prompted to release the lock on the title.  
·Default active status: Set one of your statuses to be the standard status for a current product.  
·Available stock definition: Define how you want Available stock to be defined.  
·Costs Price: Select the definition of the cost price that you will use- either latest cost price or average cost price. Stock valuations will not be affected as these report both average and last cost prices.  
·Next dummy ISBN: If you wish to use dummy ISBNs (or EANs) for products without barcodes, you can set the sequence here. For example: if you set the sequence here as 0000254856695, then, when you add a new title you can click the Next (Alt F2) to load the next number in the sequence. The number stored in this window is then incremented to the next valid, unused number.  
 
If you enter an ISBN (i.e. 13 digits starting 978 or 979) then the last (check) digit will be re-calculated to ensure it is a valid ISBN. So you don't need to know the check digit for your dummy ISBN. Just guess it, and let the program calculate it for you. For example if you enter 9780000100000 as your first dummy code the program will save it as 9780000100009, changing the last digit from 0 to 9.  
·Use Illustrator field: Setting this flag will allow you to record the illustrator of a book in the title master.  
·Firm sale: This refers to whether stock is supplied to you as "sale or return" or as a "firm sale". It sets the default which will appear during data entry. Set it to whichever is more common for your stock.  
·Binding groups: This flag is for use primarily by music wholesalers. It allows you to set each binding type as either Books or Music. When creating invoices and pick slips, the program will report a separate line and total quantity for both binding groups. Once the flag is set, open the Maintain Binding window (Tables/Authority Tables/Binding) to set up your groups.  
·Imprint matrix: Setting this flag will allow you to set up a discount percentage by imprint for customer groups. For example, customers in customer group G could be set to receive a 10% discount on all title with an ABC imprint. Once the flag is set, open the Maintain Imprints window (Tables/Imprint Master) to set up your discounts. Using the imprint matrix precludes you from using the standard pricing matrix.     
·Web searches: Set up your user names and passwords for downloading titles from web sites. The products supported are TitlePage, Nielsen Bookfind, Bowker Web Services and Bowker Search Link  
·Author/Illustrator in upper case: Forces these fields to upper case.  
·Always lift the re-price flag in receiving: Also on the Title Master is a flag to remove the re-price flag when stock is first received. In the first case outlined above (NYP titles), the re-price flag is removed but on the second (imported titles) it is not removed and the product is re-priced each time it is received into stock. The flag on this window merely sets the default "Lift re-price" flag on the New Title window.  
·Set re-price as default for new titles: In the distributor/publisher module, backordered products can be set to be re-priced as stock is received. A re-price flag is set on these titles in the Title Master. This is used for titles not yet published, so that you can take orders before a retail price has been set and also for imported title where the price to be set will depend on the exchange rate at the time stock is received. This flag sets the default for the Re-price flag in the New Title window.  
·Enable looseleaf in the Kits module: Bookscan can be configured to handle looseleaf products assembled from other products. Please contact Barcode Solutions if you are interested in setting up this feature.  
·No auto-link imprint/supplier: Stopps Bookscan from automatically loadin supplier information when a linked imprint is selected.
