Details tab
This tab contains most of the fields from the master file.
Buttons
·On hand - click on this button to make a stock adjustment. A pop up window will appear where you have to type a password set in System Options, then another pop up window appears where you can make the adjustment.  



·Specials – opens and displays the Special Orders tab.  
·Laybys – opens and displays the Laybys tab.  
·Consignments out – opens and displays the Consignment out tab.  
·Approvals – opens and displays the Approvals tab.  
·Backorders – opens and displays the Backorders tab.  
·Holds – opens the Held stock pop up window.  



·Min stock – opens a pop up window where you can change the minimum stock figure. Note that the new figure defaults to zero.  
·Max stock – opens a pop up window where you can change the maximum stock figure. Note that the new figure defaults to zero.  
·Pricing matrix – opens the pricing matrix for the selected title  
·Abstract – the abstract is a comment field of any length. Click on the Abstract button to open the abstract in a larger, pop-up window either to edit it or view if there is more than will fit in the basic screen.  
·Hide/Show prices – hides/shows all but the Sell Price field. Use this feature where customers may be able to see the screen.  
·Web (F9) – click on this button to update the selected title from a either the Title Page, Nielsen Bookdata or Global BIP web sites, if you have saved the log in details in the System Options.  



Category (F6) - clicking the F6 button will open a Categories pop-up window where you can add the title to or remove it from a category



BIC subject (F7) – clicking the F7 button will open a pop-up window allowing you to absorb all the titles with one BIC code into another



Flags
·Firm Sale - check this box where the supplier will not accept returns.  
·No Discount – when this flag is set the POS and invoicing windows will not allow a discount or change of price on the title. If a header discount is placed on a sale, it will not apply to this product.  
·No Reward - stops customer rewards being given for the title.  
·No Sp Orders - prevents special orders being placed for the title.  
·Generic - the generic flag is used for products which are not stock controlled. E.g. if you are charging freight by setting up a title called "freight", you would flag it as generic. Another example would be a dump bin of an unknown number of products at various prices. In this case you would set the selling price in the master as zero and overwrite the price as you sell it through the POS. Sets the Available quantity to 999999.  
·Tax exempt - sets the title as tax exempt.  

Context menu options
·Add to draft - this option allows you to create a draft order for the product. A pop up window will be displayed where you can enter the order quantity. Just type in this number, click the OK button and the draft order is created with the primary supplier.  
·Add to draft returns - this option allows you to create a draft return for the product.  
·Merge titles – opens a pop up window where you can merge the currently selected title with another title.  
·Marketing totals – opens a pop up window shows the sales of this product in each marketing group.  

Extra fields tab
This tab contains less important fields from the master file.



The following fields may need an explanation:
Re-pricing
(Distributor/ publisher configuration only)
Where you don't know the price of a title and you wish to take backorders on it, set the Re-price flag to true. When the title is received into stock, you will set the new price. When backorders are released, the new price will be applied to the backorders (less the customer's discount).
The program will automatically remove the re-price flag during receiving unless you have also set the 'Auto lift re-pricing' flag to false. So if you are say, publishing anew title and you haven't yet set the price, tick both the 're-price' and 'auto lift re-pricing' flags to true. If you import a title and the price you set will vary with the exchange rate set the 're-price' flag to true and 'auto lift re-pricing' flags to false.

Shortage
(Distributor/ publisher configuration only)
During the picking/packing process, where insufficient stock is found to fill an order line, the program sets the product's shortage flag to true. This will cause further orders for the product to be backordered, giving you time to find the stock or reduce the on hand quantity.

Jacket path
The best way to store jackets jpg files for your titles is to name the jpg using the titles ISBN as the jpg file name e.g. 9780732271060.jpg. Store the file in a folder called 'Catalog' in your data directory e.g. C:\e-BilityDate\Catalog\9780732271060.jpg. In these instances there is no need to enter anything in the Jacket Path field and the jacket will display in this tab.
If you have stored the jacket image elsewhere or not used the ISBN as the jpg file name, you will need to enter the file path of your jacket image in the Jacket Path field.

List tab
This tab is a browser displaying all the titles in the master file.



Double click on a line in the browser to display the Details tab for that title.
