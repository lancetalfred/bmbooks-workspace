Customer Mailout
Previous  Top  Next

In the Mail Out window you can create a mailing list for selected customers. This last may be in the form of:
·mailing labels,  
·merge files  
·simple listings of customers and their addresses or  
·emails to the selected customers.  
These options can be selected in the Produce combo box.

Customer lists can either be created in the window or loaded from files created earlier, either here, in customer rewards or when printing customer reports such as Most Profitable Customers and Best Customers.

Sending emails
If Email is selected in the Produce combo box, the Print button will be re-captioned Email. Clicking this button will open the Bookscan email window.



The selected customers' email addresses will be automatically loaded. You can add further email addresses manually.
Type a subject and a message in the appropriate fields and attach any files you want to send. Click the Send button to send the emails.   

Opening a saved customer mail out list:
·Click on the Load List button. (If this button is not visible then you already have a list loaded. If so, click either the Save List or Clear List button first).  
·A standard Windows dialogue box will open where you can navigate to the file to be opened.  
·Select the file and click OK.  
·The browser will fill with the customer list.  
Note that only mailout files created in Bookscan can be opened here. (Mailout files can be created in the Customer Rewards module.)



Creating a customer list:
The report can be created from either:
·the customer file,  
·customer categories.  
·editing a saved mailing list  
·adding customers manually  

Creating a list using from the customer file
·Click on the All Customers radio button.  
·All customers will be loaded into the browser.  
·You can then refine the list using the various filters etc described below.  

Using customer categories      
·Click on the Customers by Category radio button. This will enable the category fields.  
·Select categories using the Add Category combo box. The categories will be displayed in the Categories list box.  
·For complex expressions select the logical operator (AND, OR or AND NOT) from the Default Link combo box.  
·Then use the right mouse to add any brackets to the expression.  

An example: To select customers from the Rewards category who are either also in the History or Gardening categories:
·Select Rewards category.  
·Set the link to AND.  
·Select the History category.  
·Set the link to OR.  
·Select the Gardening category.  
·Right click on the History line in the list box and select opening bracket.  
·Right click on the Gardening line in the list box and select the close bracket.         
·The browser will re-fill as you select each category or when a viable expression has been entered.  
·For complex expressions you can click on the Test Expression button to check for logical errors.      

Using an existing mail out list
·Open a saved mail out list as described above in Opening a saved customer mail out list.  
·Refine the list using the various filters etc described below.  
·Click on the Save List button and enter a name for the new file.  

Adding customers one by one
·Clear any existing file from the browser by clicking the Clear List button.  
·In the Add customer area, select customers in the usual way entering the customer code, shortcut or using the F2 button.  
·Click on the Save List button to save to file.  

Filtering the customer list
Last sale parameters
You can use these options to select only those customers
·ignoring when their last sale was ( All radio button ),  
·who have made sales since a selected date,  
·who have had no sales since a selected date  
Select the appropriate radio button in the Last Sale Parameters box and then select the date.
Click on the Apply Sales Filter button to apply the filter.

Filters
You can also filter on:
·customers whose postcodes start with the same number,  
·debtors only,  
·mail-order customers only,  
·customers with email addresses,  
·customers without email addresses.  

Manually selecting
Double click on the Use checkbox against a customer in the browser to de-select them. When you save the list, only customers with Use selected will be saved.
Alternatively you can use the contact menu to do this. The context menu will also allow you select/de-select all above and all below and selected record.

Sorting
You can sort the browser and the report by:
·customer key ( default sort ),  
·surname  
·full customer name  
·post code.  
To perform the sort, click on the required column heading in the browser.
