Adding a new course

Click on the Add Course (F3) button.
In the Code field enter a new course code (up to 10 characters). Note that this field must be unique.
Then fill in the other fields as outlined below:
CourseCourse name ( up to 30 characters) . Compulsory field.  
Optional fields
YearThe 2 digit year of the course e.g. for 2010 enter 10.  
Faculty10 characters  
Department10 characters  
Comments Two lines of 50 characters.  
Co-ordinators25 characters  
EmailFaculty email ( email and phone numbers for individual lecturers are stored elsewhere).  
PhoneFaculty phone number  
Terms 1 - 4Terms (or semesters) that the course is taught in.  
Summer Term (5) If there is a summer term for the course it is stored as term 5.  
      
Click on the Save Changes (F12) button so save your changes or Cancel Changes ( use the Escape key) to discard them.
To edit course details, click on the Edit Course (F4) button.   
Note that text in these fields are coloured blue when you are adding or editing them.

Entering historical details
When the course is being set up, you may enter as much historical information as you prefer.
From that point forward, each time the course information is rolled over, the existing data will move one column to the right.
To enter this data manually, click on the Edit Rolls button and type in the numbers to the appropriate fields.
These fields are:
EstimatedThe estimate of the number of students taking the course  
Pre-enrolThe the number of students who have pre-enrolled.  
March If you are using a yearly roll, this is the actual number of students taking the first semester.  
JulyIf you are using a yearly roll, this is the actual number of students taking the second semester.
