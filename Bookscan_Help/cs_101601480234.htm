Setting up Carriers
Top 


To set up your carriers, go to the main menu and select Tables->Authority Tables->Transport.

·Click in the Add button to enter a carrier.  
·Enter a unique 4 character code, e.g. Post.  
· Enter the carrier name (max 20 characters) e.g. Australia Post.
·Optionally check any of the boxes described below.  
·Click OK to save.  
 
Check Box Options:

Default carrier
Set your most used carrier as the default. This carrier will be automatically displayed when printing despatch labels.

No consignment notes
If this carrier doesn't use consignment notes or stickers, tick this box. E.g. setting up "Picked Up" as a carrier.

Con note per carton
If you are using a numbered sticker for each carton (such as an Australia Post registration sticker), check this box.

Cube freight
This option turns on the features to help you calculate cubic dimensions of your freight. You can check this box if this supplier requires your stock to be cubed.

Weight
This option allows you to enter the weight of each carton as it is packed and give you a total at the end. You can check this box if this supplier requires you to record the weight of your shipments.
