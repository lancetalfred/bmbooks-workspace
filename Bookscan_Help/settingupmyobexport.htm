Step 1: Connecting Bookscan to MYOB
To connect Bookscan to MYOB you must first update your MYOB license. Please follow the steps below:
·Call Barcode Solutions for a MYOB activation number.  
·Call 1300 555 151 and select the option "to connect an add-on solution to MYOB". You will be required to quote this Add-on Solution activation number and your MYOB serial number.  
·Open the company file and login using the MYOB Administrator ID and Password. In the case of a multi-user system, you should use the 'Single User' option.  

 
 
·Once logged in, from the 'Setup' menu select 'Company Information'.  

 
·Choose the 'License' button at the bottom left of the Company Information screen.  

 
 
·Follow the onscreen instructions to update the license information held within the company file.  

 
Once these steps have been completed, the file will be activated for your Add-on Solution and Bookscan Bookscan will be able to integrate with your MYOB company data file.

Step 2: Installing MYOB ODBC
You will need to set up MYOB ODBC. This is quite simple to do:

Install the software
·In Windows, click Start, then All programs.  
·From the menu, select MYOB Accounting Plus v??/MYOB Tools/MYOB ODBC/ Install MYOB ODBC Direct V?.  
·Follow the instructions in the installation program.  

Setting up the ODBC drivers
·In windows, click Control Panel.  
·In Control Panel, double click Administrative Tools. Then double click Data Sources (ODBC). The Data Source ODBC Administrator window will open.  
 
 
·Click the Add button. Select MYOB_ODBC_AU7 and click the Finish button. Note that the name of the ODBC driver will vary with your location and version number.  
 
·In the next window that opens, enter a unique data source name say, 'MYOB7' and a Description say, 'MYOB Bookscan'.  
·In the Company file path field browse to your MYOB program (e.g. 'C:\myob16\MyShop.myo' ).  
·Click the OK Button  

Step 3: Setting up Bookscan
Open the Accounts Export window from the main menu: Accounts/Accounts export.

In the set up tab:

Exporting directly to MYOB
·Click on the direct to MYOB radio button.  
·In the 'MYOB .myo path' field, select the path of your MYOB account.  
Example: C:\MYOB17\MyShop.myo  
·In the 'MYOB .exe path' field, select the path of your MYOB program.  
Example: C:\MYOB17\MYOB.exe  
·In the MYOB ODBC DSN field, enter the name (DSN) you have given your MYOB ODBC driver.  
Example: MYOB7  
·In the Network protocol field, select the network type.  
Example: No Network  

Exporting via csv files
·Click on the Create csv export file radio button.  
·In the File path field, select the folder where you want your csv files placed.  
Example: C:\MYOB17\e-BilityExport  
 
 


Step 4: Setting up the chart of accounts
You will need to map your Bookscan data to your chart of accounts in MYOB.
A default chart of accounts (CoA) is set up in Bookscan when you first open the MYOB Export window. The chart is based on the default CoA that is created by MYOB for a bookshop. You can edit the account numbers to match the account number you have set up in MYOB.

Open the MYOB Export window from the main menu: Accounts/Export to accounts.
The CoA is displayed on the Setup tab.
 
The browser at the top right displays two cash asset accounts:
   1-1110 Cheque account
   1-1130 Cash drawer
You can add extra asset accounts by clicking on the Add Asset Account button.

Other accounts are listed the browser at the lower right. These accounts have a one-to-one mapping to the various transaction types so, while you can change the account numbers and descriptions, you can't add new accounts here. You should edit the account numbers to match those you have set up in MYOB. Just double click on the number you to change and overtype them.

Notes:
·For each transaction type you have set up in Bookscan (cash, cheques, EFTPOS, vouchers etc), there is a separate Income – sales account set up on the Bookscan CoA. If you are using the standard MYOB CoA set up, you will need to add these accounts to your MYOB COA. If you do not want to split the Income – sales accounts change all these account numbers to 4-1100 (or your Income – Sales own account number).  
·Even if you are not using an area of Bookscan such as laybys, just leave the CoA entry in the browser. The export will ignore it.  
·At any time you can re-load the default chart of accounts by pressing the Load Default COA button.

Step 5: Preparing for first time use
You will need to mark old records as not to be exported. To do this:
·Click on the 'Prepare for first use' button.  
·Select the date and press the OK button.  
Records dated prior to the date selected will be marked as exported.
