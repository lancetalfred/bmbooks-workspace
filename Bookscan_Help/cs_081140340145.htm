Adding a Title Record
Previous  Top  Next


There are several ways to load products into your title master tables:
·Manually entering titles in the New Title window.  
·Creating second hand titles from existing titles in the Buyback window.  
·Using the Web Search feature in the Title master window to download individual titles from Title Page, or groups of titles from the Nielsen BookData and Global BIP web sites.  
·Importing titles in the Import window, from text or HTML files downloaded from the Title Page, Nielsen BookData or Global BIP web sites.  
·Importing titles, in the Import window, from Onix or Bisac files issued by publishers or distributors.  

New Title window
You can open the New Title window from the Title Master window. Just click the New F11 button.


Notes on some of the fields
·Mandatory fields are coloured red.  
·After you enter the ISBN into the New Code field, the program will check to see if the title is already in the database. If it is, it will offer to return to the Title Master window and display that title. If the title is not in the database, it will check the archive. If the title is in the archive, the program will offer to return it to the master file.  
·Clicking the Copy F3 button will allow you to copy all the details, except the ISBN, of an existing title into the New Title window's fields.  
·Clicking the Copy Last F2 button will allow you to copy all the details, except the ISBN, of the last title you used into the New Title window's fields.  
·Clicking the F6 button will open a Categories pop-up window where you can add the title to or remove it from a category. See the Details tab section above, for details.  
·The Next (Alt F2) button will load the next dummy product code (set on the Titles tab in System options) into the ISBN field. The program will then increment the next dummy product code. If this code is an ISBN (i.e. 13 digits starting 978 or 979) then the last (check) digit will be calculated to make it a valid ISBN.
