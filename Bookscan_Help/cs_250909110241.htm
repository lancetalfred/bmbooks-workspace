The imprint master is the section of Bookscan where all title imprints are stored.
The imprints as shown in the diagram below are made up of a Code and Name.
Imprints being linked to a supplier is optional.
To open the Imprint Master window, on the main menu click Tables, then click Imprint Master.



Adding an imprint

Click the Add button.
Enter the imprint Code, Name and optional Supplier fields.
Then click OK button.


Edit an imprint

Click the Edit button.
Edit the Name field
Add, remove or change the Supplier field.
Then click OK button.


Global

Imprints
This will merge up to three (3) imprints into one code.
Click the Global Imprint option.
Click the Global button.
Enter the Imprint(s) you wish to change from.
Select the Imprint code to merge these into.
Then click OK button.

Supplier
Click the Global Imprint option.
Click the Global button.
Select the Imprint.
Select the Supplier to link to the imprint.
Then click OK button.
