Customer Rewards
Previous  Top  Next

Customer rewards, or loyalty, programs are a popular way of encouraging repeat sales. Bookscan allows you to define a rewards program. It will track your sales for each customer and allow you to reward your customers based on these sales.

Rewards programs are set up and managed in the Customer Rewards window which is opened from the main menu: Modules/ Rewards. This window contains five tabs:

Select rewards program
This is a simple browser allowing you to select which rewards program you wish to work on. If you are using only the one rewards program you won't need to refer to this tab. Otherwise just click on the required program and then select the tab you wish to work in.

Define reward programs tab
This tab allows you to set up or amend a rewards program.

Program specials tab
This tab allows you to enter different items to give special prices on these items for members of a reward program.

Payment/contract tab
This will be your main working area in rewards. Here you create the list of customers to be rewards, produce your mail out list and customer letters and where you produce the rewards.

Old records
In this tab you can look at your rewards history and purge old records.
The browser can be filtered to display only customers rewarded on a selected date by selecting that date in the Date Rewarded field.

Customer Rewards: Define Programs

Rewards programs are defined in the Define reward programs tab of the Customer Rewards window.



There are buttons to add, save, delete and copy a reward program. Multiple reward programs are allowed.

Adding a program
Click on the Add Program button and complete the various fields:.

·Program name: Give the reward program a name  

·Base criterion -> Base criterion for how the rewards program will calculate rewards. There are two options:  
o$Amount Net (Rewards will be based on the dollar amount of sales)  
oPurchase Quantity (Rewards will be based on the quantity of items sold)  

·Reward Percentage: This is the percentage of total sales that will be used to calculate the reward amount.  

·Round Reward To: As the final reward amount is calculated from a percentage, it may not be a whole dollar amount, so you can specify a dollar amount here that the final reward amount is rounded to.  

·Program Start: The start date of this reward program.  

·Program End: The last date of this reward program. If you want the program to go on indefinitely, then leave this blank.  

·Maximum rewarded: The maximum amount of sales that this program will reward.  

·Minimum rewarded: The minimum amount of sales that this program will reward. If using Instant Rewards this is the threshold at which "points", (the customer's previous purchase value), becomes redeemable as a reward in subsequent purchases.  

·Disqualify Stops: Set this flag to prevent customers who have been put on stop from being rewarded.  

·Include GST in reward: You can choose to base rewards amounts on sales either including or excluding GST.  

·Vouchers to be issued for rewards: If this is checked then vouchers will be printed as part of rewards processing.  

·Voucher report form: Set the path to the report form used to print the rewards vouchers. The voucher form can be modified to suit your company.  

·Membership type: The type of membership required for this rewards program. There are three types:  
1.Not required,  
2.Renew on program date,  
3.Renew each <n> months,  
Select not required if you don't need membership to reward programs.  
If you select option 2 or 3 then the "membership setup" button will be enabled.  
In this case press the "membership setup" button, to enter the renewal date and cost of the membership fee as shown below.  
   

·Category selection: You can use Bookscan categories to define which customers are eligible for, or members of a reward program. The browser on the right of the window displays a list of all categories. Select those categories which define eligibility for the program. By default all categories will be selected. If you don't wish to use categories to define customer eligibility, tick the Ignore categories checkbox.  

·You can set selected customers to be always included (or always excluded) from a reward program. Click on the Always Include or Always Exclude button to set these.  

·Scan freebie: If you are giving away a product as part of the customer reward, enter the product code in this field.  

·There is also a check box. "When a sale qualifies under multiple programs pay highest"  
·As you can have multiple reward programs if a customer qualifies for multiple programs, then this check box will ensure that they get the highest reward amount. If this is unchecked then they will get the lowest amount.  

Rewarding customers
Rewards are managed in the Payment tab of the Customer rewards window.

Step 1: Create a customer list
Select the start and end date of your rewards period and then click on the Prepare Rewards List button. This will do all the reward calculations based on the criterion that were entered into the Define reward programs tab.
Once this has finished, a list of customers who have qualified for rewards and how much they will be rewarded will be displayed in the browser

Step 2 Edit the rewards list
If you wish you and now edit the customer list by clicking on the appropriate buttons:

Remove Cust From List
Highlight a customer in the rewards list then click on this button to remove them so they will not be rewarded.

Mark Rewarded
This will mark all customers sales in the rewards list generated as rewarded. Used when you are starting a new reward program and you want to clear out the existing sales for customers.

Customer Detail
Highlight a customer in the rewards list then click on this button to show their detailed customer record.

Step 3 Print list
Here you can print a listing of the customers in the browser and/or create a mail out list of the customers listed.
If you are creating a mail out file you will need to name the file (and select the file path) in the field below the Mailout file checkbox. This is a standard Windows selection field. Click on the button at the end of the field and browse to the folder where you wish to store the file. Then either select a file there to overwrite or enter a new file name.

Step 3 Finalise
When you are happy with the generated rewards list, click the Produce Rewards button to produce the rewards reports and vouchers to reward your customers with.
When finalising is completed the browser will clear. You will now be able to review these records in the Old Records tab.




You can also view the rewards earned by an individual customer from the customer master window.



At the bottom left of the window is a button labeled "Memberships/Rewards".
This is also where memberships are updated for each customer. Once you have selected the desired customer click on the button to bring up the following window.



This will bring up a list of rewards programs that have been defined. Highlight the one you are interested in. You can then click on the "Update Membership" button to update their membership if required.

To view the sales for a particular customer, open the customer master window and search for the customer. Then open or go to the "Purchases Tab". This shows a list of items sold to this customer.
To view only the unrewarded sales check the "Unrewarded sales only" check box and you will only see the sales that have not been rewarded yet.
You can click the "Total" button at any time to total these individual sales and give a total amount.

Finally at the top of this tab is the label "Unrewarded portion of rewarded sales". When you reward a customer at a certain dollar amount, if the customers sales go over this amount then the difference will be carried over into this field and added to their next reward.

If "Unrewardsd sales only" is ticked, you can also see the totals of the customers rewardable sales, GST on those sales, quantity of items towards the rewards and unrewarded items.
