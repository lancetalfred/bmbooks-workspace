Bin locations
Previous  Top  Next

The bin locations option forms part of the warehousing module. It allows you to map your warehouse locations using different bin types (say standard, oversize, fast sellers etc) and automatically assigns an appropriate picking location to each product as it is received into stock. After receiving stock, you can print a 'putting away' report listing the received stock against it locations. Note that the location mapping is one to one: one location per product.

Setting up
System Options
In System Options, select the Options tab and tick the "Use bin locations" checkbox.

Location Types
Open the Bin Location Types window from the main menu: Tables/Authority Tables/Warehouse Bin Locations/Bin Types.

The default bin location (which has an empty bin code field) will have been automatically created for you.
Add any other bin types you require.
If some bin types are related to the shape of the product, you should map the bin type against the binding. In the example below, the binding 'Outsize' has been mapped against the 'OS' bin type code.



Now when automatically allocating a bin for products with this binding, it will be an 'Oversize' bin.

Warehouse bin location mapping
Warehouse locations should be in the format row, shelf and column slot: 99XX-9. For example 04AG-3 represents the bin in row 4, shelf AG and column slot 3.
Now you need to set up your warehouse bin locations.
Excel method
The easiest way to do this is to set them up in Excel in two columns: bin number and bin type. This way you can use Excel's auto-numbering and other features.

Alternate method
You can create locations in the Bin Locations window.



Enter the row, shelf and slot ranges and select the required bin type. Press the Create Location button. The BinLocs table will fill with the range of bin locations and display in the browser on the left.

Editing locations
The bin locations browser can display in three modes: all, allocated and unallocated.
Unallocated view
When unallocated locations are displayed you can:
·Delete locations - select the locations in the browser and click the Delete Locations button.  
·Change the bin types- select the locations in the browser, select the new bin type in the left-side combo box and click the Change Bin Type button.  

Allocated view
When unallocated locations are displayed, the right side browser is enabled and displays the selected location's product. You can remove the product from the location by clicking the Remove ISBN button.

Allocating stock to a location

Master file
You can manually add, change or remove a location in the Details tab of the Title Master window.



The Locations field is read only. To edit it, press the F3 key to open the Bin Allocation window.
Editing a location
For title that have already been allocated a bin number, the Bin allocation window will display the following:
·The current location.  
·The bin type of that location.  
·A browser listing the available locations for the selected bin type. Changing the bin type in the Bin Type combo box will change the display in the browser.  
·The 'Move to' field will display the first available alternate location if you wish to move locations.  
·As you select a different bin in the browser, it will display in the 'Move to' field.  
·To change the location to that field, click the Save (F12) button.  
·To remove the product from the current location, select the Remove from location (F5) button and click the Save F12 button.  

Allocating a location
If a title has not been allocated a bin location:
·The current location will display 'No location set'.  
·The Bin Type field will display the bin type mapped against that product's binding. It it is not mapped the default bin type will be displayed.  
·A browser lists the available locations for the selected bin type. Changing the bin type in the Bin Type combo box will change the display in the browser.  
·The 'Move to' button will be re-captioned to 'Set Location' and the text field will display the next available location for the selected bin type.  
·As you select a different bin in the browser, it will display in the 'Set Location' field.  
·To allocate the product to the selected location, click the Save (F12) button.  

Receiving
In the Receiving window, bin locations will be automatically allocated against unallocated products. You can also re-allocate a bin location here.



When a product code is entered in the edit line, the program check if a bin had been allocated to that product. If it has, it displays the location in the 'Loc' field; otherwise it allocates the next available location mapped against that product's binding and displays it in the 'Loc' field.

You can change this location by pressing the F11 key and opening the Bin Allocation window. As in the Title Master you can allocate a different location by selecting it in the Available Locations browser.

In the example above, the product's binding has been mapped against the default bin type. To allocate it to a 'fast movers' bin instead, select 'Fast movers' in the bin type combo box. The Available Locations browser will change to display 'fast movers' locations only and the Set Location field will display the first available bin. Click the Save Changes (F12) button to allocate the product to the new location.

In the main, stores people can ignore the Locations field and let just let the computer do the allocating.

Receiving EDI Orders
In the Receiving EDI Orders window, bin locations will be automatically allocated against unallocated products. If you wish you could change the alloaction after saving the stock into the receiving window or change it in the Title Master.
