Setting up your store to Electronic Order / receive invoices

To use the Pacsteam service for electronic ordering, firstly you will need to ensure that you are setup with a Pacstream account. If you do not have one, you will need to contact ECN Group. You can always contact Pacstream at support@pacstream.com.au. Then fill in, step by step the following parts of Bookscan so that when you wish to use it, it is ready to go. You will also need to make sure ECN group and the suppliers you wish to deal with using Pacstream are aware you will be ordering using this method.


Step 1: System Options

From the main menu of Bookscan, go to Utilities-->System Options. On the Licensee tab, complete the SAN field with your san number. (If you dont know this, contact ECN group as mentioned above)
Click OK button to save the change.

Note: Use of the 'Alternate SAN' field should only be used in consultation with Barcode solutions, as there are special setups that you will need to have done with ECN group.


Step 3: Suppliers

For each supplier that you are going to be using Pacstream to order through, you will need to set each of them up for this. For each one of these suppliers, do the following;

1. From the main menu of Bookscan open Tables-->Supplier Master  
2. Go to the suppliers record (using the search or by any other means). e.g. UNIT for United Book Distributers     
3. Open the Address tab.      
4. Select 'PACSTREAM' from the EDI drop-down list.     
5. Enter the suppliers SAN number in the SAN field, e.g.    9013849  
6. Repeat for each pacstream supplier.      

Note: If you do not have the supplier correctly setup with the SAN number that they will be using (Some suppliers have 2 SAN numbers, ensure you use the one they do for Electronic invoicing), there can be issues when receiving electronic invoices.

Step 4: e-Comms

e-Comms is the program which is what sends through the electronic orders to Pacstream and also retrieves the electronic invoices back. e-Comms should only be setup on one machine, which typically should be the server (machine that contains the database).

To run e-Comms from the main menu of Bookscan, simply click e-Comms-->e-Comms. To run it..
If this is the first time running it, you will be prompted with a few error messages, dont be alarmed by these are these are just to let you know that e-Comms is not yet setup to run, click OK to both of these messages. If you dont get these prompts, proceed anyway.


1.From the main menu of e-Comms, click File-->Setup.  
2.On the General Tab, set the Bookscan Path as your database directory (e.g. C:\e-Bilitydata\ ). Set Transfer Interval to appear like: 00:30:00 (HH:MM:SS; this will send/receive every 30 minutes). Tick the Activity Log box. No other options should be ticked on this window. Optionally, if you want e-Comms to start minimised in the System Tray, tick the box labelled Start in Task Bar.  
3. Click on the Connection tab. Set SMTP Server and POP3 Server to your ISP's mail servers, (eg. mail.bigpond.com for Telstra / Bigpond.)  
4. Click on the EDI tab. Fill in your username (Note: you need to leave the pac/p part of the username, followed by your SAN number. e.g. pac/p123456 ) and password (obtain from ECN group). The FTP Server field will be prefilled with ftp.pacstream.com.au.  
5. Enter you normal email address in the Store EDI Email Address field.  
5. Click Ok button to save the settings.  
 
This will now have you set up to run e-Comms to facilitate any orders that will be made, and/or electronic invoices ready to be received from suppliers.

Suggestion: If you wish to have e-Comms automatically run when your machine starts (it will start minimised in the bottom right hand corner of windows, next to the clock if you selected this in step 2 above), you will need to add a shortcut. To do this open My Computer. Go to C:\Documents and Settings\ Click on the username folder listed under this that you are logged on as. e.g. 'MainUser' . Then you want to select Start Menu, Programs, then Bookscan. (You will now be in C:\Users\MainUser\AppData\Roaming\Microsoft\Windows\Start Menu\Programs\Bookscan).
Right click on 'e-Comms.exe' and select the option 'Copy'. Now go to C:\Users\MainUser\AppData\Roaming\Microsoft\Windows\Start Menu\Programs\Startup and right click again and select 'Paste'

Note: For orders to send, e-Comms must be running and either setup to run automatically or triggered manually, otherwise they wont be sent through to the suppliers.

Electronic Invoice receiving

Electronic Invoices section are for stock coming in from suppliers. The supplier need to be setup to send them out (not all do) and they need to know that you accept them.

When e-Comms is running to send electronic orders it will at the same time download electronic invoices that are waiting to be picked up. To ensure you are setup, ensure you have followed steps 1 to 3 above.
