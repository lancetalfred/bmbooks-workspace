Problem:
When installing on a Window NT workstation you will get the following error.
The application or DLL *:\plusscan\bsa\bs5\disk1\cain4shll.dll is not a valid Windows NT image
Or
Unable to load cain4shl.dll. Desktop objects and icons may not be set up.
Please check against your installation diskette
Answer:
Ignore the error and continue with the installation. E-COMMS will install successfully.


Problem:
Dynamic memory low error.
Answer:
This is caused when a large file is in the mailbox. Remove the large file and try again.


Problem:
e-Comms caused an invalid page fault in module cavoole.dll
Answer:
This is caused when a large file is in the mailbox. Remove the large file and try again.


Problem:
Unable to send transfers time out error.
Answer:
Go to e-Comms \ File \ Setup and disable incoming
Try again.
Go to e-Comms \ File \ Setup and disable outgoing
Doing this will give you and indication of where the problem lies.
It will also prove that e-Comms communications works and the problem is with a file.

You can also rename the <database folder>\transfer directory to Transfer.old and then start e-Comms while you are on line. OK the error port already in use and e-Comms will automatically set up the transfer directory again.
Get the customer to dial again and e-Comms will now connect.
Or
Make sure the SMTP and POP3 settings are correct


Problem:
e-Comms does not appear to start after installation.
Answer:
Another copy of e-Comms is already running, check the task bar. If not found, go to Start - Run. Type in Taskmgr & click OK. Go to the Processes tab & look for e-comms.exe. If it is there, select it & click End Process.
