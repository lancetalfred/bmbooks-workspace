Electronic Gift Cards
Previous  Top  Next

Bookscan supports credit card-style gift cards that are used in conjunction with Ingenico EFTPOS and Payment Express EFTPOS. Gift voucher cards are set up in the title master like any other product and are sold through the POS in the usual. At the end of a sale involving a gift card, Bookscan connects to the EFTPOS machine. The new gift cards are swiped in the EFTPOS machine to have the card number set with the value of the card.
Note: You will require an Bookscan EFTPOS license to use this feature. Contact Barcode Solutions to obtain one.

Using electronic vouchers
·Set up a product in the title master for each electronic voucher amount. The sell price should be set as the value of the gift card. Alternatively leave the sell price at zero and enter the value in the POS during a sale.  
·In the Categories tab of the Title Master, set the product type as gift card.  
·Sell the gift card as usual through the POS.  
·At the end of the transaction, the EFTPOS window will (re-)open. Swipe the gift card and it will be loaded with the sell price of the card.  
Redeeming cards
Create a new tender type for gift cards. Set the EFTPOS flag for the transaction to true.
In the tendering window, select the gift card transaction type and enter the card as you would a debit card.
