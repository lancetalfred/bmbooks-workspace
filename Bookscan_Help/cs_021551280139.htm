Transfers inwards can arrive from two sources - either via e-Comms or via a disk or network (ie. a USB flash drive).

Via e-Comms
When you run e-Comms, transfers are automatically loaded into the transfer inwards window where they can be processed as described in Step 3: Processing Transfers below:

Via disk
For transfers received via disk or network, you need to use the Import Transfers from Disk window. From this window transfers are loaded into the transfer inwards window where they can be processed as described in Processing Transfers below:

·From the main menu select Purchasing/Transfers/Import Transfers from Disk.  
·The Import Transfers from Disk window will open.  
·If the transfer files are on a USB drive, place it into a USB port.  
·In the Data Path field select the path of the folder containing the transfer inwards files - this is a standard Windows selection field. Click on the button at the end of the field and browse to the transfer file folder to select it. (The folder, not the files.)  
·Click the Process Transfers (F12) button to load the transfer files from the folder into the Transfer Inwards window.  

Processing Transfers

Inwards transfers are processed in the Transfers In window.

Step 1:
From the main menu, select Purchasing/Transfers/Transfers In. This will open the Transfers Inwards window. Unprocessed inwards transfers are displayed in the browser.

Filtering the transfers
·Radio button From all locations will display all unprocessed transfers.  
·Radio button From selected location will allow you display only transfers from the selected branch. This will enble the Select order no. combo box where you can select a single transfer by transfer number.  

History
Click on the Show History (F11) button to display processed (and partially processed) transfers in the browsers. Click the same button to cancel history view.

Step 2: Code changes   
Note that this refers to transfers via disk only.
Where a product code has been changed at the sending store but not at the receiving store, the line in the browser will be highlighted yellow. If you wish to update the product code locally, slecet the line in the browser and open the context menu (right mouse click) and select Code Change.

Step 3: Processing transfers

·If you wish, filter the transfers you wish to process as in step 1.  
·Click on the Begin Processing (F12) button. The window will change colour and only only outstanding quantities will be displayed in the browser.  
·Double click on the line in the browser to open the Edit Received Quantities window.  
·Enter the quantity to be received in the Received field.  
·Click on one of the Save buttons. The received and not received quantites are now displayed in the browser.  
·To process the transfer, click on the Process Transfers (F12) button.  
·The transfers will then be saved to the Receiving List against the Transfer supplier, code !TRA. Open the Receiving window, click the List button and post the receipts as you would for good inwards.  

Shortcut
To receive all transfers displayed in the browser:

·Click on the Begin Processing (F12) button.  
·Open the context menu (right mouse click) and select Receive all stock. This will fill the Rec column in the browser with the total quantity.  
·Click on the Process Transfers (F12) button.
