Ordering Academic Texts
Top 


To place your orders for academic texts:
1. Select the course in the Code combo box.
2. Double click on the first line in the browser. This will hide the browser and display the title fields.
3. Using all the data of stock, sales and course numbers displayed work out the order quantity required and enter the amount in the Order Qty field.
4. Click on the Next (F12) button to save your changes and display the next text.
5. Repeat steps 3 & 4 for the remaining texts. Then press the Escape key to display the browser again.
6. Click on the Order Text (F11) button and then click OK to Compile using current values.
7. The order values will be added o the Draft Purchase Orders. Items added to the draft are left on hold and show a source of "Te".
8. The order values are then copied into the Last Order Qty field and are then set to zero.
9. To place your order with the supplier, open Draft Purchase Orders from the main menu. If you wish, filter the draft orders to show Academic titles only ( code 'Te' ). Post the order in the usual way.

To discard order quantities:
If you decide to scrap order quantities you have entered, click on the Order Text (F11) button, select radio button option Zero order quantities and click on OK.
