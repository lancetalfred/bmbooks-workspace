Sales Report:   Marketing


   Purpose:
View performance by each of the marketing groups.  

   Parameters:
Summarisation option, Start/finish dates and option to report quantities or values (latter not in summary).  

   Output:
      Detail Option:
ISBN, Title, Columns for each marketing group, plus "unknowns" and totalling. Subtotals by department.  
   Summary Option:  
    Type, Sales, Discount, Cost, %-Contribution (by Type).

   Report-form Variables reset at runtime:
ReportTitle    -   reflects the report's purpose.  
nColWidth   -   adjusts report with regard to unneeded columns.  
nDecWidth   -   dictates if certain numeric values are represented as integers.  
nTitlePadLen   -   adjusts report title centering.  

See also:   Selection Controls.
