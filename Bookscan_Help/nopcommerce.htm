EXPORTING: WooCommerce

Note: Uploads cannot be sent by machines running Windows XP.

Select Microsoft - Auto-update / Manual update, as preferred.

Initial setup for exporting

1. Registering WooCommerce libraries.

For Windows Vista/7/8/8.1/10
Run the supplied batch file: WooLibrary register. Run as Admin.bat by right clicking on it & selecting Run as administrator.


Alternatively, in the Windows destop search bar, type "cmd". Right click on Command Prompt and select Run as Administrator.
Copy & Paste one of the following lines into the command prompt window depending on your version of Windows:
(To check your version, press [Windows]+[E], then in the File Explorer window, open the C:\ drive. If the Program Files (x86) folder is there, you have 64 bit Windows, otherwise you have 32 bit.)

For 64 bit Windows - C:\windows\microsoft.net\framework\v4.0.30319\regasm "C:\program files (x86)\Bookscan\woolibrary.dll"
For 32 bit Windows: - C:\windows\microsoft.net\framework\v4.0.30319\regasm "C:\program files\Bookscan\woolibrary.dll"

If you need to unregister the library, please use the appropriate following command:

For 64 bit Windows: - C:\Windows\Microsoft.net\framework\v4.0.30319\regasm /unregister "C:\program files (x86)\Bookscan\woolibrary.dll"
For 32 bit Windows: - C:\Windows\Microsoft.net\framework\v4.0.30319\regasm /unregister "C:\program files\Bookscan\woolibrary.dll"

3. Set Defaults

Open the Set Defaults window by right clicking in the Web Export window, then clicking Set Defaults.



Set the image path in the Small Image Path field to where your images are stored in the Bookscan database.
Set the Jacket FTP Server to the supplied ftp server path and
Set the Small and Large image Directories to /wp-content/uploads/
As shown below.
(The Custom Fields & Description field do not matter as they are used for the older e-Web uploads.)



Click Save(F12) when done.
Click on the Export to Web (F9) button.
Leave this window and Bookscan open & go to your web browser.

Web Site Settings

Log into your website with the administrator login & go to Users - Add New and create a new administrator login for yourself. (Please set the Role to Administrator before clicking Add New User.)



After creating this, go to WooCommerce - Settings. Then select the Advanced tab & once the page loads, REST API, then click on Add Key.



Now enter a name for the new key, (eg. Uploads), the email for your admin user, select Read/Write from the dropdown selection and click Generate API Key.



Enter the Email used to create the new Administrator in the field marked Web site user ID:
Enter the Web Site URL the same as when opening the site in your browser.
Highlight the Public key with your mouse, right click on the test & select Copy.
Alt-Tab back to Bookscan and right click in the field marked Web Publickey and select Paste.
Highlight the Private key with your mouse, right click on the test & select Copy.
Alt-Tab back to Bookscan and right click in the field marked Web Secretkey and select Paste.
Tick the Remember passwords this machine (F3).




The Jacket user ID and Jacket password will be in the email with your site details.

You can now close your web browser if you like.

Setup is now complete, you can create a manual export by clicking Export (F12).

e-Comms will automatically update your web site when titles are updated, received or sold whenever it runs.
