Creating And Modifying Your Own Reports

New reports can be created quite readily. For an elementary exercise, try the following: Select New from the File menu, then Standard from the submenu. (At this point Report Writer's menus are replaced by the ReportPro Designer's.)

From the list of data tables, select BINDING.DBF. You are then given a blank report-form. Select the Text tool (from the Tools->Drawing Tools submenu) and define a text output area above the Header band, by clicking, dragging, then releasing the left mouse-button. Type "BINDING CODES REPORT" into the box created. This will be printed as the header on each page of the report.

The data from the BINDING.DBF table will be formatted in the Body segment/band of the form. Select Field from the Tools->Drawing Tools submenu (or click the Field icon on the toolbar). Drag/drop a field onto the "Page - Body" band of the form and the Expression Builder will pop up, to help you define what output you want. Double-click on "Binding.Code" from the fields list, then OK. Create a second output field for "Binding.Name", positioning it alongside the Code field. The report is now ready to show you the Binding codes alongside the relevant descriptions.

HINT:   To move and resize the fields you have created, first select the Pointer as your Drawing Tool.

To run the report, you can use Print Preview from the Designer's File menu (or Open from Report Writer's File menu).

For more complex forms of data access you may wish to look at the report-forms for the inbuilt reports (which you can do by pressing the Modify button on the main selection window).

Reports worth making for yourself probably need access to the system data, i.e.: the data controlled by Bookscan. ReportPro (the system you use to create reports - or to redesign them), has been configured to grant that access by default.

The system is quite complex and there are lots of file-and-field references required before certain classes of information can be extracted in a fully reliable fashion. If you are determined to generate complex reports of your own, and looking over the internal reports doesn't provide all of the answers that you need, you can always talk to the helpful and friendly support team from Barcode Solutions.
