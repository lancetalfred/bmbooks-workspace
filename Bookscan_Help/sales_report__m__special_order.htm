Sales Report:   Special Order
         Command-line execution enabled.
   
   Purpose:
Report the status of a specific special order.  

   Parameters:
Order-number, option to include/exclude filled orders.  

   Command-line Parameters:   
    /SAL_SOO /<WantPreview> /<OrderNo> /<ExcludeSupplied>

   SAL_SOO      -   Identifies the report to be run.
   WantPreview      -   /Y gives a preview, /N avoids it, /? will let the user choose.
   OrderNo      -   Number identifying the special order to be printed.
   ExcludeSupplied   -   /Y excludes orders which have been supplied, else use /N.
   
   Output:
Letterhead, Order-date, Title, Author, Quantity outstanding, Comments.  
 
   Report-form Variables reset at runtime:
Licensee       -   Name and all variables starting with "L_" (address data).
