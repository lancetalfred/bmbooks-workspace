Packing and Invoicing
Top 

In the Student Orders window, select the school and year. Select the required student using the Students combo box or the Find (F3), Next (F6) bag or Back (F5) buttons.

In the Invoice box there are three buttons:
Pick slips (F8) to print picking slips.
Order (F11) to invoice the student and print the invoice.
Reprint Order (Alt F11) to reprint the invoice.

These buttons will invoice or print for all bag numbers in that school year as nominated in the From and To fields. These default to the current bag number, so to say, invoice the currently displayed student, just click the Order (F11) button.
To print or invoice a range of bag numbers, enter the first and last bag numbers required in the From and To fields, and then click the appropriate button.
Note that only eligible student booklists will be processed. So if say, you are invoicing and a student in the range has already been invoiced, that student will be skipped over. So you don't have to worry about duplications or printing invoices for uninvoiced orders etc.

Once a student has been invoiced, most means of changing his order become unavailable and records of available stocks are decremented.

To Follows
Using the pop-up menu you can mark order lines as To-Follows in a batch (as well as marking a batch as supplied). The batch can be identified either by lower-and-upper Bag Nos. or sequentially to the point of a given quantity of items. The batch operation is then performed on the nominated order-line. It does not affect any other school/year.

Returns
Returns can also be logged from the pop-up menu and are clearly identifiable either in this or in the students' window. In this window, the value of returned items (if any) will show in the Account Summary. The value of refunds will not exceed the amount that a student has paid.
When processing returns a dialogue box will give the opportunity of allocating the returned stock to either special orders or to other pre-pack orders marked as "to follow". In the later case, the system checks for any orders marked as "to follow", allows you to select from these where you wish to allocate the stock and the "to follow" notation is removed from these. When the returns processing is finished a window listed to released orders is displayed. You can click on the Print button in this window to print the listing.
If you don't want to allocate the stock select the No Action radio button.
