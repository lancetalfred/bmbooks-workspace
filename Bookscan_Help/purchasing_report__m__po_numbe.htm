Purchasing Report:      PO Number
               Command-line execution enabled.            
   Purpose:
Produce nominated purchase order. Or does the same for Promotional orders.  

   Parameters:
PO Number, option to omit preview.  

   Command-line Parameters:   
    /PUR_NUM /<WantPreview> /<PO Number>

   PUR_NUM      -   Identifies the report to be run.
   WantPreview      -   /Y gives a preview, /N avoids it, /? will let the user choose.
   PO Number    -   The number of the purchase order to be reported.

   Output:
PO header info plus ISBN, Qty, Title, Author, Binding per book.  

   Report-form Variables reset at runtime:
PONumber   -   The selected Purchase Order number.  
    POInstruct      -   Instructions attached to the order.


See also:   Selection Controls, Executing Report Writer From The Command Line.
