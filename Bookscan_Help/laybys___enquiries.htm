Open the Layby Enquiry window from the main menu: Sales / Laybys / Layby Enquire.

Displaying Laybys
You can search for laybys in three ways:

Layby number
Select the layby number.
A list of all products on that layby number will be displayed.

Customer
Select a customer in the Customer field in the usual way (i.e. enter the customer code, use back slash or other short cuts or use the F3 or Alt F3 buttons).
A list of all titles on layby for the customer will be displayed.

ISBN
Scan or type in the barcode in the ISBN field. All laybys for that product will be displayed.
Note that in this mode, you can't delete or make a payment on a layby.

Handy shortcut - Double clicking on a line will switch to Layby Number mode with the browser displaying just the details of that layby number.
   

          
Options
Payments
·In the browser, select therequired layby.  
·Click on the Make Payment (F7) button.  
·The Tendering window will open displaying the total amount owing in the Layby Deposit field.  



·If the customer if not paying the full you can overtype this amount.  
·If the customer is not paying in cash, select a tender type.  
·Enter the tender amount in the Amt Tendered field.  
·Click on OK (or press the Enter key) to complete the transaction.  

Deleting
·In the browse, select the required layby.  
·Click on the Delete (F4) button.  
·If there are outstanding payments on the layby, the Tendering window will open displaying the payment total as the amount to be refunded.  
·If not giving a full (or any) refund you can overtype this amount with the actual refund.  
·If not refunding in cash, select a tender type.  
·Click on OK (or press the Enter key). The Tendering window will close.  
·A pop up window, Cancellation Comment will now be displayed showing a default comment of the refund amount, cancellation date and operator. Overtype or add to the comment if you wish and click OK or press the Enter key.  

 

·The cancellation is now complete. If there is cash refund for the customer, the Change window will now be displayed  

Payment History
·In the browser, select the required layby.  
·Click on the Payment History (F5) button.  
·A window will open listing each payment.  

 
 
Handy shortcut - Except in ISBN search mode, double clicking on a the line will have the browser will also open the history window.  

Docket Reprint
·In the browser, select the required layby.  
·Click on the Print Docket (F6) button.  

Layby Archive
·This allows the viewing of completed laybys for viewing purposes only.  
·Click Show Archive (F9) button.  
·To return to the current laybys click Show Current (F9).
