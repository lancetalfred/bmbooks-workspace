The Branches 'master' relates to multi-store businesses that use the inter-store transfering. If you are running only a single store business, this section does not need completing.

You can add a new branch or edit an existing branches details in the Maintain Locations window.
You can also print a list of stores and their YTD sales.

From the main menu click Tables, then point to Authority Tables and then click on Branches.



Add a location
To set up a new location, click on the Add button.

Enter the store's Branch Code (unique two character) and Name, ,number and address.

Optionally you can also complete these fields:

Address , Contact , Phone, Email, and UnMap file.  

Click the Save button when done.

Edit a location
Select the branch you want to edit and click the Edit button.
Overtype the fields you wish to change (except the Location
Code which may not be altered).
Click the Save button when done.
