Purchasing Reports:      Supplier Draft POs
               Command-line execution enabled.

   Purpose:
View draft purchase orders for nominated supplier(s).  

   Parameters:
Supplier(s).  

   Command-line Parameters:   
    /DRAFT_PO /<WantPreview> /<SupplierCode> /<SupplierName>
   DRAFT_PO      -   Identifies the report to be run.
   WantPreview      -   /Y gives a preview, /N avoids it, /? will let the user choose.
   SupplierCode    -   The supplier code. Selection will be made available, if omitted.
               "ALL" (no quotes), as <Supplier> reports all Draft POs on file.
   SupplierName   -   The full name of the supplier.

   Output:
ISBN, Author,Title, Dept; Order Date, Order Quantity, On-hand, On-order, Last order figures.  

   Report-form Variables reset at runtime:
ReportTitle   -   Fixed as "Draft Purchase Order Listing".  



See also:   Selection Controls.
