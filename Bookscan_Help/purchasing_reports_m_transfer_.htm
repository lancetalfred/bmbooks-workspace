Purchasing Report:      Transfer Reprint
               Command-line execution enabled.

   Purpose:
Reprint information for a nominated transfer-number.  

   Parameters:
Transfer-number. Option to bypass the print-preview.  

   Command-line Parameters:   
    /TRA_REP /<WantPreview> /<TransferNo>

   TRA_REP   -   Identifies the report to be run.
   WantPreview   -   /Y gives a preview, /N avoids it, /? will let the user choose.
   TransferNo   -   Identifying number of the transfer to be reprinted.

   Output:
ISBN, Title, Author, Date, Quantity transferred, To location, From location, Costing.  
 
   Report-form Variables reset at runtime:
    nReportClass       -   The type of report being run.
nTransferNo       -   The number of the transfer being reprinted.  
   
See also:   Selection Controls; Executing Report Writer From The Command Line.
