1. Sending data on a daily basis
On the main e-Comms screen click File then click Transfer.
Now click Start button , to start sending data.
It will now send data all requested data to the required locations including: -

·Email and EDI transaction advices to Customers and Suppliers.  
·Inter-store data.  
·Synchronisation's request resends.  
·Nielsen Bookscan.  

If you set a time in the Transfer Interval during configuration, you will see it counting down, (00:29:55 in the image below.). You can still run it manually by clicking Start, if you so choose.

2. Synchronise
Click on File then click Synchronise.
Here you can synchronise Titles Customers, Stock level, Title Categories, and Customer Categories between participating stores.
Each store must do this to ensure the databases are in unison

3. Request Resend
Click on File then click Request Resend.
The request resend function allows you request information from a particular store.

See below,


·Stock transfers  
If you select Stock Transfer you a have to enter the Transfer Number you are requesting.
At the bottom of the window you will need to fill in the Branch Code field for the store you are transferring to.

· Store Sales History
This will send the store sales history to National office (Paper Plus only)

· Store Sale transactions
This will send a consolidated sales history for use at National office (Paper Plus only)

· History and transactions
A combination of the above (Paper Plus only)
