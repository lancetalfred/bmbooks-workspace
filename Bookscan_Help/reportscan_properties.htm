Report Writer Properties


Report Writer's properties can be view and/or modified from an entry on the File menu.

Report Writer uses the data-files stored in your Bookscan database folder. Report Writer performs a quick test on these values each time that it is run.

Once Report Writer finds the data, it assumes that its inbuilt report forms will be found in a sub folder called Reports.

The Properties window also contains three options pertaining to the Preview window (available immediately after reports are generated and before printing). The first is a checkbox by which previewing can be omitted or not, as a default. (This default can be overridden for any report which begins by opening a parameters window. If the right mouse-button is clicked over the window, a popup menu makes it possible to switch previewing on/off as required, and the selection made will remain in force until a change is made by either the same means or through the Properties window, or through quitting Report Writer.)

You can also set a default size for the preview window, as well as a default zoom factor.
