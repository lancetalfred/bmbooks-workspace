Packing
Previous  Top  Next

Note: the steps below detail the procedures for packing standard orders. For orders for multiple stores, shipped to distribution centres (DCs), such as Coles Myer, the procedures are slightly different. See the Coles Myer section below details.

At each packing station, stores persons use the Packing window as they pack customer orders. As the barcode of order items are scanned, the program checks the product code and the quantity against the order. Packing labels are printed as each carton is filled. When finalising the order, the program will alert the packer to any items not yet packed. The packer has the option of add the missing items or, if they represent warehouse shortages, finalising the order. In this latter case, the program will backorder the missing items and the shortage flag on those products. As the order is finalised the invoice is created and printed for dispatch with the goods.

Detailed instructions
The Packing window is opened from the main menu: Modules/ Warehousing/ Packing.
·In the Scan picking slip combo down box, scan the picking slip's barcode.  
oTo consolidate a customer's orders into one shipment, just scan any subsequent picking slips for this customer.  
oThe scanned slips numbers will be displayed below the drop down box.  
oThe order lines for the picking slips will be displayed in the browser.  
Note: You will not be able to process picking slips for customers who are on stop.  
·Press the F5 key to start packing (or click the Start button).  
·Scan the barcode of each product as you pack it into the carton.  
·The Quantity is automatically set to 1.  
·For multiple quantities you can overtype the actual quantity.  
·Press F12 to save the line (or click the Save Line button).  
·After you fill a carton press the F8 key (or click the Carton Full button). The Shipping Details window will open.  
oFor the first carton, select the Carrier and enter the Consignment Note. These will be displayed when this window is subsequently opened.  
oIf a Freight charge is to be levied on the order, enter it here.  
oYou may also record the weight and size of the carton if required for this carrier.  
oClick Save when done. A carton label to be printed and the carton number incremented.  
·When all items for the customer have been packed, click the Post button. If the order has been set for Invoice with goods, the invoice will now print. Otherwise the ASN will be created and electronically despatched to the customer.  

Features
Unpacked items
If you try to post the order without it all being packed, the system will display a message 'Warning Not all lines have been packed. Backorder unpacked lines?'.
·If have been unable to locate the stock and wish to send the rest of the order click on the Yes button.  
oThe invoice will be created only for the lines packed.  
oAll items not despatched will be place on backorder and the master file flagged as having a stock shortage.  
·If you click on the No button, the browser will display all the lines not yet packed. To resume packing press the F5 key (or click the All Lines button).  

Unpacking from or adding to a carton
To edit what you have packed in a carton, click on the Edit Carton (F6) button. The contents of the current carton will be displayed in the browser.
·To select a different carton use the arrow keys beside the carton number.  
·To edit an item double click on the line in the browser to copy it into the edit line.  
·Type in the corrected quantity  
·Press F12 to save the line (or click the Save Line button).  
·To resume packing press the F5 key (or click the Resume button).  

Singles
If you just want to scan each item as you pack it without being able to type in multiple quantities, click on the Singles checkbox (or press the F9 key). This can speed up entering the data as there is then no need to press the F12 key after scanning each item.

Pallets
To palletise an order, click on the Palletise button.
The pallet number will be set to 1 and four pallet labels will be printed, to be placed on each face of the pallet after it is shrink-wrapped.
As each subsequent pallet is filled, click on the Next Pallet button.
