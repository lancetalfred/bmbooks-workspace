Re-indexing the Database
Previous  Top  Next


It is important to regularly re-index to ensure the integrity of your database. You should also do it after a system crash or if any anomalous data appears.
Ensure that all terminals are back to the main menu.

· From the main menu, click on Utilities/Database Utilities/Reindex Tables.

· Highlight those tables you wish to reindex (by clicking on them) or click on Select All.

· Click on the Re-index button.

The time it takes to re-index will depend on the speed of the computer you run the re-indexing on, the speed of your network and the size of your databases. Running this on the server machine, if you have one will allow it to run the fastest. Regularly purging and 'Packing' your files will considerably speed up re-indexing time also.
