The Subjects/KLA section of Bookscan allows you to create subjects and have them linked to ONIX codes. This enables an imported title (an ONIX import) to use the ONIX code and change it to a BIC Subjects code that it has been associated with.
You can also associate the subjects with Key Learning Areas, which are managed in this window also.

To open Subjects/KLA on the main menu click Tables, move the cursor on Authority Tables and then click Subjects/KLA.

ONIX BIC Subjects
To load the ONIX standard BIC subjects when in this window, press F12, this will allow you to not have to key them in.


Managing Subjects

Subjects
Subjects are displayed in list form in the top half of the window.

Add
To add a new Subject click on the Add button.
Enter in the following:
Code (maximum 6 characters )
Name
ONIX code (Select from drop down) Optional
Key Area (Select from drop down) Optional

Click the OK button

Edit
To modify an existing Subject click on the subject, then click the Edit button.
You may make changes to:
Code (maximum 6 characters)
Name
ONIX code (Select from drop down) Optional
Key Area (Select from drop down) Optional

Click the OK button

Delete
To delete an existing Subject click on the subject, then click the Delete button.
Click the Yes button.

Close
To close the window click the Close button.


Key Learning Areas
This is located in the bottom half of the window.
When a Subject is clicked, it will display the KLA associated with it in the Key Learning Area drop down list.

Add KLA
To add a new Key Learning Area, click the Add KLA button.
Enter in a Code and Name
Click the OK button

Edit KLA
Using the Key Learning Area drop down list, select the KLA you wish to edit then click the Edit KLA button.
You can make changes to the Name field.
Click the OK button

Delete KLA
Using the Key Learning Area drop down list, select the KLA you wish to delete then click the Delete KLA button.
Click the Yes button
