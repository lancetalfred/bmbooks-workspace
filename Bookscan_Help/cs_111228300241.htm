Customer Master - Categories
Top 


The Categories tab within the Customer Master allows for associating the customer with a Category (s) for such things as marketing.
To open the Categories tab, firstly load the customer master by clicking on the main menu Tables, then Customer Master.
Next, assuming the Categories tab is not visible, right click and then click on Show Categories, to make sure its checked.
This will then display the Categories tab.
This tab allows for a shortcut to categories instead of going through the Categories Master.

Category
On the right-hand side it will display the categories that the current customer is associated with.
When it first loads on the left-hand side will be the four buttons:

Add Category
This will allow you to link category(s) to the current customers record.
Click on Add Category. This will then hide the button and display on the left-hand side all the categories from the database.
Either type in the Add Category field the categories code and click Add (F8) button or select from the list and double-click on the category you wish to add.
The category will now be added to the customers record.
Type in another category to add more.   

When done click the Close (F9) button   

Delete Category
This will remove a category link to the customer, not delete the category itself.
Firstly click on the category you wish to delete on the right-hand side (holding down the Ctrl key will allow you to click on more than one).
Next click the Delete Category button.
Then click Yes button.
The category links will now be removed.

Create Category
Will allow you to quickly create a new category to be stored in the category database.
This might be the case if your customer does not fit into an existing category and you wish to make a new one for them to belong to.
Click Create Category button. This will display a window.
Enter in the New Code (max 6 characters) and Name (max 20 characters), then click OK button.
The category will now be added to the database and linked to the customer record.


Make Primary
The Make Primary allows for you to prioritise the importance of a customer being in particular categories, for such purposes as searches. It might also be the category they are most involved in.
Click on the category in the right-hand side list, which you wish to apply this to.
Next click Make Primary. This will move the category to the top of the list.


Membership
On the categories tab you can also handle customer membership.
Granting membership can be determined by you, however this allows for the expiration to be entered and prompted when that is over.
To add or change the date click on the Member Expiry field and select from the dates.
