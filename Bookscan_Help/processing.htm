How Report Writer Works

As well as extending to end-users the ability to design their own reports from scratch, Report Writer contains numerous predefined reports for users of Bookscan and PlusScan software. Users familiar with those reports should soon come to terms with the layout and operation of Report Writer.

Report Writer's reports can be redesigned, using the same tools that are available for the creation of the reports (but taking advantage of Report Writer'sfiltering mechanisms at the same time). The main report-design tool is a package called ReportPro, which is a standard component of Report Writer itself.

ReportPro stores report-definitions (usually called report-forms) in .rpt files which you can create, modify and run at your leisure, via Report Writer's windows. Report Writer's other contribution to reports is to select, gather, sort and summarise data for certain report-forms which are an integral part of the system. In designing your own reports from scratch, you have to find a way to make ReportPro perform these extra services (which are usually within its power). When you are working within the Report Designer you will have access to ReportPro's own Help services.

When Report Writer is preparing data for one of its integral reports, it puts a picture (something like a radar-scanner) on the monitor, to keep you informed that something's happening - because certain reports may keep you waiting for a while. You can kick off another report or function while Report Writer is already working on one.
