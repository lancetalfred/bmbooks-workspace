Subsidy Module
Top 


The subsidy module is used where some of your sales are subsidised by another organisation.
Customers eligible for a subsidy can have their sales discounted by one of three subsidy levels, with the discounted amount charged to the customer account of the subsidising organisation. To be eligible for a subsidy a customer must be a member of a specially set up customer category.
Subsidies can be applied in both cash sales and in invoicing.
You can also limit the subsidy to selected products. When processing orders for these products the correct subsidy will be automatically applied for eligible customers. Alternatively you can set the subsidy manually as you process orders.

The Subsidy module is separately licensed - to get a licence contact Barcode Solutions.

Setting up the subsidy module

System Options
Open the Sundry tab in System Options.
Check the Use Subsidy Module box .
Enter the subsidy percentages in the Subsidy Level fields ( in our example above type 40 in Subsidy Level 1 and 60 in the Subsidy Level 2 field ).
If you going to use product categories, check the box Use Subsidy Module box. Enter the product category code against each subsidy level ( e.g. type UNIFOR in top Title Category and TEXSUB in the second Title Category field.
Enter the customer category code in the Cust Category field ( in our example. SUBSID ).
Enter the customer key of the subsiding organisation in the Bill Subsidy field. ( in our example. SUBSID )

Set up the subsidy account
Open the customer master and set up the customer account for the subsidising organisation, ensuring that you set the debtor flag.

Set up the customer category
Open the Categories Maintenance window ( from the main menu select Tables/Categories ).
Set up a new category that customers who are eligible for a subsidy will be members of.
Give the category a meaningful name as the name will be used on the subsidy reports and windows. E.g. Category code SUBSID, category name Uniform Subsidy.
Add customers who are eligible for the subsidy to the category.

Set up product categories (if required)
If you are going to set products against subsidy levels, set up a category for each bonus level. E.g. If you are offering two subsidy levels 40% off uniforms and 60% off certain textbooks, you could set up a category code UNIFOR and another called TEXSUB.
Set the products eligible for subsidy against one of these categories.

Using the subsidy module

The module works the same way in Cash Sales and in Invoicing.
When a customer eligible for a subsidy is selected, a red message box will be displayed saying "eligible for subsidy".
If you have set up product subsidy categories, then as you enter products during the sale , the appropriate subsidy will be automatically applied against eligible products. If product categories are not set, you can add a subsidy to each line using the subsidy combo box that will be displayed on the window.
When posting the sale or invoice, the customer total will be reduced by the subsidy and the subsidy amount posted to the debtor account of the subsidising organisation.
