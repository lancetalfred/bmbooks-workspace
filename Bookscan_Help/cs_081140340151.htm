Adding a new supplier
To add a supplier to the supplier master, click on the New (F11) button on the Supplier Master window. The pop-up window will open where you can enter the new supplier code. The program will check that the code is unique. Then type in the rest of the supplier's details directly into the tabs of the Supplier Master window. As each tab is completed and click the Save button.
